## 二、承接线的核心命题

承接名称仍为：

```text
《分居》
```

许曼君已经完成L5、“肉偿账本”和“没有债也会来”。她已经能够承认自己不是为了还债才找玩家，但她仍然按照赵国强的出车表安排这段关系：

```text
丈夫外出
→ 玩家才能进201
→ 丈夫回来前结束
```

《分居》要改变的不是她有没有经济能力，也不是再教她一次“不必算账”，而是：

> 她不再一面替赵国强收工资卡、维持夫妻家庭，一面把另一段关系藏在丈夫外出的空窗里。

这条线用两个反向物件动作表达夫妻关系开始分开：

```text
许曼君把赵国强的工资卡归还给本人
赵国强把自己的201住户钥匙暂时交给管理员封存
```

工资卡归还代表：

- 她不再替丈夫管理未来收入；
- 她不再以“家里一切照旧”的方式继续掌管他的生活；
- 旧共同账、欠租和历史支出仍须在《离婚》中逐项处理，不因交卡自动清零。

钥匙临时封存代表：

- 赵国强本人选择暂时外住；
- 他不再按普通丈夫作息自由回201；
- 每次回楼都必须通过明确预约和钥匙取用流程；
- 他仍是丈夫和当前住户，钥匙没有永久作废，法律婚姻也没有解除。

钥匙不是魔法开关。只有以下三件事同时成立，普通丈夫回家路线才暂停：

```text
赵国强本人明确选择外住
＋ 玩家在公寓外部确认他真实离楼
＋ 201钥匙已经由本人放入封存袋并存进管理员室钥匙柜
```

缺少任一项，都不能只靠一句“他暂时不回来”改变世界。

## 三、承接完成与未完成的边界

### 3.1 《分居》完成时必须成立

1. 许曼君由本人决定把关系当面说清；
2. 她已经准备并亲手交还赵国强的工资卡；
3. 玩家将她署名的会面通知真实投进201信箱；
4. 赵国强在真实回楼时段取走通知，并确认会面；
5. 玩家准备了空的201临时钥匙封存袋；
6. 三人在201当面说破关系，玩家没有退回中立管理员身份；
7. 赵国强本人选择先去车队外住；
8. 赵国强本人把201钥匙放入封存袋；
9. 玩家亲自到公寓外部确认丈夫离楼，再把钥匙存进管理员室钥匙柜；
10. 201经过至少一个封条完整、丈夫没有取钥匙、玩家也没有留宿的真实夜晚；
11. 许曼君亲自收起用于安排秘密见面的出车表；
12. 玩家与许曼君在“丈夫已经知情、钥匙已经封存”的201完成一场路线绑定的完整L5亲密场次；
13. `201留宿权限`在该完整场次与事后收束成功后永久解锁，201从此成为第三个合法整夜睡眠地点；
14. 玩家在事后明确答应继续面对丈夫，而不是只享受新的无人空窗；
15. 赵国强按预约取回钥匙、回201拿走一批真实生活用品；
16. 赵国强提出过一次具体的婚姻修复方案；
17. 许曼君本人听完并拒绝恢复夫妻共同生活；
18. 赵国强归还钥匙，玩家再次封存；
19. 经过真实冷静时段后，夫妻与玩家在管理员室进行最终会面；
20. 赵国强亲口同意进入离婚办理，并选择让钥匙继续封存；
21. 玩家把钥匙状态从“临时外住封存”改为“待离婚交接”；
22. 赵国强再次真实离楼；
23. 201普通丈夫作息继续停用，只保留路线预约回楼。

### 3.2 《分居》完成时仍然不得成立

- 婚姻已经解除；
- 赵国强已经成为前夫；
- 201住户资格已经永久删除；
- 201旧钥匙已经作废；
- 门锁已经更换；
- 赵国强永远不能再进入201；
- 剩余共同物品已经分配；
- 房租、旧欠租或共同账已经清零；
- 孩子、监护或财产已经裁定；
- 玩家自动获得201钥匙、常驻权、再婚或独占关系；
- 一场亲密自动替夫妻完成离婚决定。

这些内容全部留给独立结局《离婚》。承接只把结局所需的现实基础做实。

## 四、四件核心物件

## 4.1 工资卡归还封套

显示名建议：

```text
赵国强工资卡归还封套
```

生命周期：

```text
许曼君在201亲手把工资卡放入封套
→ 封套固定留在201桌边
→ 玩家不能打开、取卡、使用或查看密码
→ 第一次三人会面时由许曼君本人打开
→ 工资卡直接交给赵国强本人
→ 写入“工资卡已归还”
→ 空封套只保留为201已经完成过交还的环境痕迹
```

工资卡不进入玩家背包，避免把玩家写成掌控夫妻私人资金的人。

该物件只决定“以后由谁持卡”，不修改真实余额、旧支出、欠租或共同财产。

## 4.2 201会面通知

显示名建议：

```text
许曼君署名的会面通知
```

生命周期：

```text
许曼君在201亲手写好
→ 进入玩家背包
→ 玩家到信箱区投进201信箱
→ 从背包移除，201信箱显示“有封署名通知”
→ 赵国强在真实回楼时段取走
→ 玩家再次到信箱区确认信封已取
→ 写入“丈夫已收到会面要求”
```

这不是匿名操纵，也不是伪造文书。通知只写：

- 许曼君要求三人当面谈；
- 建议的可用时段；
- 事情与夫妻生活和玩家有关；
- 不在信上提前讲完私密细节。

AI消息、微信已读或丈夫普通回楼不能替代信箱实物被取走的事实。

## 4.3 201临时钥匙封存袋

显示名建议：

```text
201临时钥匙封存袋
```

它来自管理员室现有钥匙柜旁的行政用品，不需要商店购买，也不新增通用门禁系统。

封存袋包含：

- 一次性编号封条；
- 201门牌标签；
- 当前用途栏：“临时外住”；
- 取用记录栏；
- 明确注明“临时保管不等于退居、换锁或婚姻解除”。

生命周期：

```text
管理员室准备空封存袋
→ 第一次会面日由玩家从钥匙柜取出并放进背包
→ 赵国强本人把201钥匙放入袋中
→ 玩家携带“已装钥匙、未入柜”的封存袋
→ 公寓外部确认赵国强真实离楼
→ 玩家回管理员室，把封存袋放进201钥匙格
→ 封条生效，袋子转为管理员室环境事实
→ 取物预约时由玩家取出封存袋
→ 赵国强本人验封、拆封、取钥匙
→ 取物结束后本人把钥匙放回袋中
→ 玩家重新封存并登记第二枚封条
→ 最终会面后状态改为“待离婚交接”
```

钥匙不得凭空复制。任一时刻只能存在一个权威位置：

```text
赵国强持有
玩家背包中的封存袋
管理员室201钥匙格
```

## 4.4 201钥匙取用记录

这不是玩家背包物件，而是管理员室钥匙柜的环境记录。

至少记录：

- 当前封存状态；
- 当前封条编号／修订号；
- 最近一次入柜时段；
- 最近一次取出原因；
- 当前持有人；
- 下一次合法预约；
- 是否已经进入“待离婚交接”。

它是丈夫作息与普通回家权限的长期消费者，不能只显示一行装饰文字。

## 七、逐场设计

## A1　201：《这张卡以后由他自己拿》

### 进入条件

- 201已入住；
- 许曼君为L5；
- “交易快感”已完成开幕和后效；
- 《肉偿账本》已完成；
- “没有债也会来”已完成；
- 许曼君在201；
- 赵国强按真实作息外出；
- 没有医院、生产、父亲电话或其他强剧情硬锁。

首场入口出现在201：

```text
问她那件一直没说完的事
```

若实现必须接管现有 `角色路线:201:操作性剧情` 商店占位，领取或购买只能开放这个入口，不能立即写分居、扣走工资卡或改变丈夫作息。

### 三个固定剧情回合

本场必须完成 **3个成功落地的AI剧情回合**。每回合只推进一项人物决定；生成失败、取消或同楼重掷仍停在原回合，不能因为玩家已经看过文字就跳拍。

**第1回合：她又看了一眼丈夫的出车表。**

她已经会在没有债的时候来找玩家，却仍习惯确认赵国强何时回楼。她主动承认这套生活不能继续。

台词方向：

> “账清了我还会来，这件事我认。可我不能一边认，一边还看他几点出车，才决定几点见你。”

**第2回合：她决定让三个人当面谈。**

她不让玩家替自己宣布离婚，也不靠微信把全部关系说破。她要求赵国强下一次回楼时，三人在201把话说清。

**第3回合：玩家回答自己是否会出现。**

玩家可以承担参与、问清她准备说什么，也可以暂缓。自然表达即可，不设置关键词口令。

明确拒绝出席时，路线停在A1，不产生通知和封套；已经完成的L5关系不回滚。

### 两个硬动作

正文成功后，201出现两个依次执行的动作：

```text
看她把工资卡放进归还封套
接过她写好的会面通知
```

动作一成功：

- 工资卡归还封套出现在201桌边；
- 工资卡仍属于赵国强；
- 玩家不能取走或使用；
- 不修改现金和旧账。

动作二成功：

- `许曼君署名的会面通知`进入玩家背包；
- 通知只能投递到201信箱；
- 重复点击不得复制。

A1到此结束，交还普通地图。

## A2　管理员室 → 信箱区：《把会面变成一件真实会发生的事》

A2由两项可自由先后完成的准备组成。**本段为纯地图／物件操作，固定为0个AI剧情回合**：准备封存袋、投递通知和日后确认取信都由系统直接反馈，不为了凑回合调用AI。它不是“一回合剧情”，而是一条包含两个地点、三次硬动作和一个真实时间门的操作链。

### A2-1　管理员室：准备空钥匙封存袋

玩家到管理员室，点击：

```text
准备201临时钥匙封存袋
```

成功后：

- 一个空封存袋固定放入管理员室201钥匙格；
- 尚未进入背包；
- 状态为“空袋待会面”；
- 只准备可能需要的临时保管工具，不推定赵国强一定会交钥匙；
- 不改变丈夫作息和在场。

这一步读取当前201住户事实，只填写门牌和用途，不创建法律文书、退居登记或换锁权限。

### A2-2　信箱区：投递许曼君的署名通知

玩家到信箱区，点击：

```text
把许曼君的会面通知投进201信箱
```

成功后：

- 通知从背包移除；
- 201信箱登记一封署名通知；
- 丈夫尚未收到；
- 不生成即时AI谈话。

通知只在赵国强下一个真实回楼时段被取走。丈夫人在外面时，重复查看只显示仍在信箱里。

### A2-3　经过时间以后再次确认

赵国强真实回楼并经过信箱区后，玩家再次到信箱区，点击：

```text
确认那封通知已经被取走
```

只有信封确实消失，才写入：

```text
赵国强已收到会面要求
```

随后由路线计算下一个三人都可到场的晚上。手机可显示一条简短确认，但消息生成失败不能撤销信箱已经被取走的事实。

删除信箱区以后，丈夫会面不再有可靠的收件依据，因此A3不能成立。

## A3　管理员室 → 大堂 → 201 → 公寓外部 → 管理员室：《钥匙不是一句“我走了”》

这是第一次连续现场，也是承接最重要的地图链之一。

### A3-1　管理员室取出空封存袋

约定晚上，玩家必须先到管理员室，点击：

```text
取出201临时钥匙封存袋
```

成功后：

- 空封存袋从钥匙柜环境进入玩家背包；
- 管理员室显示“封存袋外借，等待本人交钥匙”；
- 少了封存袋，A3不能启动；
- 玩家离开错误地点或错过预约时，袋子可放回柜中，不丢失。

### A3-2　大堂确认三人真实到场

玩家到大堂，必须同时确认：

- 许曼君已经从201来到大堂；
- 赵国强已经真实回楼；
- 玩家背包中有空封存袋；
- 201桌边仍有工资卡归还封套。

大堂出现：

```text
和他们一起回201
```

点击后才建立A3连续现场。人物缺席时不能由AI自动补齐。

### A3-3　201三人会面

本场固定为 **5个成功剧情回合**。每回合都必须停在需要玩家回应或完成硬动作的位置；任何一回合都不得顺手写完工资卡归还、关系说破、玩家回答、丈夫外住和交钥匙五件事。

**第1回合：三副碗筷仍是原来的家。**

赵国强先面对妻子为什么要求玩家在场。许曼君不能把玩家推到前面先宣判。本回合只建立三人坐下与冲突已经无法回避，结尾停在赵国强等她说明。

第1回合成功后，201出现硬动作：

```text
看她打开工资卡归还封套
```

**第2回合：她亲手归还工资卡。**

硬动作成功后才生成本回合。许曼君把卡直接交给赵国强，并说明：既然准备分开生活，就不能继续替他收未来收入，再让他误以为家庭仍照旧运转。

本回合提交：

- 卡持有人改为赵国强；
- 写入“工资卡已归还”；
- 空封套留在201；
- 旧账、余额和欠租不变。

赵国强本回合只针对“为什么突然还卡”作出反应，不能提前得知全部关系或决定外住。

**第3回合：许曼君亲口承认与玩家的关系。**

她承担自己的隐瞒与选择，不把责任全部推给丈夫跑车、娘家支出或玩家帮助。正文结尾只让赵国强转向玩家，不能替玩家回答。

**第4回合：赵国强直接质问玩家。**

玩家可以承担参与、承认伤害、要求对话保持边界。不能只说自己是管理员，也不能用租约或钥匙威胁丈夫让路。本回合必须停在玩家回答已经被听见、赵国强尚未作出离开决定的位置。

**第5回合：赵国强拒绝当场离婚，但选择先外住。**

他仍认为婚姻值得修复，也不接受玩家进入夫妻关系。他决定先到车队休息处住，冷静后再回来取东西和谈一次。正文停在他准备处理201钥匙的位置，不能提前写成钥匙已经入袋或已经封存在管理员室。

车队休息处不加入地图，不展示全知独处剧情。

### A3-4　丈夫本人把钥匙装入封存袋

赵国强准备离开前，201出现唯一硬动作：

```text
接住他递来的201钥匙封存袋
```

该动作演出中：

- 赵国强本人把自己的201住户钥匙放入空袋；
- 本人确认只是临时外住，不是退居和离婚；
- 封条先合上但尚未入柜；
- 玩家获得 `201临时钥匙封存袋（已装钥匙，待入柜）`；
- 赵国强仍保留住户身份；
- 普通丈夫作息此时尚未暂停。

AI不能提前写成钥匙已经在管理员室，也不能让玩家强行夺走钥匙。

### A3-5　公寓外部确认丈夫离楼

玩家必须随赵国强走过：

```text
201 → 大堂 → 公寓外部
```

在公寓外部点击：

```text
确认赵国强已经离楼
```

成功后只写：

```text
丈夫已真实离开公寓
```

钥匙仍在玩家背包，普通回家路线仍未正式关闭。

### A3-6　管理员室完成第一次封存

离楼确认后，下一必要地点是管理员室。玩家点击：

```text
把201钥匙封进钥匙柜
```

提交时同时复核：

- 背包中存在已装钥匙的封存袋；
- 赵国强已离楼；
- 许曼君仍住201；
- 当前没有另一条路线改写201住户；
- 封存袋尚未重复入柜。

成功后：

- 封存袋从背包移除；
- 管理员室201钥匙格显示“第一枚封条完整”；
- 201钥匙权威位置改为管理员室；
- 赵国强回楼模式由“普通作息”切换为“路线预约”；
- 普通201丈夫打断暂停；
- 普通夫妻共同生活模板暂停；
- 写入外住起点时段。

只有这一步完成，分居才真正开始。

## A4　201独住夜 → 管理员室复核 → 201完整亲密：《封条完整的一晚》

### A4-1　许曼君要求玩家也离开

第一次钥匙封存以后，玩家可以回201。这里固定为 **2个成功剧情回合**，不能用一条正文同时完成“丈夫刚走后的情绪”“她决定独住”与“玩家已经离场”。

**第1回合：她不把丈夫离楼变成庆祝。**

她先面对桌上空封套、少掉的钥匙和刚刚结束的争执，承认自己也需要独自理解这间屋子发生了什么。正文停在她尚未决定玩家今晚去留的位置。

**第2回合：她亲口要求玩家今晚离开。**

玩家回应以后，她明确说：

> “他的钥匙交出去，是他的决定。今晚你也回去。我想先看看，这间屋子只剩我一个人是什么样。”

第2回合成功后，201才出现：

```text
把201留给她一晚
```

点击后玩家离开201。只有玩家确实离开，并经过至少一个真实夜晚，才满足独住时间门。

玩家留在201、连续聊天、微信或重开地图都不能替代。

### A4-2　管理员室复核封条

次日以后，玩家必须先到管理员室，点击：

```text
核对201封条与取用记录
```

成功条件：

- 第一枚封条仍完整；
- 赵国强没有预约取钥匙；
- 钥匙没有离开管理员室；
- 独住夜真实经过。

成功后写入：

```text
201独住夜已验证
```

这一步相当于夏乔回302确认监控断线、沈静仪回302确认异常记录：它不是看一行提示，而是证明丈夫没有被普通作息偷偷放回201。

若封条状态异常、钥匙位置不符或时间线回档，A4不开放，系统显示真实当前去向。

### A4-3　201环境发生可见变化

玩家再次进入201，看到系统已经成立的变化：

- 第二副常用碗筷被收进柜子；
- 赵国强的工装集中到一处，等待本人预约领取；
- 鞋架少了一双常用鞋；
- 衣柜空出一部分；
- 夫妻共同物件没有被全部扔掉；
- 墙上的出车表仍在，但已经失去控制邀约的系统作用。

房内出现：

```text
陪她把出车表收进抽屉
```

由许曼君本人取下，玩家只帮她整理。成功后：

- 201环境登记“出车表已收起”；
- 许曼君后续邀约不再读取丈夫普通外出时段；
- 邀约只读取钥匙封存、预约冲突和她本人意愿；
- 不能再用普通出车空窗误触这条承接。

### A4-4　她主动再次邀请玩家

到安全晚上，许曼君通过现有私聊发出邀请。消息只开放201入口，不传送玩家。

玩家必须亲自到201。

### A4-5　两个固定关系开场回合

本段固定为 **2个成功剧情回合**；第2回合成功以前不得建立亲密账本。

**第1回合：她让玩家看见这间屋子已经怎样不同。**

不复演第一次受助、第一次动心或《肉偿账本》。她承认丈夫已经知道，钥匙也在管理员室。

**第2回合：她要求玩家不要把新状态理解成更方便的偷情空窗。**

台词方向：

> “他知道了，钥匙也交出去了。你今晚留下，不是因为终于没人会回来撞见。下一次他回来，你也得认今天。”

只有玩家明确愿意承担当前关系，才建立亲密账本。威胁住房、把丈夫离开当战利品、否认她的停止权时，本场暂停。

### A4-6　进入现有完整L5亲密系统

开场第二拍有效正文成功后：

1. 路线进入“分居之夜·亲密进行中”；
2. 创建真实普通 `_性爱场景`；
3. 参与者精确为201／许曼君；
4. 地点保持201；
5. 将普通场次标识绑定为《分居》唯一场次；
6. 把控制权完全交回现有亲密玩法。

必须完整复用：

- 自由输入与动作连续性；
- L5全部已解锁行为；
- 身体开发和角色偏好；
- “交易快感”招牌性癖；
- 当前服饰、孕态与成人CG五阶段；
- 保护准备；
- 体力、满意度和逐角色有效楼数；
- 主动收尾、体力耗尽和角色中止。

禁止：

- 另做“顺着她／接过节奏”按钮；
- 连点或长按代替完整亲密；
- 一条AI正文宣布已经发生；
- 固定动作；
- 固定收尾位置；
- 强制无保护；
- 强制受孕；
- 一张CG播放后直接跳事后。

### A4-7　完整判据

只有路线绑定场次满足全部条件，A4才进入事后：

```text
参与者包含201，且许曼君未退出
场次标识与路线绑定值完全一致
地点仍为201
赵国强钥匙仍在管理员室封存
结束方式为主动收尾或体力耗尽
许曼君个人满意度达到本场冻结的正常满意目标
许曼君个人有效楼数达到同一正常满意目标
时长评价不是“太短”
结束方式不是角色中止、突然离场或脚本强行收尾
```

按当前配置，201的L5普通满意目标通常为5，因此一般至少需要5个许曼君真实参与的有效亲密楼。正式实现读取本场冻结目标，不另写死一个新数字。

开场前应检查当前体力是否足以完成正常目标；不足时提示先休息，不让玩家必然中途失败。

若正常结束但未达到完整标准：

- 普通亲密结果照常保存；
- 不登记承接所需的完整分居之夜；
- 分居、工资卡归还、钥匙封存和丈夫知情不撤销；
- 她以后可以重新邀请；
- 不重演A1～A3。

明确角色中止时立即使用现有中止规则。分居和居住权不成为要求性行为的筹码。

### A4-8　交易快感的边界

许曼君仍可以把计数、条件、利息、结算等语言当作双方自愿的成人情趣，现有偏好照常生效。

但现实状态必须硬隔离：

```text
工资卡已归还 ≠ 她欠玩家补偿
丈夫钥匙已封存 ≠ 玩家买下201
完成亲密 ≠ 夫妻已经离婚
中止亲密 ≠ 她失去201居住权
```

不能复演唯一《肉偿账本》。

### A4-9　两个固定事后回合

完整亲密收尾后，必须再完成 **2个成功剧情回合**。亲密系统的收尾正文不能顺便替玩家作出后续承诺，也不能在同一回复里直接生成取物预约。

**第1回合：她先把当晚与下一次丈夫回楼联系起来。**

她不只评价本次亲密，而是问：

> “他下一次来拿东西，我不会让你躲。你还会不会站在这里？”

本回合结尾必须停在等待玩家回答的位置。

**第2回合：她回应玩家的选择，并决定今后是否允许留宿。**

玩家明确愿意继续面对时，写入：

```text
玩家愿意正面面对丈夫取物与修复
```

玩家拒绝或要求继续秘密时，关系成功路线暂停，但丈夫外住、工资卡归还和钥匙封存不撤销。

无论A5是否马上继续，只要本次路线绑定的完整亲密真实成立、许曼君没有中止，并且第2回合成功收束，系统同时写入稳定事实：

```text
201留宿权限：已永久解锁
```

### A4-10　永久新增201过夜瓷砖

权限写入后，201永久增加一个房间动作：

```text
在201过夜（睡到次日早晨）
```

首次可用时文案可以显示为：

```text
今晚留在201
```

“永久解锁”表示不因A5、A6、《分居》完成、《离婚》完成、刷新或跨日而重新上锁；但每次执行仍要复核现实条件。许曼君住院、明确不在201、当前关系已经硬中止、赵国强正在201或今晚已有取钥匙预约时，瓷砖保留为已解锁能力，但临时置灰并显示具体原因。

#### 每次执行条件

- 玩家当前就在201；
- `201留宿权限`已经成立；
- 许曼君本人真实在201，且不处于待产、住院或产后住院硬锁；
- 当前为晚上或深夜；
- 赵国强不在201；
- 201钥匙处于合法封存／待离婚交接，或者《离婚》已经完成且丈夫正式退居；
- 睡到次日早晨以前没有已经到期的丈夫取钥匙预约；
- 当前没有普通亲密、特殊场景、父亲电话、活动场景剧情或其他强制事件。

#### 结算必须复用现有睡眠事务

201过夜不是第二套睡眠系统。它调用现有的`睡到次日早晨`原子事务，并保留全部既有结果：

- 世界时间真实推进到次日早晨；
- 精力与体力按当前上限完全恢复；
- 作息、经济、孕情、生产、冷落与阶段线路按同一顺序结算；
- 重复点击只允许一个时间事务成功；
- 时间撤销仍可恢复到睡前；
- 玩家早晨醒来后仍在201，不能被现有默认逻辑送回管理员室。

现有时间入口和后端预检都要用同一份`201留宿可用`纯函数，不能只在前端显示按钮、后端仍以“只有管理员室或302能睡”为由拒绝。

#### 睡眠演出

201睡眠继续使用独立短线程，不创建普通聊天楼，也不推进《分居》节点。画面与事务顺序固定为：

```text
点击201留宿瓷砖
→ 立即显示 `201_留宿_夜.webp`
→ 发起现有睡眠独立生成并保持夜景等待
→ 生成成功后提交同一笔“睡到次日早晨”原子事务
→ 时间事务成功，切换 `201_留宿_晨.webp`并显示醒来结果
→ 时间事务失败或被陈旧水位拒绝，不显示伪造的清晨结果，也不恢复资源
```

与管理员室／302的普通睡眠不同，本线程允许且只允许许曼君作为固定同场人物：

- 可以演睡前收拾、关灯、夜间一句短话和次晨醒来；
- 不自动开始新的亲密场景；
- 不自动增加关系、堕落、满意度或生成受孕；
- 不凭空加入赵国强、其他住户或新任务；
- 根据当前孕态、身体负担和关系阶段调整文字，但不新增硬事实；
- 固定使用两张永久复用背景：`201_留宿_夜.webp`与`201_留宿_晨.webp`。

这项日常睡眠允许一次独立AI演出，因为它不承担承接进度；“不能一回合完成”的约束由A4前置2回合、完整亲密至少5个有效回合和事后2回合共同满足。首次留宿与以后每次留宿都只是世界时间行动，不重复播放A4的关系确认。

## A5　管理员室 → 大堂 → 201 → 公寓外部 → 管理员室：《预约取回钥匙》

A5使“丈夫外住”从一次摔门变成持续生活事实，也让管理员室钥匙机制拥有真实消费者。

本场的人物主戏固定为 **5个成功剧情回合**；A5-1至A5-3的预约、取袋、验封和交钥匙都是地图硬动作，不计入这5回合：

1. **第1回合：**赵国强重新进入201，看见房间已经改变，三人先确认本次只处理约定生活用品；
2. **第2回合：**“等他把约定的生活用品装好”硬动作完成后，他面对第二只行李袋与持续外住的现实；
3. **第3回合：**赵国强完整提出一次具体修复方案，正文停在等待许曼君回答；
4. **第4回合：**许曼君本人承认方案有分量，但明确拒绝恢复共同生活，正文停在等待玩家回应；
5. **第5回合：**玩家承担自己的位置，赵国强确认不会接受三人婚姻并准备归还钥匙，随后才开放“接回赵国强归还的201钥匙”。

不得在第1回合就打包、提修复、拒绝修复并归还钥匙，也不得把第3至第5回合压成一段AI独白。

### A5-1　生成一次取物预约

A4事后承担完成后，赵国强会在下一个安全白天提出一次取物预约。

路线状态必须记录：

- 预约时段；
- 取物目的；
- 只允许一次钥匙取用；
- 取用结束后必须归还；
- 当前封条编号。

手机通知可以显示预约，但管理员室201卡才是权威入口。消息失败不能让预约消失。


- 玩家不能在别的时段擅自取出。

### A5-3　大堂当面交给赵国强

玩家到大堂，赵国强真实出现。大堂动作：

```text
让赵国强验封并取回钥匙
```

只有本人到场才能执行。

成功后：

- 第一枚封条被本人确认完整；
- 赵国强从封存袋取出201钥匙；
- 钥匙持有人改为赵国强；
- 空封存袋仍由玩家保管；
- 建立本次路线到场演员；
- 地图开放“陪同回201”。

这不是恢复普通丈夫作息，只是一次预约进入。

### A5-4　201取第二批生活用品

赵国强本人使用钥匙进入201。玩家与许曼君都在场，或按夫妻要求由玩家留在门外；玩家不在场时，正文不能切全知视角。

- 一部分换洗衣物；
- 车队工装；
- 常用洗漱用品；
- 第二只生活行李袋。

玩家不能替他翻柜、扔东西或判定共同物品归属。

房内动作：

```text
等他把约定的生活用品装好
```

成功后，201环境中对应物件减少，证明外住不是一晚冲动。

### A5-5　丈夫提出一次具体修复

取物过程中，赵国强提出符合现有人设的修复方案，例如：

- 减少一部分非必要长途；
- 回家后不再只倒头睡；
- 与许曼君共同面对娘家支出边界；
- 给两个人各自保留明确的钱和时间；
- 不再把“工资卡全部交给她”当作自己已经参与家庭的一切。

这些只是他愿意尝试的方案。AI不能一段话以后直接写成已经换岗、加薪或解决全部家事。

许曼君必须由本人回答。她承认方案有分量，也承认丈夫过去并非一无是处，但明确拒绝恢复夫妻共同生活：

> “你愿意改，我听见了。可我现在答应回到原样，就是再瞒你一次。”

玩家可以承担自己的参与，但不能替她拒绝，也不能逼丈夫接受三人婚姻。

### A5-6　丈夫本人归还钥匙

本场收口时，201出现：

```text
接回赵国强归还的201钥匙
```

动作成功后：

### A5-7　公寓外部确认离楼

玩家再次跟到公寓外部，确认赵国强带着第二只行李袋离楼。

这一步同时证明：

- 生活用品真实离开201；
- 丈夫没有拿着钥匙留在楼里；

### A5-8　管理员室第二次封存

成功后：

若玩家未重新封存，A6不能开放，普通时间推进也应明确提示201钥匙仍在玩家手里，不能把它遗忘在背包。

## A6　管理员室 → 公寓外部：《把临时封存改成待离婚交接》

A5完成后至少经过一个完整游戏日。赵国强已在车队外住多个实际时段，取过生活用品，也亲自提出过修复。

最终会面不再回201重复第三次同桌，而是发生在钥匙真实所在的管理员室。

### A6-1　三人到管理员室

到下一个三人都可到场的安全白天：

- 许曼君从201来到管理员室；
- 赵国强从公寓外部进入；
- 玩家已经在管理员室；
- 201钥匙仍在第二枚封条中；
- 没有医院、生产或其他硬锁。

地图显示：

```text
在201钥匙柜前把下一步说清
```

### A6-2　四个固定最终会面回合

本场固定为 **4个成功剧情回合**。钥匙状态的最终硬动作只能在第4回合成功以后出现。

**第1回合：赵国强承认外住已经成为真实生活。**

钥匙封存记录、两只行李袋和多个实际时段都在。他不能再把分居理解成一晚气话。

**第2回合：许曼君再次确认自己的边界。**

她确认不恢复共同生活，也不要求丈夫接受玩家进入婚姻；这一回合只完成她自己的决定，不能替赵国强同意办理。

**第3回合：赵国强把问题转向玩家。**

他明确自己不接受名义夫妻或三人婚姻，并要求玩家说明今后是否仍承担这段关系。玩家必须获得一次完整回应机会，不能由许曼君替答，也不能用管理员权限威胁他。

**第4回合：赵国强亲口同意进入离婚办理。**

他回应玩家与许曼君已经说清的边界，再作出自己的决定。台词方向：

> “你不是一时气话，我也住出去想明白了。去办吧。剩下的东西、钥匙、账，一件件说清。”

他不祝福、不突然原谅，也不取回封存中的钥匙。

### A6-3　最终硬动作

正文成功后，管理员室出现唯一动作：

```text
把201钥匙状态改为“待离婚交接”
```

只有夫妻双方已经在当前有效现场明确同意，才能执行。

成功后：

- 第二枚封条保持完整；
- 钥匙仍在管理员室；
- 封存用途从“临时外住”改为“待离婚交接”；
- 普通丈夫作息继续停用；
- 赵国强以后只能因《离婚》或明确剩余取物预约回201；
- 写入“夫妻双方同意进入办理”；
- 解锁《离婚》，但不自动购买或启动。

该动作不是离婚登记，也不永久撤销住户资格。它只证明：丈夫本人已经决定在正式手续与剩余交接完成前不恢复普通共同居住。

### A6-4　公寓外部完成承接

玩家陪赵国强走到公寓外部，点击：

```text
确认赵国强返回车队外住
```

系统最终复核全部硬事实后，才登记：

```text
《分居》已完成
```

若钥匙仍不是“待离婚交接”、丈夫尚未离楼或任一关键事实缺失，不能靠AI台词完成。

## 八、固定回合数与背景CG台账

### 8.1 回合怎样计算

本稿中的“回合”统一指：**一条AI正文成功写回并通过当前拍验收**。玩家输入是回合之间的回应，不单独计数。

另有三种不混算的操作：

- **地图硬动作：**瓷砖、背包、信箱、钥匙柜和时间操作，由脚本直接结算，记为0个AI回合；
- **亲密有效回合：**沿用`_性爱场景`中许曼君本人真实参与的有效楼数，不用外层剧情回合代替；
- **睡眠日常演出：**201留宿解锁后的独立短生成，不承担承接进度，不计入下表主线回合。

统一纪律：

1. 人物主戏不得配置为1个AI回合；要么是0回合的纯系统操作，要么至少2回合；
2. 每回合只推进当前列明的一项人物事实；
3. 同楼重掷重放当前回合，失败、取消、迟到结果不推进；
4. 当前回合禁止提前写出下一回合的决定或下一项硬动作已经完成；
5. 地图动作成功后才允许下一回合消费该事实，AI不能先演后补账。

### 8.2 各步骤固定回合数

| 步骤 | 固定／最低AI回合 | 地图与时间动作 | 回合用途 |
|---|---:|---|---|
| A1《这张卡以后由他自己拿》 | **3** | 2个201硬动作 | 看出车表与承认问题；决定三人会面；玩家确认会出席 |
| A2《把会面变成真实会发生的事》 | **0** | 管理员室准备封存袋、信箱投递、真实取信确认＋时间门 | 纯物件链，不为凑数生成AI正文 |
| A3《钥匙不是一句“我走了”》 | **5** | 取袋、三人到场、交卡、收钥匙、确认离楼、第一次入柜 | 坐下；归还工资卡；妻子说破；丈夫质问玩家；丈夫决定外住 |
| A4《封条完整的一晚》 | **最低11** | 玩家离场、跨夜、验封、收出车表、绑定亲密、可选201留宿 | 独住前2回合＋亲密开场2回合＋正常亲密最低5有效回合＋事后2回合 |


A2虽然是0个AI回合，却至少跨两个地点、三次硬动作和一个真实丈夫回楼时间门。若A4当场冻结的满意目标为6，或玩家没有在每个亲密回合让许曼君真实参与，A4及总回合数自然增加，不能拿固定数字强制补满。

## 十一、亲密场景与路线状态如何接合

A4不能装进会屏蔽普通亲密结算的独立特殊场景壳。

正确模型参考《第二机位》开录：

```text
路线两拍开场
→ 创建普通亲密账本
→ 绑定精确场次标识
→ 交回完整亲密玩法
→ 普通收尾产生上次性爱结果
→ 路线只消费绑定结果
→ 完整才进入事后承担
```

路线不能复制第二套亲密系统，也不能因带有场景剧情票就触发“一楼脚本收尾”。

### 11.1 丈夫打断

A4开始前必须同时确认：

```text
赵国强外住
201钥匙在管理员室封存
当前没有合法取物预约
普通丈夫作息已暂停
```

满足以后，普通201丈夫回家打断不能投放赵国强。

但以下情况仍优先：

- 医院、待产、生产和产后恢复；
- 角色主动中止；
- 父亲通话或更高优先级全局事件；
- 时间线回档导致钥匙不再封存；
- 另一条硬结局已接管201。

### 11.2 怀孕与保护

本次服从现有普通规则：

- 不要求未孕；
- 不强制受孕；
- 不强制无保护；
- 不强制某种行为或位置；
- 若普通规则判定受孕，保留真实受孕来源与后续孕产生命周期；
- 已孕时使用当前孕态与合法成人素材；
- 住院期暂停路线现场，出院后从真实断点继续。

## 十二、持久状态不能压成一个“分居进度”

至少要分别表达：

| 硬事实 | 为什么独立 |
|---|---|
| 她已决定当面说清 | 不等于玩家答应出席 |
| 工资卡封套已准备 | 不等于卡已经归还 |
| 会面通知在背包／信箱／已取 | 决定预约是否成立 |
| 空封存袋已准备 | 不等于丈夫交了钥匙 |
| 丈夫已知玩家关系 | 疑心降低不能恢复无知 |
| 工资卡已归还 | 未来资金管理者已改变 |
| 第一次钥匙交出 | 不等于已经入柜 |
| 第一次离楼确认 | 不等于钥匙已封存 |
| 钥匙当前权威位置 | 防复制与错投作息 |
| 第一枚封条状态 | 独住夜与普通回家门 |
| 独住夜起止时段 | 不能刷聊天代替 |
| 出车表已收起 | 邀约规则的真实切换 |
| A4绑定场次标识 | 防后续普通亲密补票 |
| A4完整结果 | 区分发生过与完整完成 |
| 201留宿权限 | 完整亲密与事后收束后永久开放201整夜睡眠，但不等于玩家拥有钥匙或无条件进门 |
| 玩家事后承担 | 性行为不能替玩家承诺 |
| 取物预约 | 丈夫回楼不是普通作息 |
| 第二批用品已取 | 证明外住持续 |
| 修复方案已提出 | 不能从摊牌直接跳同意离婚 |
| 她已拒绝修复 | 必须由本人作决定 |
| 第二枚封条状态 | 证明丈夫再次归还钥匙 |
| 双方同意办理 | 承接最终人物事实 |
| 钥匙待离婚交接 | 《离婚》的实物前置 |

合法断点包括：

- 通知已经投递但丈夫尚未取走；
- 丈夫已取通知但会面时段未到；
- 工资卡已归还但丈夫尚未交钥匙；
- 丈夫已离楼但封存袋仍在玩家背包；
- 钥匙已封存但独住夜未经过；
- 亲密发生但未达到完整标准；
- 完整亲密已发生但玩家尚未承担；
- 201留宿权限已经解锁，但当前因许曼君不在、医院硬锁或丈夫预约而临时不可执行；
- 取物完成但钥匙尚未重新入柜；
- 修复被拒绝但丈夫尚未同意办理；
- 双方已同意但钥匙状态尚未改为待离婚交接。

每个断点都必须有唯一继续入口，不能回到A1重演。

## 十三、时间结构

建议最短跨五个实际游戏日，不固定星期，不设置错过即失败。

```text
第1日：A1决定说清，准备工资卡封套和通知
第1～2日：A2投递，等待丈夫真实取信
约定晚上：A3摊牌、工资卡归还、第一次钥匙封存
当夜：许曼君独住201
第2～3日：A4核验封条、收起出车表、完整亲密与事后承担；201留宿永久解锁
第3～4日：A5预约取物、修复、第二次封存
再经过一个完整日：A6同意办理并改为待离婚交接
```

时间只认 `系统._绝对时段`：

- 普通聊天不推进；
- 微信不推进；
- 重开地图不推进；
- 亲密有效楼数不等于世界日数；
- 通知只在丈夫真实回楼时段被取；
- 独住夜必须实际跨夜；
- 修复后必须有真实冷静日；
- A4以后玩家可以在满足条件时从201直接睡到次日早晨，但这项日常睡眠不替代A5或A6的预约等待；
- 等待期间释放全局剧情槽；
- 只有当次连续现场短暂锁定演员、地点和输入。

## 十五、失败、取消、回档与拒绝

### 15.1 正文失败

- 未成功落地的当前拍不推进；
- 已完成的投递、工资卡交还、钥匙移动、封条和时间不重做；
- 同楼重掷只重演当前拍；
- 迟到结果不能污染新聊天或新分支；
- 图片失败只回退现有背景。

### 15.2 物件幂等

- 会面通知只生成一张、只投递一次；
- 工资卡只归还一次；
- 201钥匙只能有一个权威位置；
- 空封存袋不能复制；
- 入柜、取出、归还和再次入柜各自只提交一次；
- 封条编号以修订号单调增加；
- 回档以后按当前时间线恢复，不从旧分支补发物件。

### 15.3 玩家暂缓

- A1暂缓：不产生物件；
- 通知未投递：丈夫不会预约；
- 会面日没取封存袋：三人现场不开始；
- A3玩家否认关系：丈夫已经听见妻子的选择，路线进入待澄清，不强写玩家承担；
- 丈夫已交钥匙但玩家尚未入柜：只开放公寓外部与管理员室收口，不允许开启亲密或推进长时间；
- A4暂缓亲密：分居与钥匙封存保留，之后重约；
- A4完整后拒绝承担：路线暂停，丈夫外住不撤销；201留宿权限仍按已经成立的完整场次保留，但每次执行仍需许曼君当下允许；
- 201留宿独立生成失败：世界时间不推进、资源不恢复，按钮可重试；
- 201留宿重复点击：只允许一笔睡眠事务成功，第二次只显示“时间正在推进”；
- 丈夫取钥匙预约会在睡到早晨前到期、许曼君不在201或医院硬锁时：留宿瓷砖临时置灰，不清除永久解锁事实；
- 时间撤销成功时：恢复睡前世界状态、资源和201地点，不能只退时间却把玩家留在清晨结果里；
- A5错过取物预约：钥匙继续封存，预约顺延；
- A5未重新入柜：A6不开放；
- A6未到场：双方不能通过普通微信隔空同意办理。

### 15.4 角色中止与危险冲突

- 亲密中明确中止立即使用现有角色中止规则；
- 玩家威胁、抢钥匙、扣留工资卡或主动升级暴力，不能继续正常成功文本；
- 赵国强的愤怒可以表现为拍桌、推椅和提高音量，但不能由AI随机升级重伤或死亡；
- 真正危险现场须安全结束并保存已经成立的知情事实，再从明确恢复入口继续；
- 不能把生成失败误判为玩家挑衅。

### 15.5 医院、孕产与孩子

- 医院硬状态优先；
- 住院时暂停投递后会面、亲密、取物和最终会面；
- 已有孕情、胎次、受孕来源和孩子记录全部保留；
- 不以怀孕作为离婚条件；
- 若已有需要照护的孩子，必须读取真实家庭记录确认照护持续；
- 不自动裁定监护权或让孩子凭空无人照顾。

### 15.6 旧档

旧档只有以下内容时，不推断新承接完成：

- L5；
- 《肉偿账本》；
- “没有债也会来”；
- 低婚姻值；
- 高丈夫疑心；
- 旧结局轨道；
- 任意一次普通201亲密；
- 历史草案中的账本、工作角或临时客房。

满足入口条件的旧档从A1开始，不重演阶段唯一场景。

### 15.7 其他硬结局

已有死亡、整户离场、灾难或互斥丈夫结局时，不覆盖原事实。不能把钥匙封存强行套在已经不存在的住户上。

## 十六、运行结构

这条承接跨多日、多个地点和一场普通亲密，不应从A1开始长期占用通用 `_特殊场景`。

建议职责：

- **路线紧凑状态**：保存物件位置、封条修订、预约、阶段和完成事实；
- **场景剧情事务**：只负责A1、A3、A4开场／事后、A5修复和A6谈话的连续节拍；
- **地图动作**：负责投递、取袋、交卡、收钥匙、入柜、验封、取物和改状态；
- **普通亲密系统**：完整负责A4的自由玩法、资源、满意度、收尾、角色中止与受孕；
- **丈夫作息覆盖**：读取钥匙位置＋外住事实＋预约状态；

## 二十一、现有源码可落地性核对与实施边界

> 核对日期：2026-08-31。
> 本节依据当前 `release/rq0904`、HEAD `f1bbde58` 的真实源码补充设计边界。它只证明本稿能够沿现有架构落地，并标出必须同时修改的所有权位置；不代表Schema、状态机、瓷砖、素材或测试已经实现。

### 21.1 核对结论

本稿的回合结构与素材数量可以保留：

```text
主线最低成功AI回合：28
新增非成人全屏画面：12
新增成人CG：0
```

这里的28不是为了拖长而写死的配额，而是当前逐场人物决定的最低和：

```text
A1 3
＋ A3 5
＋ A4 独住前2、亲密开场2、正常亲密通常至少5、事后2
＋ A5 5
＋ A6 4
＝ 通常最低28
```

若A4冻结的正常满意目标高于5，或某一亲密楼没有让许曼君真实参与，总回合数自然增加。系统瓷砖、投信、验封、入柜和世界时间动作仍记为0个AI回合，不用无意义正文凑数。

源码核对同时确认：

> `201留宿`绝不能只在前端增加一个“睡觉”按钮。

当前睡眠入口、宿主业务门、原子事务预检、睡醒地点、撤销地点、独立演出和深夜提示都把合法地点写成“管理员室或302”。只改其中一处会产生以下假实现：

- 按钮显示但后端拒绝；
- 时间成功推进却把玩家送回管理员室；
- 能睡但不能撤销；
- 夜间画面显示201，实际结算地点却是管理员室；
- 深夜提示仍要求离开201；
- 普通睡眠导演词禁止许曼君在场；
- 路线状态已分居，但赵国强仍被普通作息投回201。

因此201留宿必须作为一项跨层能力整体接线。

### 21.2 建议的单一路线状态

建议在 `系统` 下增加一份紧凑对象：

```text
系统._许曼君分居
```

不为每个步骤扩散几十个根级布尔值。对象至少表达：

| 字段 | 建议语义 |
|---|---|
| 阶段 | A1至A6的唯一主阶段与合法断点 |
| 当前拍 | 当前连续人物现场的下一成功拍；失败、取消和重掷不增加 |
| 最早继续时段 | 取信、独住夜、取物预约和最终冷静日共用的世界时间门 |
| 会面通知位置 | 未生成／玩家背包／201信箱／已由赵国强取走 |
| 工资卡状态 | 仍由许曼君保管／封套已准备／已归还赵国强 |
| 封存袋位置 | 未准备／管理员室空袋／玩家背包空袋／玩家背包已装钥匙／管理员室入柜 |
| 钥匙位置 | 赵国强持有／封存袋随玩家／管理员室201钥匙格 |
| 钥匙用途 | 普通住户／临时外住／预约取物／待离婚交接 |
| 封条修订 | 0、1、2……；每次合法拆封和重新封存单调更新 |
| 预约 | 时段、用途、是否到期、是否完成；不靠手机消息作为真值 |
| 独住夜起点 | 证明玩家离开201后真实跨夜 |
| 绑定亲密场次标识 | 只认A4由路线创建的那一场普通亲密 |
| 绑定亲密完整结果 | 区分发生过、正常结束与达到完整判据 |
| 玩家事后承担 | A5人物关系继续门，不与亲密结果混成一个事实 |
| 201留宿权限 | 一经路线绑定完整亲密与事后收束成立，永久保持已解锁 |
| 完成楼层 | 《分居》最终成功提交点，供刷新、回档和数据库摘要定位 |

物件位置必须使用互斥枚举，不能同时出现“钥匙在丈夫手里”和“钥匙已在管理员室”。所有地图动作先校验当前枚举，再原子切换到下一位置；重复点击只得到当前状态提示，不复制物件。

### 21.3 丈夫外住必须进入统一作息真值

当前地图演员、正文快照、档案卡、丈夫打断、对饮、邀约、经济结算和时间推进都通过：

```text
丈夫在楼(户节点, 门牌, 绝对时段)
```

读取丈夫位置。因此不能只让《分居》模块自己判断“赵国强外住”，也不能只在客户端隐藏他的立绘。

建议在201丈夫节点增加通用、可回档的居住覆盖，例如：

```text
户.201.夫._居住模式
户.201.夫._预约回楼起
户.201.夫._预约回楼至
```

居住模式至少区分：

```text
普通作息
路线外住
预约回楼
待离婚交接
正式退居（留给《离婚》）
```

`丈夫在楼()`的语义应为：

1. 普通作息时继续读取现有固定周作息、阶段预约和短期外出窗口；
2. 路线外住或待离婚交接时，默认返回外出；
3. 只有当前绝对时段落在本次合法取物预约、且钥匙确实已经由赵国强本人取回时，才允许本次路线把他投到大堂或201；
4. 预约结束、钥匙重新入袋并确认离楼以后，立即恢复路线外住；
5. 《离婚》完成后再由独立结局把模式改为正式退居。

禁止用一个极大的 `_剧情外出至` 冒充永久分居。那种做法无法自然表达预约回楼、待离婚交接、回档和正式退居，也容易与其他阶段预约互相覆盖。

### 21.4 201留宿的唯一可用判定

建议新增一份无副作用纯函数，概念名可以是：

```text
读取201留宿可用状态(data, 当前地点, 当前绝对时段)
→ { 已解锁, 可执行, 原因 }
```

同一函数必须同时由房间瓷砖、宿主事件门、时间事务预检和深夜提示消费。不得前端和后端各写一套近似条件。

永久事实只有：

```text
系统._许曼君分居.201留宿权限 = 已解锁
```

每次执行则重新核对：

- 玩家当前确实在201；
- 当前为晚上或深夜；
- 许曼君真实在201，且不处于待产、陪产、住院或产后住院硬锁；
- 赵国强不在201；
- 201钥匙处于临时封存、待离婚交接，或《离婚》完成后的正式退居状态；
- 睡到次日早晨以前没有已经到期的赵国强取物预约；
- 当前没有普通亲密、活动场景、特殊场景、父亲通话、录像带录制或其他强事务；
- 没有一位丈夫已经排期、正准备在睡前找玩家。此类通用丈夫登门不得随机改演为“其他丈夫半夜找到201”，应先回管理员室／302处理；
- 母亲首夜第二幕等明确绑定管理员室或302早餐的待办不存在。不能从201睡醒后把早餐正文伪装成发生在管理员室。

“永久解锁”与“当前可执行”必须分开。临时不满足时瓷砖保留其已经解锁的身份，但置灰并显示唯一具体原因；不得把权限清零，也不得要求重做A4亲密。

| `index.ts` 的睡眠独立演出 | 通用导演词禁止凭空安排任何住户 | 201专属分支只允许许曼君作为固定同场人物；不允许赵国强、其他住户或自动亲密 |
| `App.vue` 与 `components/回合输入.vue` | 深夜提示写死“管理员室或302” | 已解锁且当前可用时提示可在201留宿；未解锁或临时禁用时继续给真实可用地点，不提前剧透功能 |
| `App.vue` 的背景解析 | 已支持按路线状态返回房间差分背景 | 增加201分居背景解析，并明确与孕产背景的优先级 |

201留宿继续使用现有的时间事务ID、预期绝对时段、聊天双存储恢复、独立事件草稿与撤销点。它不是新增一种时间推进方式，仍然发送：

```text
睡到次日早晨
```

地点与同伴语义由201可用状态和专属睡眠演出决定。

### 21.6 睡眠演出的提交边界

正确顺序必须保持：

```text
读取201留宿可用状态
→ 显示201夜景
→ 生成不入正文长期记忆的独立睡眠草稿
→ 再次复核聊天、时间水位、201权限、丈夫预约与医院状态
→ 原子提交“睡到次日早晨”
→ 写入同一份撤销点
→ 保持醒来地点为201
→ 显示201晨景与结算结果
```

任何一步失败：

- 世界时间不推进；
- 精力和体力不恢复；
- 后台经济、孕产和冷落不结算；
- 不显示伪造的清晨画面；
- 不推进《分居》；
- 不清除永久留宿权限；
- 玩家可以从当前真实状态重试。

201专属睡眠正文只允许表现：

- 许曼君收拾房间、关灯或与玩家说一句短话；
- 当前孕态或身体负担造成的自然生活差异；
- 同床、分床、先睡或早醒等不改变系统事实的日常细节；
- 次晨在201醒来，或许曼君已经先起身但没有凭空离开世界作息。

不得自动表现：

- 新一场性行为；
- 自动无保护、射精或受孕；
- 自动增加关系、堕落、满意度、风闻或现金；
- 赵国强突然回家；
- 其他住户夜访；
- A5预约、A6同意办理或《离婚》被睡眠顺便完成。

### 21.7 持久背景与孕产背景的优先级

当前201在已生产一胎以后，会长期读取“房间宝宝用品”生产背景。若直接让分居背景无条件覆盖，既有孩子和育儿物件会从房间里消失；若生产背景无条件覆盖，玩家又可能看不见分居环境变化。

因此不能靠简单的“最后返回哪张图”解决。权威优先级为：

```text
医院／待产等硬场景
＞ 已生产孩子的房间背景
＞ 201分居基础背景
＞ 原201普通背景
```

当生产背景优先时，分居状态仍必须由不会与胎次冲突的轻量层持续表达：

- 门牌“分居中”角标；
- 第二副常用碗筷已收起的状态提示；
- 出车表已收起；
- 赵国强用品已减少；
- 管理员室201钥匙格状态；
- 201留宿月亮瓷砖。

本稿第8节的两张201持久背景仍保留，用于没有生产背景覆盖时的完整房间表现。已有孩子时不再为了组合“分居阶段×1至3胎”额外生成六张一次性排列图，也不能牺牲已存在的育儿长期后果。

两张201留宿夜／晨背景刻意避免腹部、胎次和完整人物，因此可以在未孕、孕期、产后以及已有孩子的状态下复用；当房间有孩子时，正文只能读取真实家庭记录加入安静生活细节，不能凭空改变孩子位置或照护状态。

### 21.8 通用丈夫登门与赵国强知情的兼容

现有怀孕系统会在孕情已告知、已曝光且疑心达到门槛时排期“丈夫睡前登门”。普通201版本的语义是赵国强第一次怀疑、第一次来找玩家对质。

《分居》A3以后已经成立：

```text
赵国强亲耳知道玩家与许曼君的关系
```

因此不得在之后又投放一场“他刚听说妻子可能与玩家有关系”的通用初次对质。

实现时必须统一处理：

- A3以前：现有普通丈夫登门照常有效；若正在进行，先收束再启动《分居》；
- A3以后：201通用初次对质不再排期；
- 新孕情若确实需要丈夫反应，只能消费“已经知情、正在分居、钥匙封存”的事实，注册新的稳定变体或交给《离婚》后果处理；
- 不能简单把登门账标成完成，从而吞掉其他住户的合法丈夫事件；只处理201这一户的语义；
- 201留宿点击时若有其他户丈夫已经排期，先阻止留宿，避免把未设计的对质搬进201。

### 21.9 路线背景与事件CG的接线原则

现有《第二机位》已经采用：

```text
路线纯函数返回文件语义名
→ App背景解析按状态选择资源
→ 图片失败回退普通房间背景
```

《分居》应沿用相同模型，而不是在剧情函数里直接操纵Vue图片地址。

建议分别提供：

```text
许曼君分居房间背景文件(data, 地点)
许曼君分居事件CG文件(data)
许曼君201留宿背景文件(阶段)
```

其中：

- 房间背景只根据已提交的持久状态返回；
- 事件CG只根据当前有效剧情拍或刚完成的硬动作返回；
- 留宿背景只读取本次睡眠独立线程的夜／晨阶段；
- 动态封条编号、日期、姓名和“第一次／第二次”不烘焙进图片；
- 图片加载失败不得阻止工资卡、钥匙、亲密、时间或离婚前置事实提交。

### 21.10 推荐落地顺序

为了避免先做剧情、最后才发现201睡眠或丈夫作息接不上，正式实现应按以下顺序：

1. 增加 `_许曼君分居` 紧凑Schema与旧档默认值；
2. 增加201丈夫居住覆盖，并先让 `丈夫在楼()` 的所有既有消费者共享真值；
3. 实现物件位置、封条修订、预约和地图动作的纯状态机；
4. 实现201留宿纯函数及睡眠全链路接线，先用普通背景验证时间、恢复、醒来地点和撤销；
5. 接入A1、A3、A4、A5、A6的多拍剧情事务；
6. 把A4开场接入现有普通亲密场次，并消费精确场次标识、个人有效楼数和满意目标；
7. 接入持久背景、事件CG和夜／晨背景；
8. 最后补手机预约、有限风闻、数据库摘要和《离婚》解锁，不让可选副作用阻塞硬状态。

- 独立生成失败不推进、不恢复、不显示晨景；
- 睡眠正文不自动触发亲密、受孕、关系增长或新任务；
- 其他户丈夫待登门、母亲早餐待办和赵国强取物预约能正确阻止201留宿。

#### 视觉

- 无孩子时按独住／取物后切换两张201持久背景；
- 已有孩子时继续保留对应胎次育儿背景，同时显示分居轻量状态层；
- 夜／晨背景兼容未孕、孕期、产后和已有孩子；
- 任何图片404都只回退背景，不回滚或跳过硬状态。
