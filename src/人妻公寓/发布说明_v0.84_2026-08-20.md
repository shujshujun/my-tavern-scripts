# 《人妻公寓》v0.84 发布说明

发布日期：2026-08-20

发布标签：`rq0.84`

## 本次更新

v0.84 是一次全量稳定性与兼容性更新。项目已完成 192／192 个产品文件和 244／244 个功能的逐项审查，累计修复 76 个真实 BUG。

主要改进包括：

- 加固存档读取、旧档继承、变量重生成与失败回滚，避免残缺存档被默认值伪装成新局。
- 修复回档、切聊天、swipe、删楼及 A→B→A 后旧异步结果可能写入当前分支的问题。
- 修复正文生成与购买、送礼、背包、任务等普通业务并发时互相覆盖，以及快速双击重复提交的问题。
- 完善手机发送、撤回、邀约、朋友圈图片、父亲电话、数据库记忆与强剧情只读边界。
- 完善多人亲密的逐角色同意、拒绝、退出、焦点、个人参与楼数、CG、受孕与丈夫打断结算。
- 完善孕情公开、家庭计划监控票、生产、陪产、住院、产前／产后看望及旧档孩子事实恢复。
- 修复客户端重复挂载、中文输入法 Enter 误发送、正文编辑失败丢草稿、图片迟到错误、地图点穿与重要提示互相覆盖。
- 统一变量公开格式为标准 `<UpdateVariable><JSONPatch>` 协议，并保留 number、boolean、string 与 null 的真实 JSON 类型。
- 加固设置原子保存、MVU 自动请求自愈、脚本单例心跳、启动世代复核与版本检测超时。
- 版本检测不再把 beta、rc、dev 或损坏字符串误认为正式稳定版。
