# 《录像带》平板母带本地化分镜 v2

> 2026-09-01 · 完整过程修订稿。
> 本稿取代 [v1](./录像带_平板母带本地化分镜_v1_2026-09-01.md) 第六节的“五格高光”播放映射；v1 第四、五节的 `TAPE-SJY-01…10`、`TAPE-ZXM-01…10` 源镜定义继续有效。
> 交付状态：二十张正式平板帧、十八张外层生命周期镜头与 v2 运行时均已完成并验证。旧 `SCREEN-102/202-01…05` 继续只作为无版本五格试播兼容资产。

## 一、为什么必须重做

### 1. 设计初衷

平板里播放的不是五张成人高光，而是对应妻子亲手开始、与同一成年玩家连续经历、亲手保留并停止录制的一盘母带。丈夫看到的必须是一个有起点、升级、转折、完成和余韵的过程；外层同时完成贞操锁的授权闭环。

### 2. 正常运行

完整观看顺序固定为：

`锁仍锁着 → 播放妻子片头 → 宣读条件并明确接受 → 丈夫本人解锁 → 母带 02…10 连续推进 → 丈夫只对屏幕里的妻子完成 → 丈夫本人复锁 → 陪看人目视核验 → 回执／钥匙交接`

母带的十个节点不是十张互不相干的图。每个节点至少包含一张屏幕 CG、对应的剧情文字／对白、前后动作承接和一次必要的现场反应；镜头之间必须能读出同一晚、同一房间、同一对人物和连续身体位置。

### 3. 对游戏的作用

- 平板层提供丈夫无法误读的完整事实，而不是只报结果。
- 身体层让“观看”变成一次受条件约束的事件，不是随时可重复打开的图库。
- 现场层通过陪看人的距离、见证和不接触原则制造压力，但不抢走屏幕里妻子的主体地位。
- 102 与 202 使用同一机制，却分别落到“获得观众席”和“仅此一次”的不同结算。

### 4. 旧版为什么断裂

v1 虽然写了每盘十拍，生产和消费层却只抽取 `01 / 02 / 06 / 09 / 10`，把主动口交、首次性交、连接换位、后半轮升级和峰值前准备全部跳过。运行时类型、资源正则和测试又把序号上限写死为 5，所以成品只能表达“片头 → 前戏 → 女上位 → 峰值 → 片尾”的摘要。

丈夫的“锁定 → 授权 → 本人解锁 → 本人复锁 → 核验”已写在整场 v2 分镜，但没有进入五格资产包，也没有被状态机消费。此前所谓“完成”只代表十张试播图片自身通过审核，不能代表整场故事完成。

### 5. 兼容原则

- 不删除、不覆盖现有十张已验收图片及其审核、SHA 和 provenance。
- 正式完整轨道使用版本化 ID，避免把旧 `SCREEN-102-03`（实际来源为 `TAPE-SJY-06`）误解释成新第三拍。
- 完整资源未全部验收前，不切换现有运行时，不让半套新轨道进入游戏。
- 以后切换时保留旧无版本 1—5 载荷为试播兼容入口；完整剧情只发送带版本的 1—10 载荷。

## 二、完整母带的十段弧线

两盘使用同一结构，不使用同一表演。沈静仪盘强调她清楚面对镜头并留下证据；周小满盘强调她从再次确认镜头到主动掌控、最终自己决定保留。

| 序号 | 叙事阶段 | 沈静仪源镜 | 周小满源镜 | 必须让观众读到的信息 |
|---:|---|---|---|---|
| 01 | 开始 | `TAPE-SJY-01` | `TAPE-ZXM-01` | 妻子亲手开录，玩家身份与自愿记录成立；此时丈夫仍锁着 |
| 02 | 进入 | `TAPE-SJY-02` | `TAPE-ZXM-02` | 片头结束后进入明确前戏，丈夫解锁后才允许开始自己的动作 |
| 03 | 主动参与 | `TAPE-SJY-03` | `TAPE-ZXM-03` | 妻子主动回应玩家，母带不再只是被动展示 |
| 04 | 首次越线 | `TAPE-SJY-04` | `TAPE-ZXM-04` | 第一次明确性交成立，丈夫得到无法误读的关系证据 |
| 05 | 连续换位 | `TAPE-SJY-05` | `TAPE-ZXM-05` | 保持人物和动作连续完成换位，证明这是实录而非姿势拼贴 |
| 06 | 妻子掌控 | `TAPE-SJY-06` | `TAPE-ZXM-06` | 妻子主动控制节奏并经历第一轮高点，录制没有中断 |
| 07 | 第二轮升档 | `TAPE-SJY-07` | `TAPE-ZXM-07` | 进入后半轮，强度继续上升而不是在第一轮后突然跳结尾 |
| 08 | 峰值准备 | `TAPE-SJY-08` | `TAPE-ZXM-08` | 妻子明确选择继续，以无玩具的一对一准备承接下一镜 |
| 09 | 硬核峰值 | `TAPE-SJY-09` | `TAPE-ZXM-09` | 本盘最高尺度与明确完成成立，仍只有妻子和同一玩家 |
| 10 | 结果与停止 | `TAPE-SJY-10` | `TAPE-ZXM-10` | 保留上一镜结果，妻子直视镜头留话并亲手停止录制 |

这十段共同组成“开录 → 升温 → 主动 → 首次性交 → 连续换位 → 第一轮高点 → 第二轮升档 → 峰值准备 → 完成 → 余韵停录”。任何正式播放不得再从 02 直接跳到 06，也不得从 06 直接跳到 09。

## 四、屏幕、丈夫与陪看人的交错节奏

### 播放前

1. 平板黑屏，丈夫的锁定状态可见或被清楚确认。
2. `SCREEN-V2-*-01` 播放片头。丈夫仍锁着，不能先开始。
3. 片头停在妻子正视镜头的画面；陪看人宣读“仅本次、仅此盘、结束后本人复锁并接受核验”。
4. 丈夫明确接受，由他本人解锁；陪看人只交出钥匙／解除控制，不碰他的身体。
5. 解锁动作完成后才进入 `SCREEN-V2-*-02`。

### 播放中

| 屏幕段 | 丈夫的现场进度 | 陪看人的功能 |
|---|---|---|
| 02 | 开始，动作克制，视线固定在屏幕 | 保持一臂距离，确认对象仍是屏幕里的妻子 |
| 03 | 连续动作，不得把主动参与当成跳切 | 只回答母带来源，不替妻子解释感受 |
| 04 | 明显加快，第一次性交证据触发认知反应 | 安静见证，不与丈夫接触 |
| 05 | 在换位段短暂调整呼吸；不能退出播放状态 | 可在这里揭示另一户也在进行，但不报告另一户不可见细节 |
| 06 | 第一轮高点后继续，丈夫的动作随之升档 | 可贴耳低声提醒，双手始终留在自己身上／设备上 |
| 07 | 保持后半轮连续，不让现场反应盖过屏幕 | 退回原距离，把注意力还给母带 |
| 08 | 峰值前短暂停顿，明确这是妻子主动选择继续 | 不催促、不替任何人做身体动作 |
| 09 | 接近完成但暂不收口 | 提醒他看完，不允许把视线转向陪看人 |
| 10 | 妻子留话并停录的同时完成 | 只见证，不触碰，不把完成对象改成自己 |

### 播放后

1. 平板显示停止录制／播放结束，丈夫先完成清理。
2. 丈夫本人重新戴好贞操带并锁定；陪看人不上手。
3. 丈夫整理衣物后，陪看人目视核验并收回钥匙／控制权。
4. 102 交书面回执或空白带，保留“下次仍由沈静仪决定”；202 交住户钥匙，确认“仅此一次”。
5. 陪看人带设备离开，丈夫留在本户；两路随后回到 302 收口。

## 五、贞操锁是强制生命周期，不是插图

正式状态顺序固定为：

`locked → opening-playing-locked → authorized → self-unlocked → full-tape-playing → husband-completed → self-relocked → visually-verified → settled`

硬门：

- 没有播放 01 与明确接受，不得进入 `self-unlocked`。
- 没有完成本人解锁，不得播放 02，也不得产生丈夫的身体反应进度。
- 没有顺序播放 02…09，不得直接触发 10 或 `husband-completed`。
- 没有播放 10，不得把丈夫的完成标记为本事件完成。
- 没有 `self-relocked` 与 `visually-verified`，不得发放长期结算、回执或钥匙结果。
- 陪看人从头到尾不替丈夫解锁、复锁或完成任何身体动作。

中断处理：若播放失败、被取消或场景在解锁后异常退出，先冻结播放和结算，进入“待复锁”收束；完成本人复锁与核验后才能离场。回档只恢复已提交的最后一个硬状态，不以单张 CG 已显示来反推授权或完成。

## 六、两户的同构与差异

### 102 · 顾国栋观看沈静仪盘

- 他在片头阶段已经期待继续，接受授权较快。
- 十拍的冲击重点是沈静仪始终知道镜头存在，并把完整过程主动留给他看。
- 结束交回的是回执／空白带；这次完成只建立“观众席”，下一次仍须沈静仪重新授权。

### 202 · 何俊生观看周小满盘

- 他在片头阶段仍想质问，必须听完周小满自己的开场与条件后才明确接受。
- 十拍的冲击重点是周小满从确认镜头到主动掌控并亲手保留，无法解释成别人替她剪出的材料。
- 结束交出住户钥匙；这次不产生下一盘权限，也不自动进入开放关系。

两户可以在现实时间上错开，但每户内部不得打乱十拍与锁状态顺序。

## 七、提供方与交付状态

### 平板母带优先级

- 普通片头 `TAPE-*-01`：内置模型；已完成。
- 成人源镜 `TAPE-*-02…10`：只使用本地模型。
- 含成人源镜的 `SCREEN-V2-*`：只用已审核源镜做本地确定性合成，不让任何模型重画屏幕内容。
- 任一画面只要屏幕或现场有成人尺度，整张按成人级处理；普通外框不能降低提供方等级。

正式平板轨道已交付：每户 `01…10`，共二十张 `SCREEN-V2-*`。其中每户 `01 / 02 / 06 / 09 / 10` 从已验收试播资产按字节继承审核，其余十张新增源镜与合成均已逐项完成预检、原图审核、失败证据保留、去重与登记。

### 外层必须进入正式生产的镜头族

每户至少覆盖：锁仍锁着、宣读授权、本人解锁、观看初段、观看升档、本人完成、本人复锁、目视核验、回执／钥匙交接。授权、衣物整理后的核验与交接在画面不含成人区域时用内置模型；可见贞操带、解锁、自慰、完成、复锁或可见成人平板内容全部使用本地流程。

## 八、切换门槛

以下条件全部满足前，现有五格消费者保持试播状态：

1. 二十个 `TAPE-*` 源节点都有可追溯状态，十个新增成人源镜全部正式验收。
2. 二十张 `SCREEN-V2-*` 全部完成确定性合成和原图审核。
3. 锁定、授权、本人解锁、本人复锁、核验与结算镜头均已生产或由明确的现场演出替代，不能再只存在于文字说明。
4. 新载荷契约能区分 v1 五格试播与 v2 十拍正式轨道；旧存档和旧调用不会把 v1 第三格误当成 v2 第三拍。
5. 顺序、失败、取消、回档、重复事件与两户并发测试通过。
6. 完成专项测试、相关回归、定向静态检查及隔离生产构建，正式 `dist/**` 前后不变。

以上六项均已满足，完整路线状态现为“可交付”：正式 v2 轨道进入版本隔离消费者，旧无版本五格试播与已经运行中的旧 `录像带` 特殊场景仍保留且互不串线；隔离生产构建只写入 `.codex-tmp/vtr-production-build`，正式 `dist/**` 与仓库自动生成文件前后不变。

### 正式运行时落地

- 迁移兼容存档在管理员室使用已持有的旧录像带时，先建立唯一的 `_录像带双承接` v2 场次，成功后才消耗道具；新档不会重新从商店获得这条旧商品线，也不会因此越过尚未实现的未来共享结局前置。
- 正式特殊场景不再复用旧 `录像带` 三拍状态，而是依次运行 `102-1…3 → 202-1…3` 六段正文。六段原子提交 `8 / 6 / 4 / 8 / 6 / 6` 张画面，共 38 张，完整覆盖二十张平板与十八张外层。
- 每段先持久化硬状态，再广播该段 CG。客户端把同段多张画面加入去重 FIFO，逐张显示剩余数量；关闭或单张加载失败只推进显示队列，不反写剧情状态。
- 两户各自推进到本人复锁与无接触目视核验后，最后一段才提交两户交接镜头并登记 `录像带结局`；旧完成标识 `录像带` 只属于旧路线。
