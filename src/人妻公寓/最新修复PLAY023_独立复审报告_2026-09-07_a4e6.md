## 四、新增语义回归

### 1. 逗号前只有父亲主语与话题时，后半句丢掉主语

例句：**父亲对我们的真实关系，已经知道了。**

正确结果：识别为父亲已知。修前：识别成功。修后：返回未识别；实际私人验收及数个群验收放行。

原因：`本句父亲主体` 以 false 初始化，只在知情谓语循环内赋值。逗号前没有“知道／清楚”等谓语时，即使存在明确父亲主语，也不会保留给下一分句。后一分句有话题承接，却没有父亲主体承接。

同族另复现“你爸对我们的真实关系，早就知道了”“父亲对我们的隐秘关系，已经知情了”“父亲对我们的真实关系，完全清楚”。对应否定及普通交接对照仍正常。

这是普通中文停顿句式，不依赖坏存档、并发竞态或特殊宿主环境。

### 2. “也”等副词被当作切分点，连同真正主语一起删除

例句：**我知道你爸也知道我们的真实关系。**

正确结果：识别内层父亲知情。修前：识别成功。修后：漏判。

原因：当前 `前段.replace(/^[\s\S]*(?:但是|不过|而且|并且|但|却|并|也)/u, '')` 贪婪删除到“也”为止；内层谓语前的“你爸也”整体被删除。外层“我”又正确地被认作母亲，因此最后反而找不到父亲。

同族“我清楚父亲其实也知道……”“我明白爸爸也清楚……”同样失败。不是简单补上一个词就能证明主谓归属正确。

### 3. 引述否定只看尾部，双重否定被错当成否认说过

例句：**我并非没有说过“父亲已经知道我们的真实关系”。**

当前既有契约是：普通引号和普通转述不自动豁免知情断言；只有明确否认／劝止的引述才特殊处理。在这一契约下，该句不能被当成“我没有说过”。

修前识别，修后漏判。`否认引述` 匹配前文末尾“没有说过”，没有检查更外层“并非”；随后整段引用被替换为空格。“我不是没说过……”同样复现。

本项结论针对产品既有引述契约，不把“有人说过某句话”无条件解释为现实中该命题一定为真。

### 4. 整体抹掉被否认的引用，破坏后文明确断言的指代和对象

例句：**“父亲不知道我们的真实关系”是假的，他其实早就知道了。**

正确结果：识别后半句父亲已经知情。修前：识别成功。修后：漏判。

原因：前半引用被完全空格化，关系话题和父亲指代依据一起丢掉；后半句“他……知道了”不再包含完整对象，所以不签发知情。即使后半句再次写“父亲早就知道了”，也会因对象丢失而失败。后半句重新完整重复关系对象的对照能被识别，说明问题位于信息丢失与承接，不是所有引用都失效。

父亲第一人称的同类句也有问题。但弯引号版本会被上游 `安全父亲台词` 提前拒绝，不能据此宣称已进入父亲通话。实际追加测试发现，角引号 `「」` 和 `『』` 版本能通过安全格式检查，并继续被模式验收错误放行。

## 五、新增严格类型错误

当前位置：`父亲关系知情.ts:49:13`，变量 `父亲承接`。

错误：`TS7022: '父亲承接' implicitly has type 'any' because it does not have a type annotation and is referenced directly or indirectly in its own initializer.`

对照方式：同一个本地 TypeScript `6.0.0-dev.20250807`、Node `v24.12.0`，继承当前 `tsconfig.json` 的 strict、目标、模块、bundler、未使用检查和返回值检查；只检查这个无导入纯模块，不引入全仓其他项目的环境类型，不输出文件。

结果：**HEAD 修前 0 个诊断；当前补丁 1 个诊断，正是 TS7022。**

这是循环状态推断新增问题，不等同于 JavaScript 运行时崩溃。可通过明确布尔类型或合理拆开循环推断依赖处理，但本轮不改产品。旧专项使用 `ts-node/register/transpile-only`，其运行通过不能替代严格类型验收；ESLint 无报错也不能抵消 TS7022。

## 六、既有语义残余：不是全部算在最新补丁头上

### 1. 引号后的正常标点使辟谣失效

`“父亲已经知道我们的真实关系”这句话是假的。` 当前能正确允许；仅增加普通逗号成为 `“父亲已经知道我们的真实关系”，这句话是假的。`，就再次被误拒。

`后文` 仅 trimStart，辟谣正则又从开头锚定，不接受该逗号／句号。三个变体在修前和修后均失败，属于修复覆盖不完整，不是本轮新造出的三个 BUG。

### 2. “父亲的朋友”仍被当成父亲本人

`父亲的朋友知道我们的真实关系。`、`父亲的同事已经知道我们的真实关系。` 等仍因 `父亲称呼.test(之前)` 命中定语而被算到父亲头上。比较结构“我比父亲更清楚……”也不能单凭出现父亲称呼就认定父亲获得该事实。

本项指出主体归属错误，不自动授予其他角色任何尚未取得的知情资格。

### 3. 知情对象仍未完全绑定目标事实

`父亲假装不知道房租已经交接。` 被当成该线路的隐秘关系知情，原因是“装作不知”可以绕过对象匹配。

`父亲知道房东和租客的真实关系。` 也会因泛化的“真实关系”命中，不检查被谈论的人物是否为目标对象。明确工作关系的对照正常。

这两种情况均是修前就存在的对象边界问题。不得通过禁止普通房租交接聊天来掩盖。

### 4. 父亲省略主语后的程度副词仍靠窄白名单

`我对你和你妈的真实关系，十分清楚。` 当前漏判；它能通过真实父亲台词格式检查，并被结局后家常模式允许。该例修前同样失败。

不能只增加“十分”后就宣称解决全部中文承接；应与本轮主语生命周期一起处理。
