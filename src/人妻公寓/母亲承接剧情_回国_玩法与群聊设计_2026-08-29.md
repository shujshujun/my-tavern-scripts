## 一、设计前提

《回国》开启时，玩家不是刚开始学会管理公寓，也不是刚与母亲越界。

硬前提为：

1. 母亲已经进入第五阶段“归属”；
2. 母亲专属哺育癖已经完成开幕与后效；
3. 母亲已经主动选择与玩家延续特殊关系，不再用母亲职责撤回自己的欲望；
4. 第五阶段关系权限已经来到最高档，玩家可能已经体验过复杂、深入且多样的成人玩法；
5. 玩家经营已经达到父亲现有评价中的“满意”档；
6. 当前没有通牒、重大逾期、上交缺口或等待处理的紧急父亲电话；
7. 公寓本来就在稳定运行，不应为了剧情强行制造严重故障。

因此，《回国》不能重新演：

- 母亲第一次相信玩家；
- 母亲第一次知道玩家会管理公寓；
- 玩家重新把经营刷到合格；
- 母亲因父亲回国突然退回普通母子日常；
- 两人因害怕父亲而否定已经发生的关系；
- 把父亲写成查手机、查朋友圈或逐户审问的调查者。

## 二、承接剧情真正要完成的变化

第五阶段的母亲已经在私人关系上选择玩家，但仍可能保留两种长期习惯：

1. 把玩家当作需要自己保护、需要自己向父亲圆场的孩子；
2. 把父亲当作公寓与302最终会重新回到的旧秩序。

父亲宣布回国以后，这两种习惯第一次同时受到现实挑战。

《回国》的核心变化不是：

```text
母亲从不相信玩家 → 相信玩家会管楼
```

而是：

```text
母亲私下早已选择玩家
→ 父亲回国使旧家庭与旧管理关系可能重新回流
→ 母亲先本能地想替玩家遮掩私密证据、替玩家准备父亲审核
→ 完美经营让她找不到任何需要替玩家圆场的地方
→ 她停止代替玩家处理楼务
→ 她进入姐妹茶话会，公开自己的特殊关系并协调其他关系成员
→ 她在外部人员面前维护玩家的现行管理
→ 她最终亲自告诉父亲：这里不需要他回来收尾
```

完成后的母亲不再只是保护儿子的母亲，而是：

- 私下承认自己与玩家的特殊关系；
- 在姐妹群中成为长期知情成员；
- 在楼务上把玩家视为能够独立承担父亲位置的成年人；
- 面对父亲回国时，不撤回关系，也不替玩家重新接受一次考试。

## 三、开放条件、商店剧情道具与开始方式

### 3.1 开放条件

建议只在以下条件同时成立后建立《回国》：

```text
系统._母亲入列 === true
302母亲当前阶段 >= 5
母亲哺育癖开幕与后效已完成
当前胜任度达到本难度“满意”档
系统._通牒期 < 0
没有逾期的重要／紧急楼务
本期实际上交 >= 本期应上交
当前没有亲密、特殊场景、场景剧情、父亲电话或医院硬锁
系统._已完成特殊场景不包含“回国”与“双重继承”
```

《回国》不是先开放一张缺项清单，再让玩家刷到通过。经营条件属于剧情道具的上架前提。

### 3.2 商店剧情道具：公寓经营归档册

建议名称：

```text
公寓经营归档册
```

建议分类：`特殊场景`。建议价格：`480`，最终仍可按后期现金曲线调参。

道具描述方向：

> 一册用于把近几期收支、维修、住户与上交记录整理成正式归档的硬壳册。不是临时做给谁看的报表，只有公寓已经稳定运行时，才有东西值得归档。

它不是“回国通知书”，商品名称和描述都不能提前剧透父亲一定回国。玩家只知道这是一件后期经营剧情道具。

道具只在3.1全部条件满足时上架。购买后进入背包，但购买本身不推进世界状态，也不触发父亲消息。

### 3.3 使用归档册：管理员室两拍演绎

归档册只能在`管理员室`、当前没有电话／亲密／特殊场景／场景剧情和医院硬锁时使用。

玩家从背包点击使用后，进入两拍连续演绎：

#### 第1拍：铺开真实经营记录

脚本提供当前真实经营摘要，模型只负责演出玩家把近几期记录、维修回执、住户名单与上交凭据放入归档册的现场。

本拍不能：

- 编造不存在的经营数字；
- 让父亲已经看到材料；
- 提前出现回国消息；
- 替玩家写长篇内心独白；
- 宣布管理权已经交接。

正文停在归档册已经整理完整、尚未提交的位置，等待玩家自然回应。

#### 第2拍：通过既有经营汇报渠道提交

先承接玩家上一轮言行，再演出玩家通过父亲既有的经营汇报渠道提交归档摘要。人物可以确认“已经发出”，不能描写父亲即时已读或即时回复。

只有第2拍有效正文成功落库后：

```text
移除：公寓经营归档册
回国:经营归档已提交
路线阶段：待父亲回信
父亲最早回信日 = 当前游戏日 + 1
```

生成失败、取消、刷新、错场或世界时间变化时，道具不消耗，父亲回信也不排队。

### 3.4 父亲回国微信必须自然延迟

使用归档册后不能在同一点击、同一正文楼或紧接着的手机刷新里收到父亲消息。

建议调度：

```text
至少跨过一个完整游戏日
AND
当前达到下一次安全的下午或傍晚
AND
没有父亲活动电话、亲密、特殊场景、场景剧情或医院硬锁
```

最快情况下，玩家在第D日下午使用归档册，父亲也只能在第D+1日下午或傍晚发送消息。若当时被强剧情占用，则顺延到下一个安全时段。

父亲消息只表达：

- 他已经看完玩家提交的经营归档；
- 材料让他确认公寓长期稳定，而不是临时做出一张漂亮报表；
- 海外项目准备收尾；
- 他开始计划回国；
- 机票尚未最终确定；
- 时间大约在一周以后；
- 楼里暂时照常运行。

父亲不能在这条微信里提前完成交接，也不能因为看见归档就立刻出现在地图。

消息到达后才正式登记承接任务《回国》，路线进入`待读回国消息`。

### 3.5 302两拍：和母亲读完回国消息

父亲消息到达后，玩家回到302，出现瓷砖：

```text
把父亲的回国消息给母亲看
```

本节点两拍：

1. 母亲读完消息，先面对父亲即将回来的现实，同时注意302与两人关系已经留下的真实变化；
2. 承接玩家回应后，母亲明确区分“需要隐藏父亲不能看见的证据”与“不会撤回已经作出的关系选择”。

消息最好落在已经能够承认第五阶段关系的302生活现场中。可以承接真实近期私密状态，但只能读取可靠记录，不得为了表现“玩得很花”而编造玩家没有经历过的行为。

第2拍成功后：

```text
回国:父亲已通知回国
回国:母亲拒绝撤回关系
路线阶段：待收纳
```

同时才在商店上架后续物理道具`带锁私人物件箱`。

## 四、完整玩家玩法链

```text
商店购买“公寓经营归档册”
→ 玩家在管理员室使用，完成2拍经营归档与提交
→ 至少等待一个完整游戏日
→ 父亲在后续安全下午／傍晚发来回国微信
→ 302完成2拍共同读取与关系确认
→ 商店解锁“带锁私人物件箱”
→ 302清点并封存不能留在明面的私密证据
→ 玩家把上锁箱带到管理员室锁柜
→ 次日母亲到管理员室，准备替玩家整理父亲可能检查的经营材料
→ 真实经营记录证明没有需要母亲圆场的缺口
→ 玩家在302把姐妹茶话会展示给母亲并邀请她入群
→ 特殊茶话会：入群与改名系统提示、群成员先起哄、母亲再坦白、逐人调侃、自然转入父亲回国正事
→ 正事交代完成后，群聊立即恢复普通运行，母亲永久留群
→ 其他角色按性格陆续私聊玩家追问母亲关系
→ 父亲旧维修委托在大堂与玩家现行管理发生重复
→ 母亲在外部人员面前明确支持按玩家的管理执行
→ 深夜母亲以伴侣而非保护者的身份与玩家确认立场
→ 父亲询问是否还有事情等他回来收尾
→ 母亲亲自回复，父亲改变回国目的并确定日期
→ 《回国》完成，进入“待父亲回楼”
```

最快约七个完整游戏日；遇到医院、其他强剧情、错过安全时段或玩家长聊时自然延长。节点之间不锁地图，玩家可以继续经营、互动、约会与使用第五阶段普通玩法。

### 4.2 茶话会可变回合的计算口径

茶话会不做固定总轮数，但存在最低任务覆盖：

```text
0个AI回合：微信居中显示“邀请入群”和“修改群名”两条确定性系统提示
1回合：至少`min(2，N)`名其他成员对新群名作出反应，母亲带笑回一句；不得提前坦白或逐人调侃
1回合：玩家第一次插话后，母亲承接当前气口并自然坦白
N回合：逐个覆盖N名当前其他成员的点评与回应主题
1回合：母亲在回应当前话题后自然带出父亲回国
1回合：成员围绕回国现实分寸作出回应（成员多时可拆为2批）
1回合：母亲自然表示正事已交代完，群聊继续
```

因此最低约为`5＋N`个群生成回合；当前成员较多、单批无法覆盖全部回应时自然增加。改名反应首拍由玩家点击邀请这一真实动作直接触发，不要求玩家再发送一句无意义的话；生成期间手机显示“群成员输入中”并暂时锁住输入框。首拍成功落库后重新开放输入，从母亲坦白开始由玩家真实群消息推动。玩家插话与自由延伸不设上限，也不会重置已完成任务。

## 五、道具与地图瓷砖

### 5.1 特殊道具：带锁私人物件箱

父亲微信到达后，商店“特殊场景”页才上架：

```text
带锁私人物件箱
```

道具只承担真实物件与经济参与感，不代表购买剧情资格。

建议设定：

- 外表普通，不像剧情机关；
- 内部分隔可存放成人用品、特殊服饰、记录卡及其他私密物件；
- 两把钥匙分别由母亲与玩家保管；
- 价格不宜成为后期玩家的实质卡点，最终数值另行调参。

### 5.2 302瓷砖：和母亲清点需要收起来的东西

出现条件：

- 路线阶段为`待收纳`；
- 玩家持有带锁私人物件箱；
- 母亲在302；
- 当前为安全傍晚或晚上；
- 当前没有亲密或其他强剧情。

本节点是三拍连续剧情：

1. 打开箱子，根据实际存档与近期可靠记忆确认可能暴露关系的物件或痕迹；
2. 由母亲决定哪些必须收起、哪些普通生活物件不需要移动、哪些属于玩家在302的正常位置不能被清空；
3. 母亲亲自封箱、上锁，并把其中一把钥匙交给玩家。

AI负责具体演出，脚本只在三拍有效正文全部成功后：

```text
移除：带锁私人物件箱
获得：私人物件箱（已上锁）
路线阶段：待存箱
```

### 5.3 管理员室瓷砖：把私人物件箱锁进柜底

这是确定性物理动作，不调用AI决定是否成功。

完成后：

- 上锁箱从背包移除；
- 管理员室锁柜增加环境差分；
- 普通送礼、丢弃和背包整理不能吞掉它；
- 写入`回国:私密证据已安全收纳`；
- 路线进入`待看记录`，最早次日继续。

### 5.4 管理员室瓷砖：和母亲看一次平常的管理记录

至少经过一个完整游戏日后出现。

母亲带着过去替父亲整理材料的习惯进入管理员室，准备替玩家补漏。界面可以同步显示一张只读运行摘要，但不能做成缺项任务表。

本节点固定三拍：

1. 母亲带着纸笔或旧习惯进入管理员室，提出帮玩家把父亲可能问的内容重新理一遍；
2. 承接玩家回应，母亲与玩家一起查看真实运行摘要，逐渐发现所有项目都已有稳定经办与结果；
3. 再承接玩家回应，由母亲确认自己找不到需要替玩家补救或向父亲圆场的经营缺口。

摘要只读取真实状态：

- 当前胜任度；
- 最近稳定经营期；
- 本期收支与上交；
- 当前没有重大逾期；
- 当前入住户；
- 最近完成的真实楼务；
- 父亲多久没有亲自经办；
- 母亲过去是否真实使用过圆场机制。

本节点的关系事实是：母亲最终找不到需要自己替玩家向父亲解释的经营缺口。

成功后写入：

```text
回国:母亲确认玩家无需经营圆场
路线阶段：待姐妹茶话会
```

## 六、姐妹茶话会：母亲入群

### 6.1 地图入口

管理员室记录节点结束后的下一个安全302时段，出现瓷砖：

```text
把姐妹茶话会的群聊给母亲看
```

母亲看见的只有当前群名与真实成员列表；微信新成员不能倒读旧消息，所以她不能凭空看见入群前完整聊天。

地图现场固定两拍：

1. 玩家把群成员页给母亲看，她只根据当前成员名单与已经在现实中看见的关系痕迹作出反应；
2. 承接玩家回应，母亲自己提出加入，理由是由她一次说明父亲回国，比玩家逐个提醒更自然。

第2拍有效正文成功后，玩家通过手机执行正常动作：

```text
邀请母亲加入群聊
```

群内分两次显示仿照现实微信的居中系统提示；它们没有头像、没有左右气泡，也不是任何角色的普通发言：

```text
立即：你邀请“母亲”加入了群聊
约5秒后：“母亲”修改群名为“{玩家角色名}人妻后宫群”
```

第一条出现后，群聊顶部仍保持旧名“姐妹茶话会”。约5秒的停顿里，输入框暂时锁定，状态显示“母亲正在修改群名”；第二条系统提示真正落库时，顶部标题和会话列表才同步切换为新群名。角色在改名提示出现以前不得起哄、回应、坦白或进入后续调侃。

这五秒只是一段手机界面演出，不推进游戏世界时段，也不在MVU保存队列里原地等待。刷新、回档或切分支使等待失效时，下一次恢复会重新等待完整约5秒，绝不把迟到改名写进错误时间线。

`{玩家角色名}`不交给AI猜，也不从SQLite人物记忆里反推。邀请动作发生时，脚本直接读取酒馆当前 Persona 的玩家名（`SillyTavern.name1`，即`{{user}}`展开后的名字），先冻结本次昵称；约5秒后再随改名系统消息写进当前微信时间线。此后界面标题与群聊提示都读取这条带硬事件键的真实记录：刷新会保留，回档／切分支会随消息一起撤回；玩家以后修改 Persona，也不会倒改母亲当时已经取好的群名。

改名发生在母亲坦白和逐人调侃之前。只有改名系统提示成功落库后，才自动触发茶话会第1个AI节拍：若当前有1名其他成员，她必须回应；若有2名以上，至少2名不同成员必须按各自性格对新群名起哄、错愕、吐槽或反问，随后母亲带笑回一句。该节拍不允许提前坦白关系、逐人揭短或提父亲回国；验收不足会整批放弃，不会假装成员已经反应过。

首拍结束后才开放玩家输入。玩家的下一条真实群消息进入第2节拍，由母亲承接刚才的群名气口并坦白自己的关系位置。这样“人妻后宫群”先成为全群看得见、会引发反应的现实动作，而不是和坦白、调侃挤在一批台词里。AI不能伪造第二次改名、把改名交给其他角色，或把它写成没有真实界面变化的口头玩笑。

不向玩家展示“主母”、管理员、主持人或其他做作称号。她在群里的地位只通过发言方式与其他角色的反应自然表现。

### 6.2 特殊入群资格

当前普通姐妹群成员由阶段与雌竞资格派生，302母亲默认被排除。本剧情不得给母亲增加雌竞属性。

需要增加独立资格：

```text
回国:母亲已加入姐妹茶话会
```

普通群成员最终为：

```text
普通阶段3+姐妹群成员
＋
完成《回国》入群的母亲
```

母亲长期留群，但不进入雌竞火气、争夺排名或普通争宠计算。

### 6.3 没有其他合资格角色时

母亲线不能被其他角色进度永久卡住。

- 至少有一名其他阶段3+关系成员：正常建立群剧情；母亲加入后达到两人以上即可形成茶话会。
- 没有任何其他合资格成员：登记`回国:当前无需群提醒`，保留母亲未来加入资格，路线直接进入下一节点。

## 七、《回国茶话会》不是固定对白

### 7.1 任务调度而非固定台词

产品代码只给模型本轮演出任务，不保存母亲或其他角色必须逐字说出的对白。

任务序列为：

```text
玩家邀请母亲，微信依次显示入群与改名系统提示
→ 第1节拍自动生成：至少一至两名其他成员对“{玩家角色名}人妻后宫群”起哄，母亲回一句
→ 第2节拍由玩家群消息触发：母亲自然坦白自己与玩家已经越过普通母子关系
→ 母亲根据真实进度逐个调侃当前成员
→ 被点评成员按自身性格回应，玩家可以自由插话
→ 所有成员完成点评与回应后，母亲自然转入父亲回国
→ 群成员讨论父亲实际在楼时需要注意的普通现实分寸
→ 母亲自然表示正事已经交代完，不关闭群聊
```

每个任务只有在生成结果通过人物、隐私、越拍与文本安全验收，并成功写入当前微信时间线后，脚本才登记完成。AI不能自行修改路线阶段。

### 7.2 临时角色上下文窗口

茶话会开始时，为母亲冻结当前成员的临时画像：

- 当前阶段；
- 已完成阶段节点；
- 已完成招牌性癖；
- 已完成承接与特殊场景；
- 最近可靠私密摘要；
- 已在姐妹群公开的事实；
- 当前与玩家的关系方向；
- 必要的孕产与医院状态。

允许母亲使用这些事实进行成熟、带笑、符合她人设的调侃。

禁止提供或泄露：

- 未完成的未来剧情；
- 会破坏其他丈夫路线的隐秘证据；
- 未公开的胎儿父亲结论；
- 数据库推测而非真实落库的内容；
- 玩家没有经历过的成人玩法；
- 当前角色无法承接的精确私密细节。

母亲在群里实际说出口的内容从此成为群内共同知识；未说出口的后台画像在特殊茶话会结束后销毁。

### 7.3 调侃必须逐人覆盖但不写成系统播报

内部维护：

```text
成员快照
群名反应已完成
已点评成员
已回应点评成员
```

母亲每次只重点带出一名角色，使用该角色已经成立的关系主题和近期事实。模型决定具体措辞，其他角色可以尴尬、反驳、反过来调侃母亲或玩家。

母亲不是群规训者，也不能把所有人的反应写成统一服从。

## 八、茶话会如何自然转入正事并结束特殊状态

### 8.1 不给玩家“让母亲说正事”按钮

内部判断同时满足：

```text
母亲已坦白
全部当前成员都已被点评
全部被点评成员至少回应一次
当前没有待生成消息
```

下一轮模型任务自动变为：

```text
先回应玩家当前仍在延伸的群聊内容，
然后由母亲自然结束逐人玩笑，带出父亲大约一周后回国的正事。
```

玩家即使一直聊天，也不会卡死。母亲会先承接当前话题，再自然转入正事；玩家看不到阶段切换。

### 8.2 正事只处理现实分寸

母亲只需要让大家知道：

- 父亲大约什么时候回来；
- 父亲真实在楼时，公共区域保持正常住户与管理员关系；
- 去302前最好先正常说一声，避免正好撞见；
- 其他时候生活、群聊、私聊和邀约照常，不需要集体躲避或中断关系。

明确禁止把剧情写成反侦查：

- 不统一静音手机；
- 不删除朋友圈；
- 不清理聊天记录；
- 不暂停全部邀约；
- 不统一虚假口径；
- 不把父亲写成警察式调查者。

### 8.3 “结束”只代表正事交代完

内部要求：

```text
母亲已经说明父亲回国
每名当前群成员至少回应一次
玩家在本场群聊中至少发言一次
母亲的正事收束任务成功落库
当前没有待生成消息
```

最后一个特殊任务只要求母亲自然表达：事情只是提前告知，大家无需现在就紧张，群聊可以继续。

消息成功保存后：

```text
回国茶话会状态 = 已完成
```

同一个群不会关闭，也不弹“会议结束”。下一条玩家消息立即走普通姐妹群运行逻辑。

## 九、茶话会完成后的普通群逻辑

### 9.1 母亲永久留群

茶话会结束后，母亲成为普通可发言成员，但使用特殊方向：

- 知道当前群成员与玩家关系不普通；
- 只承接群里已经公开的事实与本场结构摘要；
- 不再读取其他角色完整后台进度；
- 可以参与生活、孕产、关系和楼内话题；
- 可以调侃玩家与其他角色；
- 不参与普通雌竞；
- 不争夺次数、排名或玩家关注；
- 发生冲突时更倾向于缓和、换角度或让双方把话说清；
- 不必每次拌嘴都出来训话，也不能成为群里的纪律委员。

母亲平息冲突应来自人物本身：有时拿玩家开玩笑让双方下台，有时指出双方在气同一件事，有时只劝一句，有时让其他人自行解决。

### 9.2 群聊长时上下文

特殊茶话会允许玩家长聊。内部保留结构化摘要：

```text
母亲已坦白的关系方向
逐角色点评与回应摘要
玩家在群中的主要立场
父亲回国事实
群成员对正事的回应
尚未解决的问题
```

自由聊天可以按现有手机摘要规则压缩，但上述硬节点不能被截断或重复生成。

## 十、其他角色的私聊后效

茶话会正事收束后，根据当前真实群成员建立非阻塞私聊队列。

可能主题包括：

- 想确认玩家与母亲从什么时候开始；
- 对母亲主动入群感到意外；
- 询问父亲是否知道；
- 对母亲知道自己的私密经历感到尴尬；
- 拿玩家与母亲的特殊关系开玩笑；
- 重新确认自己与玩家的关系位置；
- 好奇母亲私下与群里表现是否相同；
- 询问父亲真正回楼时的普通相处方式。

差分原则：

- 不要求每名角色立刻私聊；
- 外向、好奇的人可以较早发来；
- 克制或羞怯的人可以延后，或在后续正常话题中绕到这件事；
- 每名角色只读取本人状态、茶话会结构摘要、母亲对本人说过的话和玩家实际群聊回应；
- 不读取其他成员完整临时画像。

这些私聊属于可选世界余波：

- 生成失败不回滚茶话会；
- 玩家不回复不阻塞《回国》；
- 回复进入各自正常私聊记忆；
- 不重复触发。

## 十一、后续地图节点

### 11.1 大堂瓷砖：接待父亲联系的旧维修人员

茶话会完成后的下一个安全下午，父亲按过去习惯联系的旧维修人员来到大堂。

旧委托应与玩家当前真实管理发生“重复”，而不是凭空发现故障，例如：

- 重复检查已完成保养的设施；
- 使用已经失效的旧名单或旧时间；
- 绕过现行登记方式；
- 形成重复支出或打乱住户安排。

玩家点击瓷砖时，硬动作就是按现行登记重新确认委托。

本节点固定三拍：

1. 旧维修人员说明父亲从国外留下的安排，并自然暴露它与现行记录发生重复；
2. 承接玩家回应，由维修人员把实际决定权交回当前管理员，确认哪些内容应该取消、保留或改按现行登记；
3. 再承接玩家回应，母亲在外部人员面前明确支持继续按玩家的管理方式执行，并收束父亲回国不等于重新换管理员的现实口径。

成功后写入：

```text
回国:父亲旧委托已被现行管理接管
回国:母亲已公开确认玩家为现任管理员
```

### 11.2 管理员室深夜瓷砖：让她进来

到达后续安全深夜，母亲主动进入管理员室。

这不是阶段3或阶段4的第一次夜访，也不规定新的成人动作。

本节点固定三拍：

1. 母亲以没有家务借口的第五阶段日常进入管理员室，先承认自己仍本能地想替玩家找缺口、替玩家面对父亲；
2. 承接玩家回应，她把管理员室经营记录、大堂旧委托和姐妹群经历联系起来，确认玩家已经不需要自己圆场；
3. 再承接玩家回应，她明确区分“隐藏父亲不能看见的证据”与“撤回已经作出的关系选择”，并以共同承担后果的伴侣位置收束本节点。

剧情任务只负责：

- 她承认自己仍本能地想替玩家找缺口、替玩家面对父亲；
- 她发现玩家已经不需要自己圆场；
- 她明确区分“隐藏父亲不能看见的证据”与“撤回已经作出的关系选择”；
- 她以共同承担后果的伴侣位置面对玩家。

成功后普通第五阶段输入继续开放。玩家愿意亲近时，当前实际偏好、装载项目和最高阶段许可照常生效；不强制具体动作、尺度或回合数，也不把任何行为写成第一次。

### 11.3 302瓷砖：把父亲的消息递给母亲

父亲后续询问楼里是否还有事情等他回来处理。玩家回302后把消息递给母亲。

点击瓷砖后直接打开玩家与父亲的微信会话，并进入本场专属协同表现。父亲刚才询问“是否还有事情等他回来处理”的气泡已经位于左侧，使用父亲头像。

本节点不是普通正文，也不需要为母亲调用模型：

1. 玩家先从右侧自由回复父亲。玩家气泡始终使用主角头像和右侧样式；
2. 玩家消息成功落库后，脚本插入本路线第1个一次性母亲气泡，使用母亲头像和左侧样式；
3. 固定母亲气泡成功写入后，脚本提交“母亲已经回复父亲”的硬事实。

第1个母亲固定气泡当前建议为：

> 这里没有什么等你回来收尾。楼里的事情，现在都是他在管。你回来看看就好。

该气泡只出现一次，不因刷新、重开手机、重复点击瓷砖或玩家继续聊天而再次插入。

母亲使用自己的口吻向父亲确认：

- 公寓没有等待他回来收尾的经营缺口；
- 玩家已经建立自己的管理方式；
- 父亲回来可以看，但不需要远程重新安排；
- 正式回楼时应由玩家走在前面。

不把具体回复写成固定产品台词，只向父亲通话／微信模型提供任务、硬事实和语义边界。

母亲发送成功后，父亲不能在同一拍即时回复。至少跨过一个自然时段，并等待下一安全手机时点，才生成父亲确认机票的消息批次。

父亲有效回复后，302出现最后瓷砖：

```text
和母亲确认父亲的回国日
```

点击后再次打开同一父亲微信会话。父亲确认日期的左侧父亲头像气泡已经存在。

最后节点同样不调用母亲模型：

1. 玩家先从右侧自由回应父亲确定的日期、时段与回楼目的；
2. 玩家消息成功落库后，脚本插入本路线第2个一次性母亲气泡，使用母亲头像和左侧样式；
3. 固定母亲气泡成功写入后，脚本原子完成《回国》。

第2个母亲固定气泡当前建议为：

> 日子定了就好。你回来以后，让他走在前面。这里现在怎么运转，你跟着他看。

该气泡同样只出现一次。

### 11.4 父亲会话中的左右气泡语义

本场微信界面使用“玩家行为归属”而不是只按一对一账号方向排版：

```text
右侧＋主角头像：玩家亲自输入、玩家拥有的气泡
左侧＋父亲头像：父亲独立生成的气泡
左侧＋母亲头像：母亲独立生成的气泡
```

母亲气泡放在左侧的意义是：这句话由母亲自己说出，不是玩家代写，也不是玩家右侧气泡换了一个头像。

父亲与母亲都位于左侧时，靠各自头像区分说话人；消息顺序仍按真实生成顺序排列。玩家始终从右侧插入自己的回应，形成可读的三人协同会话。

母亲在父亲会话里总共只出现两次，而且两条内容都可以固定，因此不需要给整个微信消息模型增加通用`说话人`字段，也不需要重构普通私聊生成、摘要或会话成员系统。

建议使用两个稳定事件键：

```text
回国:父亲会话:母亲确认无需收尾
回国:父亲会话:母亲确认回国日
```

两条消息仍使用现有结构：

```text
会话: 父亲
发: 对方
文: 固定母亲词条
键: 对应的一次性事件键
```

父亲会话渲染时只做一个最小特判：消息键命中上述两个键时，把左侧默认父亲头像替换为母亲头像；其他所有父亲会话消息保持现状。

不把`母亲:`前缀塞进气泡正文，不增加第三参与者通用协议，不改普通消息左右逻辑。引用这两条特殊消息时，最小特判同样把发送者显示为母亲；两条消息都不是玩家消息，不能由玩家撤回。

## 十四、失败、暂停与回档纪律

- 购买公寓经营归档册不推进路线；只有在管理员室使用后的两拍全部成功，才消耗道具并排入父亲延迟回信。
- 父亲回国微信不得作为“使用归档册”的即时结果返回；至少跨过一个完整游戏日和下一安全下午／傍晚。
- 道具只在302封箱三拍全部成功后替换；失败、取消和刷新不消耗。
- 已上锁箱存入管理员室后，不因母亲医院状态变化而丢失。
- 医院、待产、生产、父亲活动电话或其他强剧情只暂停路线，不回退节点。
- 入群与改名两条系统提示不依赖AI；自动群名反应首拍生成失败时不登记完成，也不越过到母亲坦白。玩家下一条真实群消息可补跑同一首拍；已经成功落库并提交的改名反应、坦白或点评不重复。
- 群成员迁出、医院或时间线变化时，重新验证后续发言资格；已经发生的群消息不删除。
- 茶话会结束后，普通群聊和私聊余波失败都不得回滚承接硬状态。
- 大堂旧委托错过时段只顺延到下一个安全下午。
- 父亲回国具体日期只在最终确认后写入；玩家拖延承接不会让一个已经过去的日期强行触发。
- 同楼重掷、回档、切聊天和旧分支必须服从现有场景剧情事务与手机时间线租约，迟到回复不能推进新分支。
