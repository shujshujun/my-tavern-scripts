# 许曼君承接线：《分居》外层剧情草案（亲密玩法未完成）

> 日期：2026-08-31。性质：承接段细化提案，未实装，未生成素材。
> 当前已确认方向只有“201最终正式离婚”。《分居》名称、临时客房及下列具体桥段均为待讨论设计，不因本稿落盘变成已批准方案。
> 本稿细化V3的承接部分，不另立V4，也不扩写《离婚》结局。与V3有差异的地方单独列明，旧稿及用户现有修改均保留。
> 本轮最新反馈：用户否决用非露骨淡出替代游戏所要求的完整亲密场景。此前把六段外层演出称为“完整亲密主戏”的结论撤回。A4核心玩法未完成，本稿不能作为完整承接线或已满足用户要求的实现依据；不以助手可提供的内容范围改写游戏的设计标准。

## 1. 本线要完成的变化

**前面的许曼君已经能在没有债的时候来找玩家；这一次，她要为继续这段关系，亲自改变仍在维持的夫妻生活。**

玩家要玩到的不是替她签几张表，而是：帮她找到落脚处、把她的生活搬过去、在她的新住处相处，再与她一起面对赵国强。承接完成时，三人已经无法假装一切照旧，但婚姻尚未解除。

这条线有三层张力：

- 她很会安排别人的日子，却不习惯直接说自己想怎样生活。
- 赵国强不是突然变坏的障碍。他仍信任她，愿意为家庭做事；这些事实使她的选择更难，也使他的受伤成立。
- 玩家不能只享受他不在家的时间，又在他说破时退回“我只是管理员”。玩家的回答会影响三人怎样继续谈，不替任何人决定婚姻。

外层剧情建议保留**一个箱子、一次由她主动留人的客房邀约、一次没有替对方回答的会面**。客房场景应承担承接的情感中心，但其核心玩法目前缺失；之后的摊牌只能消费真实发生的关系事实。账本只在必要的旧账交接中出现，不再当整条线的主角。

| 人设：赵国强工资卡上交，在家搬水扛米；信任她管账 | 不新增赌博、外遇、藏钱或长期虐待；允许他真心提出修复 |
| 阶段线路：201后段已有主动邀约、唯一《肉偿账本》与“没有债也会来” | 不复演初见受助、第一次动心、第一次不标价，不重置唯一场景 |
| `角色结局占位.ts`：201当前是L5且阶段主题永久完成后可见的只读占位 | 本稿没有可购买的正式承接商品；未来替换占位，不并存两条同名入口 |
| `stageConfig.ts`：201丈夫当前复用标准作息，中午、下午、傍晚外出 | 第一场默认取可独处的傍晚，不把人设里的长途工作当作已有多日离楼状态 |

| `useRoomActions.ts`已有公寓外部入口，没有本线临时客房 | 客房是拟新增的路线地点，不宣称已有地图、住房或搬运系统支持 |

既有娘家问题只按当前存档已揭示范围承接。这里不重新调查四份线索，不新添欠款金额、债主或医疗急难，也不要求她在摊牌时复述整份隐藏人设。赵国强知道玩家关系与知道全部家庭账目是两件事。

### 相对V3的三项明确调整建议

1. A1不固定深夜：默认在她在201、丈夫确实外出的傍晚发生；若已有有效夜间外出才用夜景。
2. 原建议用六段外层演出和淡出代表A4完整亲密场景，已被用户否决并撤回。A4仅保留前后叙事建议，不用淡出或陪伴替代尚缺的核心玩法。
3. A5与A7之间用真实分开生活形成等待，缝纫设备允许提前搬妥；不为凑节点要求玩家再搬一次。

## 3. 入口、终点与整体节奏

**入口建议：**复用当前L5＋阶段主题永久完成的资格。玩家主动选择开始，先预约A1，不立即扣住宿费或移动人物。已有阶段历史影响她的措辞，旧档缺少细节记录时不虚构已完成某个细分桥段。

**本线独立终点：**许曼君真实搬出；新住处能生活、能继续处理工作；两人已明确当前关系；赵国强已知情，提出过修复；她明确拒绝恢复夫妻生活；夫妻双方当面同意进入办理。

到这里仅解锁独立结局。赵国强仍是丈夫，不是前夫；201尚未退居交接，没有离婚证明，不换锁，不删除丈夫。

```text
A1 201：她提出分开住
  ↓
A2 公寓外部／临时客房：看房、确认安排
  ↓
A3 201 → 客房：搬入，向丈夫告知分居
  ↓ 至少一个实际独住的夜晚
A4 客房：她主动留下玩家（核心玩法未设计，不能用淡出替代）
  ↓ 赴真实约定的会面；丈夫可以此前已经正常回楼
A5 201：当面说破关系，第一次谈话没有达成办理共识
  ↓ 至少一个完整游戏日；工作恢复、夫妻修复谈话
A6 大堂／客房：他提出挽回，她回应，仍回自己的住处
  ↓ A6结束后的下一个双方可赴约的白天
A7 公寓外部：双方同意办理，承接收口
```

建议是七个主场景、两段有生活变化的等待。轮数仅作表现预算，不按“发满几条消息”判成功；不固定总天数、不固定星期、不额外强制买丈夫外出道具。等待期间归还普通地图操作权。

## 4. 逐场剧情

### A1　201：《今晚先不替他安排》

**进入：**玩家按约到201，许曼君在场，赵国强实际外出；当前没有医院、生产或其他强剧情占用。默认傍晚。

**开场：**她原本在归拢晚上要做的事，话说到一半，仍习惯性给赵国强留出一份。她停下来，先问玩家今天能待多久，随后把问题改掉：以后是不是都要这样算着他不在的时间见面。

**三拍推进：**

1. 她说明自己已经想过先搬出去，不把决定包装成“最近手头紧”。
2. 玩家回应能实际帮哪一部分。她会问住在哪里、工作怎么办，也会纠正“以后什么都不用管”的空承诺。
3. 她明确自己会告诉赵国强、会亲自谈；今天先落实住处，不由玩家通知全楼。

台词方向：

> “账清了我还是会来，这话我说过。可我不能一边这么说，一边回去照旧过日子。”

这是承接既有关系的示例。缺少对应历史时换成“我们不能一直只挑他不在的时候见面”，不让旧档凭空经历过特定台词。

**玩家可做：**答应一起找住处；先问清她的安排；说明暂时无法继续。前两项都能进入准备，表达差异保留在本场；第三项暂停情侣路线，不扣款、不替她承诺继续隐瞒。

**收口：**她提出的分居意愿与双方实际接受的协助范围落地。地图仅增加“公寓外部：确认短住安排”。201物件、夫妻身份和位置此时都不变。

### A2　公寓外部：《去看一间真的能住的房》

**玩家动作：**到公寓外部，进入本线短住客房，确认入住条件与可使用的工作桌。房间正常可住，不人为塞进坏床、漏电等维修关卡。

**场面重点：**玩家可以带回房间情况，也可以约她一起看；不让一张商店图代替现场。两种方式最终都须她本人确认愿意住。

**费用建议：**准备页一次展示覆盖本线等待和延期的总价，由玩家明确确认后支付；本稿不定金额、不冒充现有商品。余额不足可以保留准备进度，不产生负数、不先把人搬出。住宿支持不附带恋爱或亲密义务，也不声称她已经因此拥有稳定收入。

**收口：**形成有效短住安排，房卡交由她持有。她确认住处后才允许正式搬入。支付成功、房卡到手和本人入住分别记录；消息失败不重复收费。

### A3　201→客房：《她自己合上箱子》

**开场：**她把日常衣物、个人文件与用品放进箱子。收拾到丈夫的东西时，把它们放回原处。玩家可以问是否还要带别的，不能擅自翻出证件或扔掉合照。

**两种搬取安排：**

| 玩家与她商定的方式 | 当下场面 | 后续区别 |
|---|---|---|
| 趁正常外出先搬随身用品 | 两人完成个人箱的搬取；共同物件和未明确归属的大件留下 | 丈夫先经她的告知得知搬出；缝纫机另约确认后搬 |
| 约双方在场，当面搬取 | 她说明暂住决定，赵国强追问，玩家须说明自己在协助什么 | 已获本人确认的设备可同批带走；A5不再重复质问同一搬运事实 |

当面搬取不自动等于公开情侣关系。如玩家或她已经明确说破关系，则记录已知内容；A5从未解决的婚姻问题继续，不能让赵国强再演一次第一次听说。

**实际路线：**她确认可搬范围 → 玩家提起箱子 → 从201到公寓外部 → 与她到客房 → 放下行李。箱子离开201时只代表已经取走；本人到场、行李放妥、入住确认成功后，才写实际分居起点。

**可见变化：**201她那一侧的抽屉收空，客房出现她带来的物件。缝纫机没有搬来就不显示工作角。

她本人向赵国强说明“已另住，回来需要谈”。路线保存告知的内容与送达状态；单靠通知弹窗或已读图标不能推定他已了解关系，更不能推定同意离婚。辅助手机展示失败，可按已成立的告知事实补显，不另发一套矛盾消息。

**情绪收口：**玩家临走前等她还有没有话。她看了一眼摆好的箱子，说今晚想自己待一晚。不是惩罚，也不是亲密邀请；让这次搬出真正成为她独自经历的改变。

### A4　客房：《今晚留下》（核心玩法未完成）

**用户指出的问题成立：**项目的场景标准包含实际可玩的亲密过程；增加邀约、晚饭、告白、事后和次晨的篇幅，不等于补上这一部分。此前“发生关系以淡出呈现”的替代方案撤回，不用于实现，也不再声称已经满足要求。

本次已核对的对照依据：

| 对照来源 | 已有标准 | 本稿的实际缺口 |
|---|---|---|
| 夏乔2026-08-21当前权威设计，第4.2节 | 明确复用完整阶段5亲密系统，不制作比普通系统更薄的按钮循环；结果依赖真实场次事实 | 本稿以淡出直接跨到事后，省略了玩家过程与结果来源 |
| 当前工作区《第二机位》系统的开录与收尾段 | 开场把控制权交回可继续游玩的普通亲密流程，之后才根据实际完成情况接续场景 | 本稿把增加外层叙事篇幅当成了补齐核心交互 |

上述比较只说明当前方案为何不合要求，不把历史旧稿的其他结局、动作或状态一并搬到201。尤其夏乔8月14日稿已经被8月21日稿取代，不能引用其中被否决的专属按钮循环作为现行标准。

**仍可保留、但尚未获用户认可的外层建议：**

1. 她先实际独住一晚，再主动邀请玩家到客房；A3独住与本次邀约分开。
2. 邀约、晚饭和主动留人只承担进入场景的叙事，不替代场景本身。
3. 具体核心内容与交互目前没有完成，本轮不新增露骨描写或动作设计，不能用“已发生”的自动标记填补空缺。
4. 后续对话须消费真实发生的结果，再谈双方是否愿意面对赵国强；不能用已有亲密替玩家回答关系承诺。
5. 留宿与次晨分别依照玩家决定和真实休息产生，未留宿不生成共同次晨。

因此A4目前没有完整可实施方案，A5—A7也只是外层后续建议。全条承接不能因其他场景已经写出，就被登记为设计完成。

### A5　201：《你们都在，那就说清楚》

**预约：**赵国强实际回楼后约一次三人可在场的会面。若他在玩家完成A4前已经回家，就照常在201生活；只顺延会面，不把他强行藏在楼外。

玩家先在大堂与她会合，再一起到201；她没有接受同行时不能被自动带过去。

**四拍主戏：**

1. **熟悉的家已经缺了一部分。**赵国强看见抽屉与物件变化，问的是“搬出去是认真的？”若他参与过搬取，就直接问是否打算回来。
2. **她说决定，不让玩家先宣判。**她说明不想继续夫妻生活，承认与玩家的关系。她可以有愧疚和停顿，但不把责任推给他跑车，更不临时揭出丈夫新恶行。
3. **赵国强转向玩家。**他问玩家是否知道这是什么关系。玩家可坦承参与、只说明自己的决定，也可要求降温后继续；不能凭一句“她现在归我”结算成功。
4. **第一次没有谈成。**他认为还有事情没说清，也想知道是否真没有修复余地。她坚持先继续分开住，答应在约定时间回应。他此时不直接同意办理。

赵国强台词方向：

> “我以为这个家没什么事。你跟我说，我到底从什么时候开始，什么都不知道？”

**玩家必须有实际应对：**选择留下听完、承认自己参与并停止争夺口吻、在对方要求后退到门外。她仍在场的私下夫妻谈话不向门外玩家全知播报；只从后来本人告知的内容补充已知事实。

辱骂、威胁或明显否认既有关系不走相同成功文本：会面暂停、等待重新约谈与明确回应，不抹掉已经说破的事实。不存在靠挑衅赢得她、一次选错永久报废的分支。

**收口：**丈夫知情内容、夫妻当前分开居住、未达成办理共识分别成立。玩家陪她回客房或按她要求让她自己回；不把返程奖励写成必须发生亲密。

### A6　大堂与客房：《他愿意改，她仍然不回去》

**时间门：**A5结束后至少经过一个完整游戏日。中间玩家可以经营、走其他线路；单纯多聊几轮不形成冷静时间。

**等待里有两件真事，允许先后互换：**

**其一，工作跟着她搬过来。**玩家按已确认的范围取来缝纫机和工单夹，在客房安放。她自己接续已有工作，不让玩家做缝纫小游戏。设备已提前搬妥则直接承接，不重复取物。

经过她实际可工作的时段，场景中出现这批活的进展；完成后工钱由她留作当前生活。金额与结算能力未接入前不虚构玩家现金奖励，也不把“有工单”当作“已获收入”。

可以加入一次非紧急的额外家用请求，作为新增桥段：她亲自说明这次不能再追加。不能拿母亲的急需药费制造二选一，不让玩家替她挂电话。这个小场面表明她正在改变旧支出习惯，不宣称从此解决了娘家的全部问题。

**其二，他提出一次具体的修复。**赵国强通过她能真实收到的联络提出见面，表示愿意试着调整长途安排、一起谈家里的压力。这是打算，不是系统已经替他换岗或增加收入。

玩家在大堂陪她等到约定的人。她可以先与丈夫单独谈；玩家不能代答，也不能隔空知道每句话。她在可见场面中或回来后明确自己的回应：

> “你愿意改，我听见了。可我现在答应回去，就是又瞒你一次。”

她承认他过去的照顾，不承诺把感情恢复成原来，也不要求他接受玩家留在婚姻里。

**玩家动作：**谈前听她说准备怎样回答；谈后接她回客房，或尊重她想独自走一段。下一次客房来访看见的是工作与生活仍在继续，不是她回201做饭然后再秘密出来。

**收口：**修复确实被提出、她亲自回应、实际分居持续。设备就位、有效工作进展和收入留用各记各的；不能用一段抒情替代这些事实。

### A7　公寓外部：《去办吧，剩下的说清楚》

**前置：**A6的回应已经落地，A5后的完整一日已经经过，工作与生活安排已有可核验进展；到A6结束后的下一个双方可赴约白天，再进入最终会面。

**开场：**赵国强提出谈下一步。玩家与她按约到公寓外部。这次没有屋里的夫妻物件挡在中间；他不再问玩家什么时候离开201，而是问两人打算怎样把现状说清。

**三拍推进：**

1. 他说明自己不能接受保留夫妻名义、另有一段关系的生活；她再确认不恢复共同生活。不是重新检定她选谁，而是双方各自把边界说完整。
2. 两人同意进入办理，约定各自准备资料和处理旧物旧账。她提出手续结束后希望继续住201，他明确愿另作居住安排；这里只形成后续约定，不马上撤掉他的住户身份。
3. 玩家回应自己会协助已说清的事项，不代签、不替夫妻分财产，也不向他索取祝福。赵国强结束会面，三人按实际去向离开。

台词方向：

> “你不是一时气话，我也听明白了。去办吧。该拿走的、该说清的，别再拖着。”

**尾声：**她站在玩家身边，先问下一次能安排在哪个白天。可以疲惫、难过，也可以松一口气，不把这场写成击败丈夫后的庆祝。

**收口：**有效现场确认双方同意办理，承接完成。解锁独立《离婚》入口，交还地图；不强制立即购买或跳到办事大厅。此后再见赵国强承接已同意的事实，不再循环“能不能接受”。

## 5. 玩家实际能操作什么

以下是设计动作，不是宣称现有接口已经具备。每一时刻只露出与当前阶段有关的少量动作。

| 地点／动作 | 必要条件 | 成功后改变 | 不满足时 |
|---|---|---|---|
| 201：谈谈分开住的打算 | 资格满足、本人在场、可独处、玩家赴约 | 她的意愿和已接受的协助范围 | 显示下一可约时段，不临时赶走丈夫 |
| 公寓外部：确认短住安排 | A1已同意准备 | 进入看房，选择是否确认费用 | 未同意前可查看说明，不产生订单 |
| 201：确认可搬物件 | 她在场，住处已接受 | 本次搬取范围与方式 | 不允许无人时翻找 |
| 201：搬取已打包物件 | 本次范围成立；必要的共同物件确认完成 | 物件从201进入携带状态 | 突然有人在场时转为谈话或改约 |
| 公寓外部：送她去客房 | 本人同意同行、住处有效 | 人与携带物实际移动 | 只到楼外不算入住 |
| 客房：放妥行李 | 本人在场，携带物存在 | 物件落地、入住确认后开始分居 | 不复制箱子，不推定缺席人物入住 |
| 客房：安放缝纫设备 | 已搬来、获得允许 | 工作角可用 | 设备仍在201时显示取物入口 |
| 客房：赴《今晚留下》的邀请 | 独住夜晚成立、本人邀请、无硬冲突 | 仅明确赴约入口；核心玩法未设计，不能用淡出代替 | 邀请过期只重约，不写失约惩罚连锁 |
| 客房：留下过夜／按约告别 | 本次相处已到事后或陪伴收束；双方意愿明确 | 实际留宿才开放合法休息与次晨；告别则保留真实约定 | 不自动睡眠，不用多聊一轮推进时间 |
| 大堂：赴201会面／陪她见丈夫 | 对应预约有效、演员实际到齐 | 进入A5或A6 | 不在场的人不会凭空出现在对话里 |
| 公寓外部：把后续安排说清 | A7前置成熟、双方赴约 | 同意办理、承接完成 | 告知具体缺项，不让玩家猜关键词 |

移动和执行动作消耗多少时段、精力，后续按现有行动种类核定；本稿不让模型临时定价。只有明确的世界时间动作才能推进世界钟。

## 6. 完成以后，世界必须记得什么

| 层面 | 承接进行中／完成后的应有表现 |
|---|---|
| 地图与房间 | 已入住后，她的路线住处是客房；201保留实际未搬走的东西。医院等硬位置优先；暂住不能把她从医院拉走 |
| 日常生活 | 客房能发生普通会面、处理工单和休息；不会每次重播第一次搬入。公共区及外出安排按实际仍可发生 |
| 丈夫 | 搬出知情、玩家关系知情、修复回应、同意办理分别继承；疑心降低或送礼不能让他遗忘 |
| 联系 | 已发出的邀请和具体承诺可复查；客房地址只给被告知的人，不自动给丈夫或其他住户导航 |
| 群聊与风闻 | 看见箱子只能知道在搬东西，不能直接知道婚姻决定。关系或分居公开须有实际告知；同一场面的风闻不跨天重复结算 |
| 房租与金钱 | 旧欠租、宽限、已缴款保持真实。本线不豁免201房租，不预支结局可能调整的正常收租效果 |
| 关系 | 她仍有自己的安排，不自动常驻玩家房间、不自动独占或再婚；亲密暂缓不会撤销她的住处 |
| 后续结局 | 只消费已经同意办理的事实，继续手续、旧账与居住交接；不得再次劝丈夫接受，也不得把开线当离婚 |

原有丈夫日常打断不能在客房随机生成“丈夫在自己家抓到玩家”。201里的普通夫妻生活模板也须识别分居。A5知情以后的冲突采用本线已知事实，不能每次撞见都重新演首次发现；并非因此全局免疫其他路线的风闻或冲突。

这些都是未来接线要求，本轮没有修改相应系统。

## 7. 状态与中断边界

### 独立保存的事实

不以一个“分居进度＝100”代替全过程。至少分开表达：准备意愿、已确认住处、费用结算、人物当前位置、物件位置、实际入住时点、独住夜晚、继续关系的回应、丈夫已知范围、修复提出与回应、工作进展、双方同意办理、后续居住约定。

事实之间允许不同步。例如“箱子已到，她尚未入住”“丈夫知道搬出，不知道玩家关系”“已经同意办理，仍是夫妻”都必须能表达。名称不是已经定下来的Schema字段。

### 四层职责

- **硬事实：**系统管理人物、物件、钱、时间和已经完成的决定。
- **强制现场：**只在当前有效预约、演员和地点成立时展开；有效正文成功提交后才推进本场结果。
- **软上下文：**空抽屉、生活习惯、已经说过的承诺；只能描述已有事实，不反向发放完成资格。
- **可选副作用：**图片、辅助手机展示和数据库摘要；失败不撤回已成功提交的主线事实，不因补发重复结算。

### 必须保留的中断行为

| 情况 | 预期行为 |
|---|---|
| 正文失败、超时或取消 | 未成功提交的本场不推进；已经成功的前一场、费用及搬运不重做 |
| 付款成功但下一场失败 | 保留订单与付款，不二次收费；继续从入住准备断点走 |
| 玩家中途停止谈话 | 保存已成功落地的知情内容，未谈完的决定留待重约，不自动代答 |
| 玩家拒绝继续关系 | 暂停情侣成功路线，不自动恢复婚姻，不收回她的住房支持；另行回应后才可能恢复同行 |
| 邀约失效、生产／住院 | 释放现场，预约顺延；医院、照护及既有孕产状态优先，不重复收费 |
| 已有孩子或照护安排 | 搬出前要确认其现有照护可持续；不能让孩子凭空留在空房，不能自动裁定监护或改写亲子事实 |
| 并发点击、重复进入 | 同一笔付款、物件转移、会面结果仅一次；准备中不能多开另一个现场 |
| 回档、切聊天、重掷 | 按真实聊天与时间线恢复位置、账务和认知；旧分支迟到结果不得补推进新分支 |
| 旧档只有L5或旧结局轨道 | 可以按资格进入准备，不补造分居、亲密、知情或办理完成 |
| 已有角色离场／灾难结果 | 不覆盖既有硬结局，不把本线的丈夫最终搬出套成整户迁走 |

不能仅凭模型在普通微信里写“我已经同意离婚”跨过A7；自由对话的意向只用来约定正式会面。相反，已经成功完成A7以后，也不能因后续普通对话措辞不同就撤销同意事实。

## 8. 本次设计核对与后续范围

本稿已对照当前人物、阶段与占位来源，按下列情形检查剧情闭合；这是文案设计核对，不是运行测试通过：

- 普通傍晚外出可起线，不依赖源码尚未表达的多日长途。
- 两种搬取顺序分别保留物件与知情差异，提前完成的设备搬运不重复。
- 丈夫可以提前正常回楼，A5消费当前认知，不冻结作息、不重播发现。
- A4尚缺核心玩法，原淡出方案已被否决；目前不能验证完整场次与后续收口，也不能误记亲密或次晨。
- 两段等待分别有独住与修复的内容，不以刷消息冒充时间。
- 承接完成只有同意办理，不提前改婚姻、退居或房租。

未完成：符合用户要求的A4亲密核心玩法。未做：代码接线、Schema设计、商品定价、临时地点UI、素材制作、运行测试和生产构建。后续进入实现时还需逐项追踪地图、作息、打断、手机、孕产、收租、档案及回档消费者，完成专项与相关全量回归、定向静态检查和隔离生产构建；当前不写正式`dist`、不发布。
