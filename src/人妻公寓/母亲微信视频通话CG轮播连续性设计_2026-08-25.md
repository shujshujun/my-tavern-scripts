## 二、为什么不把30张全部首尾硬循环

口交过程存在不可逆的终幕状态。若把“射精／事后／母亲起身”一起轮回到“刚刚靠近”，画面会在循环边界突然清空液体、恢复连接和改变姿势，破坏剧情可信度。

因此循环只覆盖稳定的进行中区段：

```text
001—004：只进一次
        ↓
005→006→……→022
 ↑                 ↓
 └──────循环───────┘
        ↓ 玩家决定结束通话
023／024／025／026：按当前深度四选一
        ↓
027→028→029→030：只出一次并结束
```

玩家可以和父亲继续聊任意轮数，`005—022`循环任意次数都不改变剧情状态；只有玩家明确选择结束交接通话，或说出明确告别并确认结束，才离开循环。

## 三、逐张动作设计

### 3.1 入场连接：001—004

| 编号 | 唯一动作变化 | 连续性要求 |
|---|---|---|
| `001` | 母亲已经跪到玩家两腿之间，双手落在固定的大腿位置，抬眼确认玩家 | 与样板同一机位、房门、地毯、灯光；尚未发生口腔连接 |
| `002` | 母亲上身前倾，脸靠近，手掌仍在原位 | 身体重心只向前移动，不换跪姿、不换房间 |
| `003` | 舌尖／嘴唇接近龟头，目光仍向上 | 玩家下腹、阴阜与阴茎来源连续，不突然改变长度、角度或左右 |
| `004` | 嘴唇第一次包覆，建立连接 | 作为非循环入场与循环起点005之间的桥；不能直接跳到深入口交 |

### 3.2 无限通话主循环：005—022

`005—022`全程保持口腔连接，但循环不再只是四档深浅往复。它包含舌尖调整、两种节奏、一次完整深喉段、含泪／屏息表情、听见父亲说话时的侧目、退出恢复、唾液连续和再次主动。每张仍只改变一个主要动作变量，避免表情、手位和深度同时突变。

| 编号 | 动作段 | 深度带 | 主要画面变化 |
|---|---|---|---|
| `005` | 循环接缝 | 浅 | 已验收样板；浅含、抬眼，作为每轮起点 |
| `006` | 舌尖调整 | 浅 | 龟头仍被嘴唇控制，舌尖在连接处做小幅变化，双手不换位 |
| `007` | 慢速浅含 | 浅 | 轻微后退再包覆，目光保持在玩家脸部方向 |
| `008` | 第一段推进 | 浅→中 | 头部前移一级，嘴角与面颊开始受力 |
| `009` | 听父亲说话 | 中 | 连接不松，眼神短暂偏向手机／父亲头像区域，表现克制与紧张 |
| `010` | 稳定中段 | 中 | 眼睑半垂，呼吸由鼻部承担，唾液开始增加 |
| `011` | 深喉准备 | 中→深 | 双手在原大腿位置收紧，肩颈下沉一级 |
| `012` | 深喉进入 | 深 | 嘴唇包覆明显加深，眼睛闭合，不能跳成不同机位 |
| `013` | 深喉停留 | 深停留 | 喉部承受与面颊张力可见，眼角开始含泪，保持同一进入角度 |
| `014` | 深喉表情 | 深停留 | 轻微含泪／屏息、手指用力和唾液连续；不得夸张成窒息或动作失败 |
| `015` | 最深主动段 | 深停留 | 母亲主动维持最深位置并短暂抬眼，作为本轮强度峰值 |
| `016` | 控制退出 | 深→中 | 平滑退出一级，泪光与唾液不能突然消失 |
| `017` | 恢复呼吸 | 中 | 眼睛重新睁开，鼻息恢复，嘴唇仍保持包覆 |
| `018` | 浅处恢复 | 中→浅 | 退出到浅处，出现连续唾液丝但连接不完全断开 |
| `019` | 表情变化 | 浅 | 听见父亲提到自己时短暂羞怯／挑衅地抬眼，不改变跪姿和手位 |
| `020` | 再次主动 | 浅→中 | 第二次较短的主动前移，表情从紧张转为从容 |
| `021` | 回落 | 中→浅 | 平滑退回，面颊与唇部受力逐步恢复 |
| `022` | 接缝复位 | 浅 | 回到与005兼容的浅含、抬眼和手位；下一张无缝回到005 |

严格循环接缝改为 `022 → 005`。这组相邻图必须额外检查脸部比例、发髻位置、玩家大腿间距、阴茎根部、嘴唇包覆深度、房门线条和床灯高光；深喉段还要逐对检查 `011→012→013→014→015→016`，确保进入、停留和退出依次发生，而不是六张互不相关的深喉插图。

### 3.3 退出衔接：023—026

玩家结束通话时可能停在不同深度，不能从任意循环图直接跳到同一张终幕图。系统按当前 `depthBand` 只选择以下一张：

| 编号 | 适用当前帧 | 衔接动作 |
|---|---|---|
| `023` | 浅带：005、006、007、018、019、021、022 | 从浅含开始一次明确的最终前移 |
| `024` | 中带：008、009、010、016、017、020 | 保持中等连接并调整到终幕共同角度 |
| `025` | 深带：011、012 | 从深处轻退半级后重新稳定，避免直接位置跳变 |
| `026` | 深停留：013、014、015 | 保持深处、抬眼听父亲最后一句，直接承接027 |

四张的末端构图都必须汇入同一个共同状态，使下一张 `027` 不依赖玩家恰好停在哪一帧。

### 3.4 终幕：027—030

| 编号 | 唯一动作变化 | 结局功能 |
|---|---|---|
| `027` | 母亲听见“照顾好你妈”后与玩家对视，保持连接并主动做最后一次动作 | 双重托付的视觉确认 |
| `028` | 最终完成帧 | 只播放一次；不得进入主循环 |
| `029` | 母亲结束口腔连接，仍跪在原处，保留可信的含泪、唾液与动作后状态 | 从进行中转为事后，不瞬间清洁或换姿势 |
| `030` | 母亲坐回少许、整理呼吸并伸手接回手机 | 成人CG序列结束；之后由普通剧情层处理手机、钥匙和关门，不再继续轮播 |

## 四、无限聊天与CG轮播必须解耦

父亲的聊天轮数与CG编号是两个独立状态：

- `chatTurn`：父亲和玩家已经完成的对话轮数，无上限；
- `hardBeat`：最后确认、母亲进入裁切线下、父亲问起母亲、险些暴露、最终托付等硬剧情节点；
- `cgIndex`：当前背景编号；
- `depthBand`：`shallow／medium／deep／hold`，只用于选择退出衔接图；
- `endingRequested`：玩家是否明确结束交接通话。

主循环可按视觉定时器缓慢轮播，也可按产品最终节奏与父亲语音状态协调，但不得把“一条父亲回复”硬绑定成“必须推进一个结局节点”。推荐表现：

- 每张停留约1.4—2.0秒；
- 相邻图使用约180—260毫秒轻微交叉淡化；
- 父亲回复失败、玩家长时间停留或继续追问时，硬剧情不推进，但005—022仍可循环；
- 点击“隐藏界面”只隐藏微信层，母亲动作循环继续；恢复后仍显示当前帧，不重播001；
- 明确暴露真相的二次确认弹窗出现时冻结当前CG，避免玩家做高风险选择时背景继续推进；
- 玩家提前挂断并重新拨回时，恢复原 `hardBeat`，CG从保存帧或最近安全浅含接缝继续，不重新播放入场四张。

第4个硬节点后进入不限时自由交谈窗口。父亲的最终托付台词不再因“已经聊满五轮”自动出现；只有玩家选择“结束交接通话／让父亲登机”，或明确告别并确认结束，才生成父亲最后一句、设置 `endingRequested=true`，随后选择023—026之一并播放027—030。

## 五、动作连续性硬门

30张共用同一份连续性母版：

1. **角色固定**：46岁明确成年、非孕态母亲；暖圆成熟脸、暖棕下垂眼、灰棕发、宽侧分刘海、右耳后松散低侧髻、成熟丰满体型。
2. **机位固定**：与已验收 `MVC-ADULT-001` 相同的男性第一视角、床沿坐姿、竖幅近景；不切第三人称，不出现玩家脸。
3. **场景固定**：302私人卧室，同一关闭房门、同一木色、同一白色软垫／地毯、同一中性暖光。
4. **玩家来源固定**：下腹、阴阜、大腿与阴茎必须从同一连续身体来源进入画面；不得生成第二根、游离器官或来源断裂。
5. **承重固定**：母亲始终在同一跪姿区域，双膝、髋部、肩颈和双手支撑关系不可跨图跳位。
6. **连接固定**：005—022嘴唇始终包覆；相邻图的进入深度最多变化一个等级，不能浅含后一张直接跳最深；深喉段必须完整包含准备、进入、停留、表情峰值和控制退出。
7. **造型固定**：发髻、刘海、妆容、指甲、乳房体积、肤色和高光方向不随帧变化。
8. **UI安全区固定**：脸与嘴部核心尽量保持上中区域；父亲头像、气泡和底部输入框按权威样板覆盖后不能长期遮住动作焦点。

每张原图除成人CG工作流九门外，还要登记 `continuityAudit`：

- `previousAcceptedFrame`；
- 身份／机位／场景是否一致；
- 玩家身体来源是否一致；
- 头部位移与进入深度是否只变化一级；
- 双手是否发生瞬移或换边；
- 唾液与动作后状态是否连续；
- `022→005`、`011→016`深喉连续段或退出桥→`027`是否通过专门接缝复审。

任何单张即使独立看起来漂亮，只要破坏相邻动作连接，也不能进入正式序列。
