# 夏乔「借种」结局——系统玩法、受孕来源与长期后果设计（2026-08-21）

> 状态：当前权威设计，开始实现。  
> 前置权威文件：`夏乔借种结局_前置玩法设计_2026-08-13.md`。  
> 本文件取代 `夏乔借种结局_特殊场景玩法设计_2026-08-14.md` 中尚未实现的特殊场景方案，尤其不得恢复已否决的“顺着夏乔／接过节奏＋至少两轮＋长按完成”玩法。  
> 核心原则：操作先结算，AI 后演出；即使把所有 AI 正文替换成一句占位，硬玩法、地图因果、受孕结果与长期后果仍必须完整成立。

## 一、已经拍板的结论

1. 家庭计划五日前置和赴约保持现状，不重做；赴约完成只代表陆嘉明已经同意并选定玩家。
2. 家庭计划完成后、借种结局完成前，普通亲密场景不得让夏乔提前受孕；她的第一胎必须由借种结局取得。
3. 借种结局最终有效完成时，脚本确定性登记夏乔受孕成功，不走普通 `60%／80%／100%` 概率阶梯。
4. 受孕当晚保持隐藏；经过现实确认期后，由玩家亲自前往101查看阳性结果，不能只靠一条 AI 微信宣布。
5. 借种前必须拆除101针孔摄像头并回302确认断线；摄像头不永久禁用，结局后仍可按原现实逻辑重新撬门安装。
6. 正戏复用完整阶段5亲密系统，不制作比普通亲密更薄的按钮循环；完成只认真实对象、地点、保护、行为和收尾事实。
7. 结局必须改变后续101日常、陆嘉明语义、监控内容、私聊、姐妹群、朋友圈／照片、孕期、住院、生产和出院内容。
8. 三人合照和产后家庭合照是跨系统真实物件：现场产生后，同一资源可进入私聊、姐妹群和101环境，而不是让模型凭空声称有照片。
9. 敏感CG使用本地 ComfyUI；非敏感CG使用内置生图。正式生产图片前必须服从本机既有生图 Skill／规则。
10. 目标是不新增 Schema 字段、不抬数据版本，不为一次性步骤扩散布尔值、坐标、动画进度或操作历史。

## 二、为什么这是系统玩法，而不是特殊提示词

现有监控玩法的沉浸感来自真实因果链：

```text
住户在场 → 不能安装
住户外出 → 才有进入机会
门锁着 → 必须撬门并完成操作
背包有摄像头 → 才能安装并真实消耗
101安装完成 → 监控系统才出现101
玩家回到302 → 才能观看画面
```

AI可以描述这条链，却不能绕过任何一个由脚本维护的事实。借种结局必须达到相同标准：跨地点、跨系统、带物品生命周期、带延迟回报，并在结局后永久改变可读内容。

## 三、借种前置：拆除101观察点

### 3.1 开放条件

家庭计划赴约有效完成后，商店出现一次性商品`借种`。购买可先于清理监控，但正式启动必须满足：

- 夏乔处于阶段5；
- 夏乔未孕、未处于待产／住院等硬锁；
- 101当前确有针孔摄像头；
- 夏乔与陆嘉明都不在101；
- 当前没有其他特殊场景、亲密场景、父亲电话或阻塞事务。

### 3.2 玩家实际操作链

```text
等待101夫妻都外出
  ↓
在地图点击101并完成既有撬门连点
  ↓
进入101后出现“拆下针孔摄像头”瓷砖
  ↓
摄像头从 `_摄像头布设['101']` 移除并回到背包
  ↓
玩家亲自离开101并返回302
  ↓
打开监控，101显示 `NO SIGNAL／观察点已移除`
  ↓
点击确认断线，写入一个短前置键
```

拆除和回收必须原子完成；重复点击不得复制摄像头。确认断线只在302且101确实未布设时成立。若玩家在正式启动前重新安装摄像头，前置资格立即失效，必须再次拆除并回302确认。

### 3.3 结局后重新安装

借种完成不永久禁止101摄像头。玩家以后仍须：

```text
等待101无人 → 撬门 → 使用背包摄像头重新安装 → 回302观看
```

重新安装后，监控可出现借种结局、孕期、计划板、产检、住院空房和产后家庭生活的专属内容。

## 四、正式启动与正戏

### 4.1 启动

- 固定为星期一晚上或深夜；
- 玩家必须亲自前往101，不自动传送；
- 启动时复核场景票、监控断线资格、夏乔状态和全部互斥；
- 有效确认后一次性消费票并进入通用 `_特殊场景`；
- 场景内冻结世界时间，失败、取消、回档和重掷服从现有事务纪律。

### 4.2 正戏玩法

不另做“顺着／接手／最少回合／长按完成”系统。进入正戏后开放夏乔完整阶段5亲密能力：

- 既有自由输入与动作连续性；
- 已解锁行为、身体开发和偏好；
- 现有成人CG舞台与画面连续性；
- 玩家可继续、切换或停止，不设强制回合数。

借种专属完成入口只在脚本硬事实全部满足时出现：

```text
特殊场景 = 借种
对象 = 夏乔／101
地点 = 101有效区域
保护状态 = 未使用
当前行为 = 阴道插入
最终位置 = 小屄
收尾对象 = 101
```

模型自行声称“已经完成”不能绕过账本。有效完成时使用稳定来源标识：

```text
借种结局:101:<稳定场次令牌>
```

该来源随现有字段贯穿怀孕、生产账、孩子档案、手机消息键和长期后果。

## 五、确定性受孕与阳性确认

### 5.1 当晚确定受孕

借种有效收尾后，在同一原子事务中：

1. 登记`借种`特殊场景完成；
2. 以借种来源写入夏乔`已受孕`；
3. 初始化本胎生产账并冻结陆嘉明知情；
4. 清理一次性运行态和监控断线前置键；
5. 保持受孕信息对正文、手机和界面隐藏。

普通概率随机不得参与，也不得被当天普通判定水位挡住。

### 5.2 一周后的实地确认

确认期到达后，夏乔的私聊只负责邀请玩家去101，不直接把结果完整说破。玩家必须：

```text
阅读邀请
  ↓
亲自前往101
  ↓
进入浴室／结果区域
  ↓
点击“查看检测结果”
  ↓
显示阳性CG
  ↓
正式把孕情推进为已告知
```

阳性结果来自脚本已存在的确定受孕真值，不由模型决定。

## 六、三人合照与照片跨系统传播

阳性确认后，101出现实际操作`站到她身边／拍下这张照片`。玩家完成后显示三人合照CG：

- 夏乔在中间；
- 陆嘉明和玩家各在一侧；
- 玩家不固定正脸，使用手机遮挡、侧背、裁切或阴影；
- 阳性结果、计划板或检查资料形成可识别连续性。

同一资源随后可被复用到：

1. 夏乔私聊原图；
2. 姐妹群的完整三人合照；
3. 公开朋友圈的安全裁切版或由玩家拍摄视角版；
4. 101计划板／相框环境痕迹。

完整照片进入公开朋友圈必须另有明确公开选择；默认只在姐妹群确认三人关系，对普通外界保持可解释口径。

## 七、结局后的日常硬变化

### 7.1 101地图与拜访

- 陆嘉明在家时不再自动把玩家拜访解释为秘密闯入或背叛；
- 101可出现家庭类行动，例如一起吃饭、查看计划板、准备产检；
- 可安排低频、固定窗口的三人日常行动；
- 普通亲密授权仍由夏乔当下状态决定，借种结局不是永久身体授权。

### 7.2 监控内容

重新安装101摄像头后，观察池增加：

- 夫妻讨论孩子和玩家；
- 夏乔把三人照片放上计划板；
- 陆嘉明独自面对计划板的复杂反应；
- 孕期准备婴儿用品；
- 住院期间101的空房痕迹；
- 出院后的家庭生活。

### 7.3 丈夫语义

陆嘉明已知、同意并承担社会父亲责任。相关孕情不得进入通用怀疑、索赔、安眠药圆场或被背叛轨道。现有第一胎感谢、后续带酒等变体必须同时确认结局事实／来源，不能只凭“家庭计划曾完成”误触发。

## 八、私聊、姐妹群与朋友圈差分

尽量替换现有通用孕产节点，不额外堆积几十条消息：

| 通用节点 | 借种结局版本 |
| --- | --- |
| 报孕私聊 | 邀请玩家到101亲自查看结果 |
| 孕情姐妹群 | 夏乔晒三人合照，明确陆嘉明知情和玩家的生物学身份 |
| 群后私聊 | 其他太太按真实火气、关系和既往认知私聊玩家 |
| 预产通知 | 夏乔说明夫妻已在医院，询问玩家是否过来 |
| 生产姐妹群 | 不再猜父亲；围绕三人家庭安排、孩子和各角色反应展开 |
| 产后照片 | 借种专属家庭合照，而非通用母婴照 |
| 住院恢复／近况／出院 | 读取玩家是否陪产、陆嘉明在场和三人关系 |
| 后续普通私聊 | 偶尔自然提到“我们三个”，不反复解释整条前置 |

消息幂等继续使用现有稳定事件键；认知只从真实落库消息和来源事实重建，不新增认知布尔表。

## 九、住院、生产与产后差分

复用现有医院和生产生命周期，不建立第二套生产系统；借种来源改变演出、人物位置、CG和手机内容：

- 陆嘉明负责入院手续、社会父亲和家庭安排；
- 玩家是生物学帮助者，也是夏乔主动希望陪在身边的人；
- 待产可出现`和陆嘉明一起办理入院`等专属动作口吻；
- 陪产、生产和产后探望读取三人的真实在场与选择；
- 产后可增加`请护士帮忙拍一张`，产生夏乔＋孩子＋陆嘉明＋玩家的家庭合照；
- 该合照继续进入私聊、生产姐妹群和出院后的101环境。

### 10.2 敏感图（本地 ComfyUI）

- 使用本机既有生图 Skill／规则；
- 使用夏乔专属LoRA和项目统一画风；
- 现有普通夏乔成人图库继续承担大多数自由行为；
- 只补6—8张具有101地点、借种来源和关键完成语义的专属标志图；
- 陆嘉明不进入成人画面；
- 玩家继续使用第一人称、背影、局部身体、遮脸或裁切，不固定正脸。

## 十一、变量与提示预算

### 11.1 持久变量预算

```text
新增Schema字段：0
新增默认对象：0
新增逐步布尔值：0
新增拖拽坐标／动画进度／操作历史：0
数据版本升级：0（除非实现中证明现有通用槽无法安全承载）
```

复用：

- `_已完成特殊场景`
- `_特殊场景`
- `_特殊场景前置`
- `_摄像头布设`
- `_怀孕`
- `_生产`
- `_家庭文档.孩子`
- 手机消息稳定键

`家庭计划知情`只表示陆嘉明知情，不能单独证明借种结局完成。结局差分至少读取：

```text
_已完成特殊场景包含“借种”
受孕场次标识属于“借种结局:101:”来源
```

### 11.2 提示预算

- 借种未运行、且当前内容无关时：新增提示0字符；
- 活动场景最小提示：目标约80—150字符；
- 阶段切换完整提示：不超过300—400字符；
- 结局完成后的事实只在101、夏乔、陆嘉明、孕产、孩子、相关手机事件或监控内容中按需注入；
- 不把本文件或全套操作说明每轮发送给AI。

## 十三、本轮实际落地记录（2026-08-21）

### 已完成

1. 新增借种来源事实与场景状态机，不新增 Schema 字段、不抬数据版本；
2. 家庭计划完成后、借种结局完成前，普通亲密不再抢先让夏乔受孕；
3. 商店`借种`从只读占位升级为真实收费、入包、一次性场景票；
4. 101摄像头支持真实拆除并按数量回到背包，重复拆除不复制；
5. 玩家必须撬门进入无人101拆机，再回302打开真实监控面板，点击`CAM-101 / NO SIGNAL`断线卡确认；
6. 重新安装101摄像头会立即取消未使用的断线资格，结局完成后仍允许按原现实逻辑重新安装；
7. 星期一晚上／深夜、101、断线凭据和互斥全部满足后，地图出现真实结局启动瓷砖；
8. 借种正戏直接开放完整夏乔阶段5亲密账本，不使用已否决的缩水按钮循环；
9. 只有真实无保护阴道插入、对象101、正确最终位置的有效收尾，才会原子完成结局并确定性登记受孕；

17. 产后家庭照拍下后才进入私聊、姐妹群和朋友圈，并升级101持久背景；
18. 孕产图片键按受孕场次来源分流到`生产/借种/夏乔/...`，孩子档案继续保存来源；

20. 新增专项测试覆盖购买、摄像头计数、断线、启动、停止、确定受孕、延迟告知、阳性、照片、手机、群聊、医院、生产资源和完整端到端链。

### 尚未作为正式资产完成

1. 非敏感CG尚未调用内置生图批量生成；
2. 借种专属敏感CG尚未按本机 Skill 逐张生成、视觉审核和WebP入库；
3. 成人CG当前仍可降级复用夏乔既有阶段5图库，借种专属7张图的优先路由要与最终文件名一并落地；
4. 正式图片完成后还需移动端裁切、缺图降级、资源孤儿检查和角色卡发布物自检。

以上未完成项只影响专属画面丰富度，不影响已经落地的地图操作、场景票、监控闭环、确定受孕、实地阳性、照片事实及孕产后果链。
