# 夏乔「借种」结局——硬玩法与孕产后果权威设计（2026-08-21）

> 状态：当前落地权威设计。  
> 本文取代 `夏乔借种结局_特殊场景玩法设计_2026-08-14.md` 中尚未实现、且已被否决的“顺着夏乔／接过节奏＋最少两轮＋长按完成”玩法。  
> 已完成的五日家庭计划前置继续以 `夏乔借种结局_前置玩法设计_2026-08-13.md` 与当前源码为准，不重做。  
> 核心原则：玩家操作先改变真实世界状态，AI只演绎已经成立的事实；即使把AI正文替换成占位句，玩法因果链仍须完整成立。

## 一、已拍板结论

1. 家庭计划完成以后，独立商品 `借种` 才在特殊场景货架出现。
2. 借种不是一段可由普通自由输入复现的AI剧情，而是一条跨地点、跨系统、有现实条件和延迟回报的硬玩法链。
3. 借种开始前，玩家必须亲自拆除101既有针孔摄像头，并回到302通过监控界面确认101已经无信号。
4. 摄像头不永久关闭。结局完成以后，玩家仍可等待101无人、再次撬门、重新安装摄像头，再回302观看。
5. 借种结局的有效完成必定让夏乔受孕，不再运行60%／80%／100%的随机阶梯。
6. 当晚只在系统内部确定受孕；玩家仍需经过现实等待期，之后亲自前往101查看阳性结果。
7. 结局完成后，101日常、丈夫语义、私聊、姐妹群、朋友圈、监控内容、孕期、住院、生产、产后与孩子相关内容都必须读取“借种结局来源”，不能只换一句AI提示。
8. 夏乔可将自己、玩家和陆嘉明的三人合照发到私聊和姐妹群；公开朋友圈若使用，应采用对外仍可解释的裁切版本，不默认把完整父亲关系公开给全楼外界。
9. 敏感CG走本地ComfyUI与 `$rqgy-adult-cg-workflow`；非敏感CG走内置 `$imagegen`。所有正式成人CG必须按编号、单图、原图审核、分类、登记和报告工作流执行，禁止普通工作流直接批量入库。
10. 当前工作优先完成玩法、来源标识、孕产分流和资产路由；图片缺失时只降级画面，不得阻断核心状态提交。

## 二、不能退让的体验标准

特殊场景必须满足以下检验：

> 把所有AI正文暂时替换成“人物作出了回应”，玩家仍然能理解自己做了什么、为什么现在能做、操作失败会怎样、以及操作在另一个地点或后续系统里造成了什么结果。

因此，以下内容不能充当核心玩法：

- 只移动几块不会改变系统的姓名磁贴；
- 只选择丈夫留在客厅还是外出；
- 关窗帘、倒水、放毛巾等一次性装饰动作；
- 为了操作而设计的长按、连点、进度条或隐藏回合计数；
- 三句共识拆成三次确认；
- 用一段长提示词要求AI自行宣布所有结果。

值得开发的操作必须在别处或以后出现可验证后果，例如：

- 101拆掉摄像头 → 302监控真实变为无信号；
- 当晚完成受孕条件 → 一周后检测结果真实为阳性；
- 101现场拍下三人合照 → 同一图片进入私聊、姐妹群和101环境；
- 结局来源写入怀孕场次 → 医院、生产、丈夫和孩子档案读取相同来源。

## 四、摄像头拆除与恢复规则

### 4.1 拆除条件

只有同时满足以下条件，101房内才显示拆除动作：

- 家庭计划已经完成；
- 玩家持有 `借种` 场景票；
- 101确实已经布设针孔摄像头；
- 玩家真实位于101室内；
- 夏乔与陆嘉明均不在101；
- 当前没有其他大型特殊场景、活动场景剧情或父亲电话阻塞；
- 借种结局尚未完成。

拆除必须与安装同账提交：

- `_摄像头布设['101']`关闭；
- `针孔摄像头`回到背包；
- 写入短前置键 `借种:摄像头已拆`；
- 不调用AI，不创建聊天楼。

### 4.2 302断线确认

拆除后必须回到302打开监控。监控列表临时保留一张101离线卡：

```text
CAM-101
NO SIGNAL
观察点已移除
```

只有玩家在302点击这张离线卡后，才写入短前置键：

```text
借种:断线已确认
```

确认不调用AI，也不创建聊天楼。

### 4.3 临时禁止重新安装

从摄像头拆除到借种场景完成或玩家放弃票据期间，101不得重新安装摄像头。其他房间不受影响。

### 4.4 结局后恢复普通安装

结局完成后：

- 不自动恢复101摄像头；
- 针孔摄像头仍在玩家背包；
- 玩家以后可等待101无人，重新撬门进入，使用现有安装流程；
- 重新安装后，回302才能再次观看；
- 101监控内容读取借种完成、孕情、住院、产后等真实状态，出现专属观察内容。

- 结局CG和合照资源路由。

`家庭计划知情=true`只表示陆嘉明知道家庭安排，不能单独证明借种结局已完成。所有专属后果须同时读取完成事实或场次前缀。

## 六、亲密系统边界

### 6.1 复用完整阶段5玩法

借种开场后，继续使用现有亲密系统的：

- 自由输入；
- 动作连续性；
- 夏乔既有身体开发；
- 阶段5行为范围；
- 成人CG舞台；
- 玩家随时停止；
- 生成失败、重试、重掷与回档。

不得建立：

- `顺着夏乔／接过节奏`二按钮循环；
- 最低两轮；
- 接种准备度；
- 长按完成；
- 借种专属满意进度条。

### 6.2 借种最终收尾

借种场内的最终选项只保留：

- `小屄`：在当前行为为阴道插入、保护状态未使用时完成结局；
- `停下并收尾`：安全退出，不登记结局、不受孕，恢复场景票，保留已经完成的拆机／断线前置，方便下一个合法星期一重试。

若夏乔在正文中明确中止，同样安全退出并恢复票据。

### 6.3 保证受孕

有效体内完成时，不调用随机概率阶梯。脚本直接写入与普通成功受孕同构的怀孕状态，并冻结：

- 受孕绝对时段；
- 一周后的最早确认时段；
- 借种场次标识；
- 本胎序号；
- 家庭计划知情事实；
- 丈夫登门与生产初始账。

提交顺序必须原子化：

1. 验证当前场景、对象、行为、保护、票据和来源；
2. 写入保证受孕；
3. 登记 `借种` 已完成；
4. 清除临时前置与运行态；
5. 不自动恢复摄像头；
6. 任何一步失败都不得留下“结局完成但没有怀孕”或“已经怀孕但结局未完成”的半状态。

## 七、阳性结果与三人合照

### 7.1 不由微信直接宣布

一周后到期，借种来源不发送通用“我怀孕了”气泡，而是发送一条必须包含以下硬事实的邀请：

- 夏乔本人发信；
- 请玩家来101；
- 有结果或东西要当面给他看；
- 不在消息中直接宣布阳性；
- 不声称玩家已经到达或回应。

### 7.2 101现场确认

玩家读到邀请后，101出现专属地点动作。玩家亲自到场并点击查看检测结果，才：

- 展示阳性结果CG；
- 把孕情从待告知推进为已告知；
- 起算现有孕期时钟；
- 允许后续姐妹群、孕肚CG和医院内容出现。

### 7.3 三人合照作为真实跨系统物件

阳性确认后，现场提供一次性动作形成三人合照。照片必须：

- 夏乔、陆嘉明和玩家三人真实同场；
- 玩家不固定正脸，可用第一人称、侧后方、手机遮挡、镜面裁切或肩膀入镜；
- 画面与阳性结果、计划板或101环境连续；
- 同一资产在私聊、姐妹群和101结局环境中复用；
- 手机消息键防止重复发图。

## 八、结局后的日常变化

结局完成不是只给AI一条常驻提示。至少包括：

1. 101在陆嘉明在家时也可出现知情家庭类拜访动作，不再统一套用秘密偷情语义。
2. 101可出现阶段5后的三人日常入口，如一起吃饭、准备产检、查看家庭计划痕迹；这些动作消耗现有行动资源，不增设新资源。
3. 陆嘉明在场时，AI读取知情家庭关系，不得自动质问、撞破、索赔或把孩子当背叛证据。
4. 重新安装摄像头后，101监控可出现计划板、产检、婴儿用品、三人照片及丈夫复杂反应等专属内容。
5. 夏乔普通私聊自然承接三人关系，但不得每一条都复述借种经过。
6. 结局完成事实只在夏乔、陆嘉明、101、孕产和直接相关场景中按需注入；其他住户与普通楼务回合新增提示为零。

## 九、孕期、住院、生产和产后差分

### 9.1 孕期

- 报孕改为101当面查看阳性结果；
- 三人共同产检可成为专属地图／CG节点；
- 陆嘉明承担登记、家庭身份和生活安排；
- 玩家是明确知情的生物学父亲，也是夏乔希望参与的人；
- 不把两名男性写成争夺夏乔或孩子所有权。

### 9.2 医院与待产

复用现有医院生命周期和动作，不建立第二套生产系统；但借种来源改变动作文案、事件注入和CG：

- `和陆嘉明一起办理入院`
- `留下陪夏乔生产`
- `等待夏乔生产`
- `产后看望夏乔`

丈夫与玩家可以在同一医院场景承担不同现实角色。

### 9.3 生产与住院

借种来源的住院节点应覆盖：

- 恢复：夏乔对两人的依赖和分工；
- 近况：陆嘉明照顾家庭身份，玩家陪伴或被夏乔私聊点名；
- 出院预告：三个人如何把孩子带回101；
- 出院：101背景升级为宝宝用品与三人照片版本。

### 9.4 产后家庭合照

玩家在医院现场亲自触发“请护士帮忙拍一张”，形成夏乔、孩子、陆嘉明和玩家的家庭合照。该图随后进入：

- 夏乔私聊；
- 姐妹群生产专场；
- 101出院后环境；
- 结局图库。

## 十、手机与公开层变化

### 10.1 优先替换通用孕产节点，不额外堆消息

| 通用节点 | 借种来源版本 |
| --- | --- |
| 报孕私聊 | 邀请玩家来101看结果 |
| 孕情姐妹群 | 三人合照与知情关系专场 |
| 群后私聊 | 其他太太按既有火气和认知私聊玩家 |
| 预产通知 | 夏乔告知她与陆嘉明已在医院，询问玩家是否来 |
| 生产姐妹群 | 不再猜本胎父亲；按已公开的借种关系讨论 |
| 母婴合照 | 借种专属家庭合照 |
| 住院恢复／近况／出院 | 读取三人关系和玩家是否陪产／探望 |

### 10.2 姐妹群

夏乔可在姐妹群主动晒完整三人合照。该消息一旦真实落库：

- 群成员知道陆嘉明知情；
- 群成员知道玩家是本胎生物学父亲；
- 后续不能再次演成第一次发现；
- 各人仍按自身关系、火气、胎次经验作出差分反应；
- 不自动把这个事实传播给丈夫、楼外人或公开朋友圈。

### 10.3 朋友圈

默认不发完整三人合照到对外公开朋友圈。可使用：

- 玩家作为拍照者；
- 只露玩家手臂或肩膀；
- 对外可解释成管理员帮忙；
- 夏乔和陆嘉明作为公开夫妻主体。

若以后要开放完整公开版，必须单独设计风闻和楼内后果，不作为本轮默认落地内容。

```text

```


| 拆机成功 | 摄像头回包、101断线、写临时前置 |
| 未回302确认 | 不能启动借种 |
| 非星期一／非晚上深夜 | 不消费票、不启动 |
| 开场正文失败 | 保留票与运行阶段，原拍重试 |
| 亲密过程中停止／夏乔中止 | 不完成、不受孕；恢复票；保留拆机与断线确认 |
| 有效体内完成 | 原子完成结局并保证受孕 |
| 重复点击／迟到旧正文 | 只认当前场景、阶段与稳定场次令牌一次 |
| 回档／删楼／切分支 | 票、摄像头、前置、怀孕、结局、手机与图片事件随有效时间线恢复 |
| 图片缺失 | 隐藏或显示占位，不回滚核心结算 |

## 十四、落地顺序

1. 建立借种来源常量和纯状态函数；
2. 将 `借种` 从路线占位升级为真实特殊场景商品；
3. 落地拆摄像头、回302确认无信号和临时禁止重装；
4. 落地星期一101启动与固定开场；
5. 复用完整亲密系统，限制借种收尾并保证受孕；
6. 用来源前缀修正普通受孕、丈夫和生产分流；
7. 落地一周后101阳性确认；
8. 落地三人合照、私聊、姐妹群、朋友圈和日常差分；
9. 落地医院、生产、住院、产后和101监控差分；
10. 按两套生图工作流逐张制作、审核和接线CG；
11. 完成桌面／手机实机验证、全量测试、构建和发布准备。
