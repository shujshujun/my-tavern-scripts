## 一、设计目的

《回国》只让父亲通过经营归档、母亲回复和远程信息接受“玩家已经在独立管理公寓”的事实；父亲本人尚未亲眼看过公寓现状。

因此《双重继承》首先要让父亲真实回楼，跟随玩家检查公寓全部公共区域。检查无论遇到楼务还是保持正常，最终都确认玩家具备完整管理能力：

- 没有楼务：证明公寓维护稳定；
- 存在楼务：父亲看见玩家识别、安排或完成真实处理；
- 两种情况都不会产生“父亲不满意”分支；
- 不重新运行胜任度、上交额或《回国》经营审核。

公共验收以后，母亲进入管理员室，要求丈夫把公寓完全交给玩家管理。父亲同意，玩家通过瓷砖真实取得公寓楼总钥匙。三天后的安全早上，三人在302餐桌完成家庭早餐；父亲宣布当日下午离开并再次确认管理权，随后在安全下午接入已经落地的机场微信视频终幕。

## 二、总流程

```text
父亲按《回国》冻结日期抵达
→ 公寓外部迎接父亲
→ 父亲头像临时绑定玩家当前公共区域
→ 玩家自由检查八个公共区域
→ 每个区域点击检查瓷砖，只显示CG与脚本提示，不调用AI
→ 若当前有真实楼务，父亲看见玩家使用原系统处理或安排
→ 八区全部完成
→ 管理员室出现交权瓷砖
→ 母亲头像与立绘进入管理员室
→ 两回合AI演绎：母亲要求完全交权／父亲同意
→ 玩家点击瓷砖取得“公寓楼总钥匙”
→ 母亲回302，父亲同行头像从地图消失，但父亲仍暂住302
→ 至少三天后第一个安全早上
→ 302餐桌四至五回合家庭早餐
→ 父亲宣布当日下午乘机离开并确认以后由玩家管理
→ 早餐成功后父亲离楼前往机场
→ 当日下午第一个安全时点预约现有微信视频终幕
```

## 三、公共区域同行检查

### 3.1 地图同行语义

父亲抵达以后进入`公共区域检查中`：

- 地图保持可操作，不全局冻结；
- 父亲是临时同行角色，不写入302丈夫普通作息；
- 父亲地图头像直接派生为玩家当前所在的公寓公共区域；
- 玩家移动到另一检查区域时，父亲头像同步转移；
- 刷新后按路线阶段与玩家当前位置恢复，不另存一份可能错位的父亲地图坐标；
- 城市外部地点、医院、晨跑公园和住户私室不属于本次检查；
- 玩家可以自由选择中间区域的检查顺序。

地图顶部显示：

```text
父亲现场检查　已完成数／8
```

尚未检查的区域显示金色`INSPECT`标记，已经检查的区域显示完成标记。

### 3.2 八个检查区域

| 区域 | 现场内容 | 真实消费者 |
|---|---|---|
| 公寓外部 | 门廊、外墙、排水与出入口 | 公寓入口与外部环境状态 |
| 大堂 | 门禁、声控灯、公告与共享物件 | 大堂公共任务与门禁状态 |
| 信箱区 | 门牌、箱门、积压信件 | 当前住户与信箱楼务 |
| 楼梯间 | 声控灯、扶手、通行与消防空间 | 扶手、照明和重要任务 |
| 垃圾房 | 清运、异味、分类与卫生 | 垃圾房公共楼务，不翻住户垃圾 |
| 公共洗手间 | 水电、通风、清洁与隔板维护 | 公共设施状态，不暴露成人玩法秘密 |
| 健身房 | 器械、地垫、通风与使用记录 | 公寓健身设施状态 |
| 天台 | 排水、护栏、晾晒区与杂物 | 天台排水等公共任务 |

管理员室不计入普通八区；它是全部检查后的交权收口地点。

### 3.3 点击检查瓷砖

每个区域显示一次性瓷砖：

```text
陪父亲检查当前区域
```

点击后：

1. 显示本区域对应检查CG；
2. 脚本读取当前地点的真实楼务、近期完成记录和环境状态；
3. 显示一段确定性提示；
4. 原子登记本区域已经检查；
5. 不调用AI，不增加普通正文回合，不推进世界时间。

没有楼务时，脚本提示父亲确认维护稳定。存在楼务时，检查瓷砖不替玩家完成任务；玩家仍使用原有楼务瓷砖处理或安排，父亲通过同行状态见证过程。无论有无楼务，父亲最终都会满意，不存在失败、扣分、重审或延期分支。

## 四、管理员室两回合完全交权

八区全部完成后，管理员室出现：

```text
和父亲汇总公寓检查
```

点击后：

- 父亲从地图同行头像转为管理员室现场角色；
- 母亲头像与立绘临时出现在管理员室；
- 使用三人管理员室事件CG；
- 脚本预先冻结结论：父亲必然同意完全交权；
- AI只负责两回合演出，不能增加附加考核、反悔或失败条件。

### 第1回合：母亲要求完全交权

母亲根据父亲刚刚完成的八区检查，直接要求：

- 既然公寓现在确实由玩家管理，就把管理权完整交给玩家；
- 以后普通事务由玩家自行决定；
- 父亲不再隔着电话替玩家重新安排。

玩家可以自由回应，不检查关键词。

### 第2回合：父亲同意

父亲确认：

- 公寓日常管理完全归玩家；
- 普通事务不再等待他的远程批准；
- 重大产权与业主事项仍按既有现实规则联系；
- 自己不再作为实际管理员干预公寓。

有效正文成功后出现硬瓷砖：

```text
接过公寓楼总钥匙
```

玩家点击后：

- `公寓楼总钥匙`真实进入背包；
- 重复点击不得复制；
- 写入管理权已经交接；
- 母亲回到302；
- 父亲同行头像从地图消失；
- 头像消失只表示同行检查结束，不表示父亲已经离楼。

## 五、三日等待

取得总钥匙以后：

```text
最早早餐日 = 当前游戏日 + 3
路线阶段 = 等待三日早餐
```

三天期间：

- 父亲暂时住在302，但不作为普通丈夫地图角色随机活动；
- 地图恢复普通使用；
- 《回国》建立的姐妹群临时收敛口径继续有效；
- 302不开放与父亲在场硬冲突的普通亲密动作；
- 母亲保持302家庭生活语义；
- 公寓楼总钥匙持续留在玩家背包；
- 不重新检查公共区域，不重复管理员室交权。

## 六、三日后的302家庭早餐

触发条件：

```text
当前游戏日 >= 最早早餐日
当前时段 = 早上
玩家位于302
当前没有医院、生产、亲密、父亲活动电话、其他强剧情或场景事务
```

发生竞态时顺延到下一个安全早上，不失败、不跳过。

302出现：

```text
和父母一起吃早餐
```

点击后使用专属事件CG：母亲与玩家坐在餐桌同一侧，父亲坐在桌子另一侧，父亲行李位于门口或背景侧面。场景建议五回合。

### 第1回合：座位变化

父亲自然问母亲为什么坐到对面。母亲回答已经习惯了，平时吃饭就是这样坐。父亲只理解为自己长期不在以后形成的生活习惯，不再追问。

### 第2回合：普通家庭近况

父亲询问这几天家里、公寓或母亲生活，玩家与母亲自然回应，让三人早餐真实存在，不坐下就宣布离场。

### 第3回合：宣布下午离开

父亲说明当日下午前往机场，海外仍有最后一段工作需要收尾，行李已经整理好，不需要玩家再为公寓准备什么。

### 第4回合：家庭场景确认管理权

父亲再次确认管理员室已经完成的事实：公寓以后由玩家管理，普通事项玩家自行决定，重大事项再联系。这不是第二次审核。

### 第5回合：普通叮嘱与收尾

父亲对母亲作普通生活叮嘱，并说明到机场后会联系。不得提前使用现有视频终幕固定句“家里也多上点心，照顾好你妈”。

第五回合成功后：

- 早餐完成；
- 父亲离开302并前往机场；
- 写入父亲已离楼事实；
- 母亲继续留在302；
- 路线进入`待机场视频`；
- 最早视频时段为当日下午。

## 七、接入已经落地的微信视频

当日下午第一个安全时点，满足以下条件后调用现有入口：

```text
父亲已经离楼并到达机场
早餐有效完成
公寓楼总钥匙仍在玩家背包
没有其他活动父亲电话
没有医院、生产、亲密或强剧情
```

调用：

```ts
预约母亲视频通话终幕(data, 双重继承标识, 当前楼层)
```

玩家不在302时来电保持待接，现有接听门要求玩家先回302。发生竞态时顺延到下一个安全时点，可解释为安检、候机或航班延误；不取消早餐结果，不让父亲重新回楼，也不重复公共检查、管理员室交权或总钥匙取得。

从预约成功开始，本路线停止控制视频内部。54张CG、父亲回复、现场正文、最终回答、挂断与终幕推进全部继续由现有视频状态机负责。
