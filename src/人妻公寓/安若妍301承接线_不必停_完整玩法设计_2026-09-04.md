## 一、产品定位

301的核心不是调查婚姻真相、收回账号、归档原片或让三个人长谈关系，而是：

> **玩家明知江辰会回301，仍然在夫妻卧室与安若妍开始并继续一场完整亲密互动；江辰回来亲眼看见后没有打断、没有观看、没有加入，而是从外面替两人关上卧室门，接受彼此私人生活互不干涉。**

承接线只解决正式结局成立前必须存在的硬事实：

1. 江辰明确知道玩家与安若妍的性关系；
2. 他不是被骗、猜到或只听到传闻，而是在301亲眼确认；
3. 玩家没有因为丈夫回来就退出夫妻卧室；
4. 江辰主动退出卧室并关门，第一次用行动接受这种安排；
5. 事后他明确提出双方私人生活互不干涉、以后回301提前通知；
6. 对外夫妻身份暂时保留，但尚未登记正式结局。

本线的冲击来自同一空间里的身份错位：丈夫在书房取自己的文件，玩家在一墙之隔的夫妻卧室继续占有他的妻子。剧情解释必须短，亲密现场和江辰关门才是主体。

## 二、明确不采用的设计

- 不创建直播、账号、剪辑、双路录像或新社交平台系统；
- 不恢复已归档的《原片归档→撤稿》；
- 不把江辰写成102／202式苦主观众；
- 不把江辰加入多人亲密参与者，也不形成101式三人家庭；
- 不让玩家靠自由输入几句话说服江辰；
- 不用一次AI回复同时完成撞见、接受、关门和事后协议；
- 不建立第二套体力、满意度、保护、受孕或成人CG状态机；
- 不要求特定射精位置，不用结局专属收尾覆盖普通亲密选择；
- 不让承接线提前登记正式“名义夫妻／默契”结局。

## 三、标准时长与回合总量

### 3.1 游戏时间

标准流程至少跨越**三次日期边界，覆盖四个游戏日**：

```text
第1日：301使用剧情道具，得知江辰回程
→ 第2日：大堂签收卷宗、管理员室登记、301书房放置
→ 至少再经过一个完整世界日
→ 第3日晚上：江辰按约回301，完成《不必停》主体
→ 第4日早晨：管理员室登记提前通知规则，承接完成
```

普通聊天和AI回合不推进世界钟。玩家必须使用现有睡眠、休息、训练、楼务等时间动作真实跨日；线路只保存最早继续日和预约夜晚，不暗中跳时间。

错过第3日安全晚上时自动顺延到下一个安全晚上，不重跑第1—2日已经成立的物件与登记。

### 3.2 AI回合

标准流程为**20个AI演绎回合**：

- 辅助剧情：7回合；
- 亲密主体：13回合；
- 其中由玩家通过现有亲密界面推进的普通亲密过程，收尾前必须累计安若妍本人**7个有效楼**；
- 硬地图操作、商店购买和交互瓷砖不计AI回合。

必须区分“AI回复数”和“普通亲密有效楼数”：

- 第3日晚的现场准备拆为2个AI回合，分别完成书房核对与前门／卧室空间布置，不能把两个地点和进入卧室压进同一楼；
- H1只负责专属开场并创建零进度普通亲密账，不增加满意度或有效楼数；
- H6—H8属于江辰进入、看见、玩家继续与关门的线路演出，期间暂停普通亲密结算，不扣体力、不增加满意度或有效楼数；
- 只有H2—H5与H9—H11共7楼属于收尾前的普通亲密有效楼；
- H12另用1个AI回复完成普通收尾。主动收尾时通常成为第8个有效楼；体力正好在第7楼耗尽时，下一楼只演免费失控收尾，有效楼数保持7；
- H13再用1个固定回合完成卧室余韵与走向客厅的转场，不再结算普通亲密，避免高潮后直接跳到三人谈话。

301当前L5普通满意目标为6，但她的角色时长偏移为`最短+1`，所以正常主动收尾至少需要**7个个人有效楼**，理想区间为7—8楼。不能只看到满意度达到6就开放结尾；偏好和体力等级加成可能让满意度提前达标，却不会替代真实时长。

因此本线启动前要求当前体力至少7点，并把标准亲密节奏固定为“江辰回来前4个有效楼＋关门后3个有效楼＋1个收尾回复＋1个不计账余韵回合”。无效输入只停留在当前节拍，不会把丈夫提前召来，也不会用一楼亲密冒充完整场景。

## 四、玩家地图流程与逐步回合

## 第1日：他会回来

### 步骤A1　商店购买《不必停》

- AI回合：0
- 操作：商店购买剧情道具`安若妍·《不必停》`；进入背包。
- 只扣款并取得道具，不安排回程、不改变丈夫状态、不播放剧情。

### 步骤A2　到301主动使用

- AI回合：2
- 地点：301
- 条件：安若妍在301、江辰外出、没有医院硬锁、电话、其他特殊场景或普通亲密占用。

#### A2-1《回程消息》

安若妍向玩家展示江辰的确定消息：他会在两日后的晚上回301，取走一箱需要本人进入书房拿取的案件卷宗。

本回合只确定：

- 江辰回程日与时段；
- 返回原因；
- 他必须进入301，而非只在大堂取件；
- 不提前让江辰知情或接受。

#### A2-2《照常留下》

安若妍明确知道那个晚上原本属于她和玩家。她不取消、不安排躲藏，也不进行长篇关系询问，只确认玩家到时仍可按原约进入301。

本回合结束后：

- 路线激活；
- 301普通随机丈夫回家与亲密打断暂时冻结，避免抢占这次固定到访；
- 次日白天开放卷宗箱地图动作。

## 第2日：让他真正走进301

### 步骤B1　大堂／信箱区签收密封卷宗箱

- AI回合：0
- 地图硬操作：`签收301密封卷宗箱`
- 获得真实任务物：`江辰的密封卷宗箱`
- 不在大堂直接完成交付。

### 步骤B2　管理员室登记取件

- AI回合：0
- 地图硬操作：`登记301代收件与取件时段`
- 系统写入：江辰须在预约夜晚进入301书房取走卷宗；不允许AI改成楼下交接、快递转送或安若妍代拿。

### 步骤B3　回301，把卷宗放进书房

- AI回合：1
- 地图硬操作：`把卷宗箱放进301书房`

#### B3-1《放进他的旧位置》

玩家亲手将箱子放到江辰曾使用的书桌旁。安若妍看见后不要求改放玄关，也不提替丈夫送下楼，只短暂确认：这样他就必须自己走进301。

本回合成功后形成硬因果：

```text
江辰通知回程
→ 玩家签收卷宗
→ 管理员室登记本人取件
→ 玩家把卷宗放进301书房
→ 江辰必须在预约夜晚真实进入301
```

随后必须至少经过一个完整世界日，线路不锁玩家处理其他公寓内容。

## 第3日晚上：预约夜晚

### 步骤C1　回301核对现场

- AI回合：2
- 地图硬操作一：`确认卷宗仍在书房`
- 地图硬操作二：`把前门留作未反锁`

#### C1-1《卷宗还在原位》

玩家先进入301书房，亲手核对密封卷宗箱仍在江辰旧书桌旁。AI本回合只表现书房空间、卷宗位置和安若妍看见玩家再次确认这条进入理由；结束时两人离开书房。不能在这一楼同时写到前门、卧室和亲密开场。

#### C1-2《门没有锁》

玩家再到玄关执行`把前门留作未反锁`。AI本回合表现安若妍明知江辰能够正常进入，仍没有收起玩家衣物，并亲手让卧室门停在没有完全合上的位置；两人走进卧室，但停在正式亲密开场之前。

两个回合都只建立预约夜晚的空间状态，不创建普通亲密账、不扣体力，也不让江辰提前到达。前门没有被玩家反锁，但江辰仍凭名义丈夫的正常资格进入；这不是撬门、撤销门禁或人为把他传送进来。

视觉上不新增系统：C1-1可复用`ARY-NBS-04`或301书房当前背景，C1-2使用`ARY-NBS-05`。

### 步骤C2《他回来以前》

- AI回合：1
- 性质：线路专属亲密开场

安若妍知道江辰随时可能回来。她没有收起玩家的衣物，也没有把卧室门完全关严。开场只把两人送到可以继续操作的位置，不替玩家连续演完前戏、正戏和收尾。

本回合正文成功后：

- 创建唯一301普通亲密场次；
- 将《不必停》路线实例绑定到该场次标识；
- H2起完全交给现有普通亲密系统；
- H1不消耗体力，也不增加普通满意度；
- 启动前要求玩家当前体力至少7点。

## 五、亲密主体H1—H13

### 5.1 演绎与结算纪律

每个成功AI回复只完成一个明确节拍。线路不能用一句正文同时完成“开始亲密、丈夫进门、丈夫看见、玩家继续、丈夫接受和亲密收尾”。

普通亲密账与线路剧情采用暂停／恢复关系：

- H1创建零进度账；
- H2—H5正常结算4个有效楼；
- H6—H8暂停普通账，只演江辰撞见与关门；
- H9—H11恢复同一账并正常结算3个有效楼；
- H12完成普通收尾。

固定剧情回合绝不能冒充亲密有效楼，普通亲密有效楼也不能一楼跨过多个身体阶段。玩家行动或正文没有让安若妍真实参与时，本楼不计数，线路留在当前节拍。

## H1　线路专属开场

- AI回合：1，已计入C2。
- 只演安若妍明知江辰随时会回来，仍让玩家留在夫妻卧室，并把下一步交还给玩家。
- 专属剧情CG接管一次；正文成功后建立零进度普通亲密账。
- 本楼不扣体力，不增加满意度或有效楼数，不能把脱衣、前戏、交合和收尾塞进同一回复。

## H2—H5　丈夫回来以前

- AI回合：至少4个普通有效回合。
- 玩家自由输入具体动作，每个成功有效楼继续使用普通体力、满意度、保护、偏好与成人CG。
- 四楼承担完整的递进空间，而不是规定玩家必须使用唯一姿势：
  1. H2建立真实身体接触，不能仍停留在纯对话；
  2. H3推进前戏和安若妍的实际参与；
  3. H4进入深度前戏或同等级明确性行为；
  4. H5让现场达到丈夫一眼即可确认的持续高尺度状态。
- 玩家走得更慢时，线路继续停留在相应阶段，直到累计4个安若妍本人有效楼且现场已经明确进入高尺度行为；不能靠偏好加成或AI一句“过了一阵”跳过。

丈夫到达前必须同时满足：

1. 同一绑定场次仍在进行；
2. 安若妍个人有效楼数至少4；
3. 当前现场已是无歧义的高尺度亲密状态；
4. 安若妍没有中止，玩家没有离开301。

## H6　前门打开

- AI回合：1个固定回合。
- 普通亲密账暂停，不扣体力、不增加满意度或有效楼数。
- 只演江辰打开301前门、看见客厅里的玩家衣物，并从卧室方向听见足以让他继续走近的动静。
- 本楼停在他走向卧室，不能已经看见、接受并关门。

## H7　他在门边看清

- AI回合：1个固定回合。
- 继续暂停普通亲密账。
- 江辰走到半开的卧室门边，明确认出玩家与安若妍，也确认这不是误会或普通暧昧。
- 安若妍看见江辰，但系统不替玩家决定停下或继续；画面停在三人视线真正碰上的一刻。

### H7交互幕

- AI回合：0。
- 正文与普通输入暂时隐藏；画面停在卧室门边。
- 核心瓷砖：`继续刚才的动作`
- 辅助退出：`停下，本次暂缓`

只有玩家点击继续，才能提交“丈夫已经明确看见后仍不退出夫妻卧室”的核心行为。暂缓不会吞掉第1—2日硬事实；至少经过一个完整世界日后重新安排预约夜晚。

## H8　他从外面关门

- AI回合：1个固定回合，由交互成功后自动生成。
- 本楼先明确演出玩家继续、安若妍本人没有撤回，保证江辰看见的是双方共同选择；随后江辰不质问、不观看、不加入，从外面把卧室门重新关好，转身去书房取卷宗箱。
- 本楼仍不扣体力、不增加满意度或有效楼数。
- 成功后第一次写入：`江辰已用行动接受本次互不干涉`。
- 专属结果CG保留到正文成功；随后恢复原场次标识、体力、满意度、有效楼数、保护状态和当前行为，不能重新建账。

## H9—H11　丈夫就在隔壁

- AI回合：至少3个普通有效回合。
- 玩家继续使用现有亲密界面自由决定动作。
- 固定情境事实：江辰仍在301书房，已经知道卧室里是谁，并主动关上了门。
- 三楼分别留给关门后的禁忌反应、继续深入和临近收尾；具体动作仍由玩家决定，AI不得一楼直接跳到高潮。
- 每楼正常消耗体力、增加满意度、使用保护与普通／孕态CG；普通丈夫打断不能再次发生。

H11成功后，安若妍在本场应累计至少7个个人有效楼。由于每个有效楼至少提供基础满意度`+1`，这同时保证满意度不低于当前目标6，不再依赖偏好或体力等级加成提前凑数。

## H12　按普通亲密系统收尾

- AI回合：1。
- 只有同一绑定场次、安若妍个人有效楼数至少7、满意度至少6且她仍在场时，才开放线路认可的收尾。
- 玩家体力仍有剩余时，继续使用现有收尾面板；该回复通常成为第8个个人有效楼，处于安若妍7—8楼的理想区间。
- 玩家以7点体力开场并在H11恰好耗尽时，下一楼由现有系统免费演出失控收尾；个人有效楼数保持7，线路同样接受，不会要求重演或判为一楼亲密。
- 承接线不锁定射精位置，不跳过普通受孕判定，也不把江辰设为收尾对象。
- 在7个有效楼以前请求普通收尾时，线路应明确阻止并保留当前账；安若妍中止、突然离场或场次标识不符则不进入事后接受。
- 本楼只负责完成玩家选择的收尾和最直接的身体结果，不能同时让两人整理完毕、走出卧室并与江辰谈妥长期规则。

## H13　门外的卷宗箱

- AI回合：1个固定余韵回合。
- H12已经结束普通亲密账；H13不扣体力、不增加满意度或有效楼数，也不再次触发受孕或收尾。
- 使用`ARY-NBS-13`表现关闭的卧室门仍在、门外传来卷宗箱扣合或脚步声、安若妍与玩家在卧室里完成最低限度整理。
- 安若妍不长篇解释象征，也不立即向江辰道歉；本回合只让刚才的事实沉下来，并停在两人准备打开卧室门、出去面对江辰之前。
- H13成功后才开放`出去见江辰`，避免普通收尾正文被迫同时承担高潮、余韵、穿衣、换场和三人谈判。

标准亲密主体为：

```text
H1零进度专属开场
→ H2—H5四个普通有效楼
→ H6江辰进门
→ H7江辰看清
→ 玩家点击继续
→ H8玩家与安若妍不停止、江辰关门
→ H9—H11三个普通有效楼
→ H12普通主动／耗尽收尾
→ H13卧室余韵与出门前转场
```

共13个AI演绎回合。收尾前已经具备7个安若妍个人有效楼，主动收尾通常完成第8楼；固定撞见剧情和H13余韵都不会污染普通亲密账。

## 六、事后接受与最终登记

### 步骤D1　301客厅见江辰

- AI回合：2

#### D1-1《不用解释》

## 九、亲密系统兼容契约

本线在产品分类上是承接剧情，在代码上应采用：

> **独立301线路状态机＋绑定唯一普通301亲密场次。**

不得把它放入会屏蔽普通亲密账的“独立结算特殊场景”路径。

正确接法：

```text
线路H1专属开场
→ 创建并绑定唯一301普通亲密场次
→ H2—H5累计4个普通有效楼
→ H6—H8专属事件CG临时覆盖并暂停普通结算
→ 恢复同一个普通亲密场次
→ H9—H11累计至7个个人有效楼
→ H12普通主动／耗尽收尾
→ 线路读取同一场次结果并结束普通账
→ H13固定余韵回合
→ 开放事后客厅
```

必须保留：

- 原场次标识；
- 已消耗体力；
- 安若妍满意度与有效楼数；
- 当前行为与接触部位；
- 保护状态；
- 当前普通／孕态图库；
- 玩家正常收尾权；
- 普通受孕规则。

H6—H8事件CG只是上层视觉遮挡，不能清空底层成人CG状态。三个固定回合必须走线路自己的“暂停普通亲密结算”门，不得被资源层误算为有效楼。事件图关闭后按当前最新CG信号恢复；生成失败时保留当前事件图和节拍，不要求玩家重做已经成功的交互。

江辰始终不是普通亲密参与者，不获得满意度、不进入多人CG、不成为主焦点或收尾对象。

普通体态与孕态继续硬隔离；缺少对应线路专属孕态图时宁可显示安全占位，也不能回退普通体态冒充。

## 十、失败、冻结与续接

- 购买后使用失败不消耗道具；
- 第1—2日已经完成的卷宗、登记和书房放置不会因错过夜晚重演；
- 医院、生产、电话、其他强制剧情或特殊场景占用时冻结原预约，解除后重新安排；
- 启动亲密前体力不足7点时不进入H1；
- H1只建立零进度普通账，不能被资源层误算为第一个有效楼；
- H2—H5未达到四个个人有效楼或现场仍不足以明确撞见时，江辰不到达；
- 安若妍中止、玩家突然离场或普通场次异常结束时，本次夜晚失败，路线回到待重新预约；
- H7选择暂缓时保留第1—2日硬事实，至少经过一个完整世界日后重新安排第3日现场；
- H6—H8生成失败、取消或同楼重掷不推进江辰认知和接受，也不得增加普通满意度、有效楼数或消耗体力；
- H8成功后不能被普通丈夫打断覆盖，也不能重复关门；
- H9—H11不足三个个人有效楼，或全场个人有效楼总数不足7时，不开放线路认可的H12收尾；
- 偏好或体力等级加成只能增加满意度，不能代替7个真实有效楼；
- H12正常主动收尾或达到7楼后的体力耗尽收尾完成后，只进入H13余韵；H13成功后才开放D1客厅；
- D1正文成功但玩家尚未到管理员室登记时，江辰接受事实保留，承接仍显示待最终登记；
- D2重复点击幂等，不重复写完成ID或再次修改丈夫到访规则。
