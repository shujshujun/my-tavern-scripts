## 一、这条线要讲什么

许曼君已经在私下选择了玩家，但她每天仍然替丈夫收工资、替娘家填窟窿、替所有人把日子安排妥当。她不能永远一面接受这个家给予的信任，一面把自己的另一种生活藏在账外。

承接讲她如何准备独自承担生活；结局讲她如何承认自己的选择，以及这件事如何伤害、改变三个人。

最重要的区别：赵国强不肯接受妻子与玩家的关系。他不会成为另一位观看者、默许者或被把柄堵住嘴的丈夫。他退出，是因为他拒绝继续生活在这个已经改变的家庭里，不是因为玩家赢得了对他的支配权。

许曼君也不会通过“丈夫原来很坏”免除自己的责任。她可以承认他对这个家的付出，同时不再选择跟他过下去。

## 四、两个事件各自做到哪里

| 事件 | 必须完成的事实 | 明确没有完成的事 |
|---|---|---|
| 承接《独立账本》 | 她能保留收入；对娘家的额外要求有边界；个人生活与旧家庭账已区分；重要物件可由她自行取用；她明确提出分开生活；赵国强已收到这个决定和正式谈话安排 | 不揭露私密细节；不提交丈夫离场；不改租约或清空欠租；不自动开始结局 |

她是否有退路、是否打算分开，是承接的答案。结局不再重复考试，只处理这个答案被当面说出来以后会发生什么。

## 五、《独立账本》：建议四个游戏日、六个节点

以下日期是从任务启动起计算的理想节奏，不是限时通关要求。前置未完成、作息不符或玩家暂缓时，后续节点顺延；时间只由现有的玩家时间操作推进，不因聊天轮数自动经过一天。

### 5.1 入口与开始

接管现有 `角色路线:201:操作性剧情` 占位，名称为“许曼君 · 独立账本”。

建议入口要求：

- 许曼君已到L5，相关阶段线与专属主题已完成；认已有完成记录，不重演旧场景。
- 201已入住，夫妻没有既成离场或无法继续的户级灾难。
- 许曼君没有处于医院硬锁；没有其他占用同一现场的强制剧情。
- 不要求此刻必须有欠租。账清的玩家也能开线，不能为了剧情强制造一笔新债。

商店只提供剧情用品“独立账本”，内容是一册分栏账、衣物工单夹和收纳袋。购买只扣购价、入包；不免租，不建立客户，不改夫妻状态。价格在实现前按同档剧情商品定标，不拿票价解释为现实账本的成本。

玩家在许曼君在场、赵国强正常外出时，把用品带到201。使用成功启动第一幕。已有空窗直接利用，不再次要求钓鱼券，也不强制撬门。

### 5.2 第一日，201：《这张卡以后不该由我收了》

开场不是她哭着缺钱。她已经把旧账本、丈夫的工资卡和自己的零钱铁盒并排放在桌上，正在整理下一期家用。

一张赵国强留下的生活采购单夹在里面：她随手就能看出哪样买贵了，也知道他为什么买那样。用这个细节承认十二年的熟悉，不能开场就把婚姻写成纯粹的牢笼。

她向玩家提出的不是借钱：

> “他的钱一直交给我。我既然打算换一种过法，就不能还替他收着，再装作家里什么都没变。”

建议三拍：

1. 她说明自己已经打算结束共同生活，承认尚未把这件事告诉赵国强。
2. 玩家回应；她不接受“以后我全包了”作为唯一方案，也不否认玩家已经提供的帮助。
3. 她将以后的缝改收入单列，要求玩家帮她把零散熟人活变成公开、正常收费的生意往来。

**玩家行动：**带走她亲自填写的“缝改接单告示”，前往大堂登记张贴。

**本节点结果：**她的决定与接单规则成立。工资卡仍是待归还物，旧账不动，丈夫尚不知情。新账只记她此后的收入和支出，不从旧共同账里偷搬资产。

### 5.3 第一日至第二日，大堂与信箱区：《这回照价收》

告示沿用她现有缝改手艺，不把她包装成从零起步的创业新人。

玩家在大堂确认告示，再到信箱区领取按该告示送来的首批工单。新客户只需用已有人脉的菜场王姐或普通街坊承载，不增加永久主要角色。

首单可以是一小批摊位围裙。玩家负责把衣物和工单交给许曼君，工作由她完成。经过一个明确的可工作时段后，201出现“领取做好的衣物”，再由玩家送到大堂交付。

客户照例说一句“熟人就给个方便”。许曼君亲自报出约定价，解释哪里改过、哪里没有必要花钱，最后仍笑着把找零算清楚。她没有变得冷漠，只是不再把熟络等同于免费劳动。

**关键证据不是一笔天降巨款，而是：**客户验收、真实付过工钱，并留下下一批工单；她把这次回款留给自己的生活，没有立刻汇走。

建议交付现场两拍，避免把领取、检查、找零拆成数个无意义按钮。

收入按角色生计事实记录，不加到玩家现金，不新增可供玩家无限提款的住户钱包。具体工钱由固定剧情配置提供，AI不能自编金额；这一次试单不能被夸成已经永久保证收入。

### 5.4 第二日晚，201：《阳台上的电话，这回没有关门》

许家照旧打来电话，要求她在原有支出之外再多承担一笔。这里选用非紧急的额外开销，不拿母亲急救费强迫玩家在救人与独立之间二选一，也不突然增设巨额赌债。

她起身时仍本能地想去阳台、关门。看到新账和已经留下的工钱，她停住了。这次她没有请玩家替自己接电话。

建议三拍：

1. 她听完要求，先分清已有承诺、必要支出和这一次追加。
2. 她明确拒绝追加，不再许下“我想办法”，但保留自己愿意承担、在能力内的正常照顾。
3. 对面不满意，电话挂得不愉快。她没有再补发转账，也不因家人一句指责立刻推翻决定。

玩家有一轮回应空间，可以听她说、提醒她休息、表达支持；不替她骂家人，也不靠选一句标准答案完成节点。

她不会因此突然轻松。她说不出漂亮宣言，只把铁盒重新合上，问玩家：“刚才那句话，是不是挺难听的？”她需要承受拒绝别人后的不安，但不再撤回拒绝。

**本节点结果：**本次额外承担被拒绝，收入保留。仅房内演出“许家来电”，不新增通讯录联系人，更不能和302母亲电话系统混用。

### 5.5 第三日，201→管理员室→201：《先把日子分开》

玩家和她做三件有后果的准备，合并为一次整理、一趟管理登记，不逐张证件盖章。

1. **她整理自己要带走或留下的物件。**个人文件、接单夹和工钱由她收好，带钥匙的收纳袋由她保管。丈夫的工资卡与共同账另放，准备当面交代；不让玩家控制她全部证件。
2. **玩家出具真实房租记录。**在管理员室读取201当前应收、欠租和已处理事实。欠租为零就写零；有旧账就原样保留。账目副本不能被解释成“已经偿清”。
3. **她登记未来单独继续居住的意愿。**这只是待生效安排：赵国强仍是当前住户，门锁、门禁和作息都不提前改变。若最终不能按计划留在201，随身物件保证她能先离开现场，管理登记不是安全保证。

此时大堂已有按约定验收的工单，下一批订单仍在正常接续。她已有工作能力和客源；新方案改变的是收入去向与工作边界，不是玩家凭一张申请替她创造生计。

该日允许保留一小段安静的两人对话。她拿起赵国强常穿的工作裤，确认那条补过的线还牢。玩家不能要求她把所有旧物扔掉以证明归属，她也不需要假装十二年没有一点值得记住的事。

### 5.6 第四日，大堂：《先让他知道，她是认真的》

按赵国强真实回楼时段安排他看见接单告示。无需新增侦探谜题，也不把丈夫写成第一次知道妻子会缝衣服。

他开始可能还高兴：“早点明着收钱，省得你夜里忙。”这句回应先兑现原人设。

随后许曼君当面告诉他：她今后会自己收这部分钱，也不准备继续替他管理工资；她打算分开生活，旧账会逐项交代。

他第一次冷下脸。他可以问是不是娘家又要钱、是不是自己做错了什么；她不让这些问题把话题带回“再补一笔钱就照旧过”。

> “娘家的事我会说清。可我说分开，不只是因为那笔钱。”

她提出择一个三人都能到场的晚上，把家用、房租和她与玩家的关系说清。此处只让他知道玩家必须在场、事情不仅是账，不提前替最终摊牌讲完全部真相。

赵国强答应来谈，**不等于答应分开或离场**。他可以留下：“把话想好，到时候别只给我半句。”

### 5.7 第四日晚，管理员室：《这次你也得在场》

当晚她到管理员室，把整理好的记录交给玩家，再明确一点：

> “钱的事我自己交代。轮到我们的事，你别把自己说成只帮了个忙。”

玩家确认愿意出席，承接事件最终提交。若玩家暂不愿面对，只停在该节点，不把她写回羞怯拒绝，也不无声判定结局成功。

### 5.8 承接完成证据

- 已验收并支付的首单、真实留下的续单，以及由她自己保管的收入事实。
- 已完成一次对许家追加要求的拒绝，而非手机里一条未发送草稿。
- 可回看、仍与正式账一致的201账目副本；随身物件归她。
- 她已向赵国强提出分开；赵国强亲自回应过正式谈话安排。
- 玩家已确认自己会以当事人身份出席。

这些事实齐备后，只解锁《清账》。不自动购买，不拉丈夫当晚强制上门，不提前公开全部关系。

## 六、《清账》：一场真正难以轻松获胜的结局

### 6.1 开始前

接管现有 `角色路线:201:结局剧情` 占位。承接完成后上架独立场景票“清账”，购买仍只入包。

玩家将票带到许曼君所在的201，当面确认正式谈话。系统复核人员、账目和现有医院、强制剧情、户级灾难状态，再安排下一个真实可用的晚上。过期预约可重约，不能无限等待一个已经过去的时段。

这次会面选择**大堂值班桌**。玩家并非中立调解人，不能用管理员身份掩盖自己参与关系的事实。公开地点也有代价：发生争执以后，楼里会知道201出了事。

会面安排与前面接单建立的交取衣物时段衔接，现场有真实在取件的普通街坊；这属于需要实现的有限路线演员安排，不能假设空荡的大堂天然存在见证人。旁人不代替三人作决定，也不承担必定阻止暴力的保证。不以“填过值班记录”宣称绝对安全，不强制其他可攻略角色到场做保镖或围观。人物移动必须通过路线现场状态表达，不能拿普通聊天台词代替到场。

### 6.2 第一幕，201：《她最后整理了一次他的行李》

约定前，玩家陪她核对要带去的文件。她另外把丈夫常用的工作衣物和日用品分开放好，但没有提前扔出门，也没有代替他收走私人物品。

她惯性地替工作服捋了一下领口，停了停，才把衣服放回。这里不要让她忽然哭着求玩家告诉自己该选谁——选择早在承接做出；难过的是实施这个选择必然伤人。

玩家带账目副本，她自己拿工资卡和旧账。去大堂前，201仍是夫妻当前住处。

### 6.3 第二幕，大堂：《十二年的账都算得出，信任算不出》

建议三拍：

1. 赵国强到场，质问家事为什么要在外面谈。她坚持在这里把话说完，没有把玩家推到前面挡着。
2. 她交回工资卡，交代娘家开支、隐瞒和房租事实。这里消费已有裂缝与承接记录，不能新编“赵国强欠了一大笔债”。
3. 他发现问题不在少了多少钱，而在于自己始终以为这个家无须怀疑。他可以把卡推回来：“这十二年，我哪回不是交给你？”

她不否认，不数落他不会浪漫来抵账。她承认他一直交工资、干家务，也承认自己瞒了事情。

本幕结束，旧账的情况被讲清，但没有额外扣款、补款或债务转移。任何钱的处理都必须回到既有经济操作和明示的结算依据。

### 6.4 第三幕，大堂：《不是因为欠他的钱》

赵国强看向玩家，直接问两个人究竟是什么关系。

许曼君先回答，不能由AI编成玩家逼迫、用房租换取关系，也不能用债务替自己的选择打掩护。她可以承认帮助是相识的起点，但现在继续在一起不是还账。

> “你交给我的家用，我会一笔笔交代。可我跟他的事，不是拿那笔钱换的。是我自己选的。”

玩家必须获得真实的一轮回应。自由输入可以表达承担、歉意或坚定，不设置密码式正确选项；不能默认玩家说过终身独占承诺，更不能替玩家承诺放弃其他已存在的关系。

若玩家明确否认关系或退出，不能强行播放情侣成功收束。现场转为许曼君自行完成分开决定、路线暂停待处理；她独立生活的准备不会被撤销。本稿不把这种选择扩写成第二条完整好结局。

对于愿意继续的玩家，本拍的重点是承认自己也是造成局面的当事人，而非借管理员规则宣布胜负。

### 6.5 第四幕，大堂：《他确实会掀桌》

赵国强会出现真实的失控动作：推开椅子、拍翻桌边的杯子，向玩家逼近。力度、损坏物件和在场人由脚本确定，不能让AI自行升级成重伤、死亡或满楼械斗。

玩家可以后撤留出距离、承认冲突、要求把话说完；不设计限时闪避、拳击小游戏，也不让高体力自动把丈夫打服。

许曼君明确站在自己的选择上，但不借此羞辱他。她不说“你哪点比得上他”，也不把曾经的家用和照顾宣布成笑话。

他最后给她一个自己仍愿意接受的答案：“你跟我回去，这事还能谈。”

她拒绝。**这是承接中已作决定的兑现，不再掷一次婚姻值骰子。**她可以说：

> “我不跟你回去。你可以恨我，但我不能再说回去以后就跟从前一样。”

他明白留在201意味着每天面对自己不肯接受的关系。剧情不让他瞬间平静，只给他一个符合性格的动作：把工资卡收进自己口袋，停止继续谈钱。

> “屋子我不跟你争。你们也别指望我说一句好听的。”

这是他自己的退出决定。玩家没有拿租约赶他，也没有通过一场公开羞辱使他服从。

若玩家主动升级肢体冲突，或有既存危机打断，不得假装仍按正常成功分支继续。先结束危险现场、保存已知情事实，再由明确恢复入口处理；不把普通生成失败当成玩家主动挑衅。

### 6.6 第五幕，大堂→201→大堂：《钥匙是他自己放下的》

赵国强表示离开后先住车队休息处，现在回201取自己的随身物。车队休息处只是与职业相符的场外去处，不新增可探索地图，不临时出现一个替他安排新人生的角色。

许曼君留在公共区域，玩家不趁机进201摆出新男主人的姿态。通过一个明确的等待／确认节点，让赵国强取走前面已经整理好的个人物品，随后返回大堂。

他放下201钥匙，确认不再住这里。玩家记录钥匙与居住联系人变更。只有这次实际交接成功，丈夫日常作息和门禁资格才转入离场状态。

钥匙本身不是万能物件：门禁作废或换锁登记必须与退出居住的事实一并提交；不能仅凭收回一把钥匙就宣称所有旧钥匙都失效。

他临走可以看她一眼，也可以一句话不说。他不祝福、不喝送别酒、不留在楼里继续当保护者。允许遗留一项日后约时间领取的普通物件，但不是隐藏骚扰循环。

系统此刻登记“已分开居住、赵国强已离场”，不伪称法律离婚即时完成。不删除他的历史聊天和过去共同生活的记忆。

### 6.7 第六幕，201：《她先坐了下来》

玩家和许曼君再次进入201。这一幕必须发生在丈夫真实离场之后。

屋子没有立刻焕然一新：缝纫机还在，辣椒还在阳台，她留下的旧物也还在。改变的是今天晚上由谁决定这里怎样生活。

她打开灯，把工资卡原来放的位置空出来。她没有把玩家的钱包塞进去代替，也没有立刻要求玩家交工资证明自己。

简单热一点吃的即可。往常她要先忙完、把别人安排好才坐下；这次她关掉缝纫机，把明天的工单合上，自己先坐下，招呼玩家过来。

> “明天的活，明天再做。先吃吧。”

允许她疲惫、难过，也允许两人牵手或拥抱。气氛是终于不必把见面藏在丈夫外出的间隙，又知道这份生活付出了代价；不能写成击败丈夫后的庆功宴。

这段有效正文落地后，《清账》才整体完成。玩家不进入额外亲密互动也能完成，拒绝或结束可选互动不得让丈夫回楼或撤销新生活。

## 七、玩家真正做了什么

| 玩家操作 | 改变的事实 | 后面的剧情为什么因此成立 |
|---|---|---|
| 买用品并送到201 | 路线开始，许曼君提出方案 | 不靠后台数值突然宣布她要结束婚姻 |
| 张贴告示、递送工单、交付成品 | 原有手艺形成一次可核验的正式交易与后续联系 | “以后自己过”有实际凭据，不只有一句豪言 |
| 参与许家来电后的对话 | 她完成一次有代价的拒绝 | 原来每笔收入马上填回窟窿的循环被打断 |
| 读取并带回真实租金记录 | 过去的钱有清楚依据 | 终幕不靠AI乱编财务罪状或凭空清零 |
| 确认出席、主动预约和赴约 | 正式对话发生于具体时间地点 | 玩家必须面对自己参与的关系，不能只当文件搬运者 |
| 当面回应赵国强 | 玩家立场真正进入场景 | 不默认玩家无辜、无条件承担或作出独占承诺 |
| 确认离场交接，再回201 | 居住状态改变并被生活场景验证 | 结局不止是丈夫台词里说一句“我走了” |

日常节点之间可以继续经营和其他角色互动。只有当次连续谈话短暂占用强制剧情槽，不把整个四日承接或预约等待锁成一场特殊场景。

不使用新小游戏、伪证、偷看手机、跟踪取证、匿名刺激、药物或丈夫观赏安排。上述功能并非201这条线因果成立所必需。

## 八、结局以后必须留下什么

### 8.1 许曼君的生活与关系

- 她继续精明、会砍价、记工单，遇到额外委托仍会谈报酬。结局不治掉她所有性格特征。
- 她不再用“欠了你所以必须陪你”解释关系；仍保留已经建立的偏好，不把偏好当必须清除的毛病。
- 玩家不自动获得她的工资、证件、居住支配权或排他承诺。她有自己的订单、朋友和拒绝。
- 201的普通邀请可以来自收工、一起吃饭、帮忙挑布，而不再每次以催租和丈夫外出开头。
- 她偶尔会记起赵国强，不因此重置关系进度，也不被要求每次出场证明自己绝不后悔。

### 8.2 经济：旧欠租保留，未来不再强制欠租

源码目前把201固定为 `天生欠租: true`，月租字段为900，收租周期为9个世界时段。不能照现实月份等一个月，也不能不看真账随口编出欠款数额。

本稿建议：

1. 承接期间仍沿用原经济规则，副本只展示，不制造新账户余额。
2. 结局前已到期的欠租和经营责任全部保留。未来的分开生活不能替她消除既有账务，也不能把赵国强相关历史欠款强制改判为她个人新债。
3. 正式完成后，201未来到期租金切换为普通住户的正常到账语义。依据是原有劳动收入开始优先保障生活，且已有持续接单关系；这是住户生计抽象，不新增经营小游戏或玩家收益加成。
4. 切换从完成时刻之后的到期账开始，保留原入住相位和收租水位。此前积累的到期账不能被快进结算误算成已经正常缴纳。
5. 历史欠租继续通过明确的现有处理入口结算；不得在《清账》最后一拍悄悄归零，也不能把宽限写成已实付。
6. 经济模式改变与最终结局提交绑定。丈夫已离场、最终201收束尚未完成时，界面要明确当前状态，不能出现完成一半但提前返款或重复租金。

需要实现时为201增加按完成事实派生的收租分流，不能全局改掉静态“天生欠租”或改变所有旧档。当前源代码尚没有这项新效果，本文不把它当作已支持。

“向妻子要钱”的旧通用台词在次数增加后会写她去向丈夫开口，201结局后必须独立审查：不能继续生成赵国强出钱，也不能借此新增一个无限收入源。

### 8.3 赵国强的长期状态

- 日常作息、在场头像、窗灯、随机撞见、普通丈夫打断停止把他放回201。
- “已经知道关系”是独立事实，不能靠送礼或疑心下降恢复成不知情。
- 后续仅允许一次明确预约的取物余波；不因刷新、跨天或手机重试重复生成。
- 历史聊天保留；不再自动发夫妻日常、共同计划或普通回家消息。
- 不把他的离场复用成“201整户搬走”，许曼君和房间仍在。

### 8.4 手机、街坊与风闻

三层认知分开：

- **街坊／公开朋友圈：**可以知道夫妻分开住、许曼君开始正式接活。见过大堂争执的人只知道亲眼听见的范围，不会自动掌握所有历史。
- **姐妹群：**在她真实发言以后才能传播相应事实。没入群、不在场或尚不知情的角色不能通过后台结局标志变得全知。
- **私聊：**她与玩家可以直接谈当晚、以后邀约和生活安排，不反复担心丈夫随时进门。

结局后安全手机节拍允许一次非阻塞余波：她说清201以后由自己住、接活照常；其他人按真实关系回应。周小满若已经在场且可参与，可以因她过去的照应作出个人回应，但不能成为强制通关角色。

公开争执产生一次与现场相称的风闻事件，不免费洗掉旧风闻，也不全楼永久广播私密细节。数值沿用现有事件档位核对后再定，不随意另加一套“结局惩罚”。

### 8.5 孕产与已有孩子

- 不以怀孕、孩子归属或亲子鉴定作为本线必须条件，也不添加原人设未存在的孩子。
- 进入医院、待产或恢复限制时，相关当面节点暂停；不能为了约谈把她从病房传送回201。
- 已有孕情、胎次、来源和已完成告知保持原样。结局不能追认玩家为某个已有孩子的生父。
- 丈夫离场后，取消或失效化尚未执行的201普通丈夫孕情登门，并保留已经发生过的历史。
- 之后的陪诊、生产、探望依据当前真实家庭关系选演员，不能照搬夏乔的三人家庭后效。

## 九、实现边界备忘：先让故事成立，再做定向接线

本节是后续实现要求，不是本轮已经完成的代码审计。

| 层 | 必须持久保存／派生的内容 | 不允许的替代 |
|---|---|---|
| 路线状态 | 当前节点、订单交付事实、拒绝追加事实、整理结果、丈夫已收到谈话要求、预约与完成记录 | 靠聊天摘要猜“她应该准备好了” |
| 现场剧情 | 当次演员、地点、待发送节拍、有效正文提交令牌 | 暂停后仍长期占着全局生成锁，或从台词临时猜在场角色 |
| 关系硬事实 | 丈夫知情、分开意愿、退出居住、最终结局完成 | 一个疑心数值代替全部状态 |
| 账务 | 实时欠租来源、账目副本修订、结局收租切换时刻 | 复制一套独立现金账，AI修改工资或欠款 |
| 软上下文 | 当前节点的短人物摘要、各人确实知道的事 | 向全员永久注入整场摊牌和全部账本 |
| 可选后效 | 手机通知、数据库摘要、画面、一次取物余波 | 任一辅助服务失败就撤销丈夫离场 |

核心读取链至少包含：商店／背包、地图与房间行动、场景事务与回合提交、时间推进与预约、经济、丈夫作息与打断、孕产登门、手机节拍与邀约、结局展示和存档恢复。不能只做一个“清账系统”文件就宣称全线落地。

一个事件ID配合有序节点即可表达的大部分过程，不扩散成几十个全局布尔值。状态结构和版本迁移须在实现前结合当时的Schema另作小范围确认；本稿不预先绕过存档协议。

地图文字必须使用实际地点名：“管理员室”和“302”是不同地点，旧草案把“回302办管理登记”混用的写法不再沿用。

## 十、失败、等待和回档

| 情况 | 设计行为 |
|---|---|
| 购买后未使用 | 只有物品，不开剧情、不分账、不通知丈夫 |
| 正文失败、超时、取消 | 当前谈话节点不推进，已提交的递送／收款事实不重复发生 |
| 同楼重掷、双击、迟到结果 | 按本次事务令牌判定，不能第二次给工钱、交钥匙或收租 |
| 凭据生成后普通收租改变了数额 | 重新读取并更新副本，保留此前节点成果；不沿用已经过期的金额 |
| 错过工作或约谈窗口 | 提供下一真实可用时段，不永久失败，不让丈夫在楼里无期限等候 |
| 跨节点等候 | 释放全局剧情槽；只有当前连续现场占锁，普通经营仍可进行 |
| 怀孕住院、临时冲突或已有强剧情 | 暂停预约并明确原因，不抢占已存在事件，不把角色临时复制到大堂 |
| 赵国强已知情但谈话中断 | 保留知情事实，进入明确的待恢复状态，绝不能回到“他仍蒙在鼓里” |
| 中断到跨时段 | 结束临时在场，记录三人分别离开现场后的去向；只对201应用该过渡，不冻结全楼丈夫逻辑 |
| 丈夫已实际离场，最终收束未完成 | 标为“已交接，待返回201”，开放继续入口；不重复交接或重播冲突 |
| 玩家明确退出这段关系 | 不播放恋人成功收束；保留她已获得的生活准备和已发生事实，不借回滚惩罚她 |
| 回档到关键动作之前 | 依时间线恢复人物、物件、账务水位和通知，旧分支回调不得写新档 |
| 旧档只有高阶段／旧结局轨道／《肉偿账本》 | 只认其原语义，不补造新承接或《清账》完成 |
| 新档没有订单、没有欠租 | 订单由新路线按节点生成；欠租继续是零，两者都不构成无解前置 |
| 图片、手机辅助生成、数据库失败 | 降级或后续重试，不影响已成功提交的主线硬结果 |

原有户级灾难不能被全程屏蔽。正式路线现场只接管自己已经负责的201冲突；范围外的真实危机照旧处理，也不得因新结局改坏其他五户。

## 十一、关键画面与节奏

本轮只确定叙事用途，不生图、不登记素材，也不固定必须凑满多少张。

| 画面 | 必须传达的变化 |
|---|---|
| 201桌上并排的工资卡、旧账和铁盒 | 她开始区分共同生活与自己的将来，不是否定过去 |
| 大堂接单，熟客笑着讨价，她笑着找零 | 手艺、精明与正常收费同时成立 |
| 阳台门没有关上，她握着已挂断的电话 | 她亲自承受一次拒绝的后果 |
| 她收好自己的包，把工资卡放回另一侧 | 自己的退路与应交代的旧生活都真实存在 |
| 赵国强先看告示，再看她 | 从放心到意识到婚姻发生了他不知道的改变 |
| 大堂值班桌，工资卡被推回 | 冲突的核心是信任，不是钱不够 |

建议承接六个节点、约12—16个有效对话节拍；结局六幕、约12—15个有效对话节拍。数量只是编排预算，不是让玩家机械回复相同话语的门槛。递送、账务和移动用真实操作，重要回应留给自由输入。

## 十二、设计自检与待讨论重点

本稿按以下问题检查过方向：

- 去掉AI修辞，接单、留钱、拒绝追加、提出分开、预约、知情和离场仍有明确完成证据。
- 没有重演L5的“账清以后仍会来”，也没有让丈夫突然变成多年财务施暴者。
- 玩家既有实际行动，也必须面对当事人；许曼君同时保有自己的声音和生计。
- 赵国强的退出有人物动机，不靠管理员夺房、催眠接受或AI一句“同意了”。
- 成功改变未来收租、丈夫在场与日常家庭叙事，同时保留历史债务、已知事实和回档语义。
- 群聊和画面失败不挡结局，没有把新独立生活绑在额外亲密互动上。

优先供用户讨论的三项是：**是否采用“不洗白背叛”的冲突基调；是否保留大堂正面摊牌与赵国强主动离场；是否把201未来恢复正常收租作为这条线的长期收益。**未获确认前，这三项和整份剧情均只是设计提案。
