## 一、结局核心

这不是把录像带路线换成夏乔，也不是丈夫观看、受辱或把妻子交给玩家的绿帽结局。

前五日证明玩家成功把“可信任的第三方”送进丈夫的考虑范围；赴约后的核心则是让三个人重新取得主动权：

- 陆嘉明主动提出请求，并明确自己愿意承担丈夫与父亲的位置；
- 夏乔不是被两个男人安排，她亲自确认对象、边界、时机，并拥有最后决定权；
- 玩家明确接受或拒绝丈夫的请求，并在夏乔亲自决定后遵守三人的边界；
- 孩子在社会与家庭关系上属于夏乔夫妻，玩家是知情的生物学帮助者，不因此取得对孩子或夏乔的所有权。

`孕欲`在这里仅是已经完成的一次阶段主题和路线前置。赴约以后不再重复注入性癖提示词，人物表现由本场共识、正文历史、数据库记忆、怀孕状态与户级关系事实承接。

## 二、赴约开场：丈夫先把真相说出来

地点固定为 101。最终计划板背景继续保留玩家姓名磁贴和“找个时间谈谈”。

### 第一拍：陆嘉明坦白

陆嘉明把男方检查报告、匿名资料和姓名磁贴一起放在桌上，由他先开口。他当着夏乔和玩家承认：三个月前检查结果已经出来，问题很可能在自己；他因为羞耻和害怕失去丈夫的体面，把报告藏了起来，让夏乔继续吃叶酸、测日子并把三年无果怪在自己身上。

这不是重复前置裂缝，而是第一次把玩家早已查到的秘密交还给夏乔。陆嘉明必须亲口承担，不能让玩家揭发，也不能用“怕你难过”一句话换取原谅。

夏乔会先本能地放大声音、试图把场面岔成普通家事，随后发现自己再也接不下去。她可以生气、追问和暂时不原谅，但不会在丈夫坦白以前进入借种讨论。

### 第二拍：陆嘉明提出请求

坦白完成后，陆嘉明才说明家庭计划带给他的答案：如果夏乔仍然想要孩子，他愿意接受一名双方都信任的人提供帮助；他保留玩家的姓名磁贴，是因为最终选择了玩家作为候选。

请求必须由丈夫亲口说出，内容包括：

- 他愿意继续承担丈夫和社会父亲的位置；
- 他不会把妻子“交给”玩家，也不能替夏乔同意；
- 玩家可以拒绝，不会因此承担公寓经营或关系惩罚。

这里是本场唯一一轮玩家文本瓷砖，不是地图上的房间行动。玩家只需明确`愿意听夏乔决定`、`需要先听清边界`或`暂不接受`，不再重新审判家庭计划前置中的匿名资料、监控和磁贴步骤。

### 第三拍：夏乔亲自确认

夏乔提出本场最关键的问题：玩家究竟是在帮助他们要一个孩子，还是借孩子取得她。

这里不再出现第二轮玩家答题。脚本先根据夏乔的当前阶段、好感／堕落／婚姻等真实数值、已经完成的`孕欲`线路、近期关系记忆和既有人格，确定她本次是`接受`、`延期`还是`拒绝`，正文模型只负责演出这个已经确定的结果，不能靠玩家选中一句正确台词改变。

表现必须仍是夏乔本人：行动先于自省，越紧张越忙、声音越大；她可以承认自己对玩家的欲望，也可以因丈夫隐瞒而暂时不愿继续，但不能突然变成等待两个男人替她决定的人。路线正常入口应已经用阶段和数值挡住明显不成立的状态；旧档或异常状态不满足时，由她延期或拒绝，而不是让玩家用选项说服。

### 第四拍：三人定规则

不再让三个人逐条谈判，也不做规则选择。若夏乔决定继续，陆嘉明只用一小段话说明固定安排：不观看、不记录；孩子由夫妻共同抚养；以后是否再与玩家亲密仍由夏乔决定。

陆嘉明留在客厅还是暂时离开101、今晚开始还是等下一窗口，都由夏乔结合当前关系状态亲口决定，不再交给玩家选择。她决定继续时，亲手把玩家姓名磁贴从“可信任的人”移到“孩子计划”；她决定延期时不移动磁贴；她明确拒绝时结束路线。

## 三、互动玩法：一次回应，随后由夏乔决定

本段只保留丈夫提出请求后的那一轮玩家文本瓷砖。它表达玩家愿意、想先听清安排或暂不接受，不承担“说服夏乔”的功能。

玩家没有暂不接受时，脚本立即按夏乔当前状态算出她的决定：

- `接受`：进入第一次尝试的时间与地点安排；
- `延期`：本场正常结束，以后由夏乔主动重新联系；
- `拒绝`：结束借种路线，不再通过重复选择改口说服。

没有三枚共识、完成位或三轮正确回答。固定关系边界属于剧情事实和生成纪律，在对话中自然说明一次即可；不扣资源、不运行怀孕判定，直到夏乔已经决定继续并且后续尝试真实完成。

## 四、特殊场景节拍

### A. 夏乔决定继续

夏乔移动姓名磁贴，亲口确定陆嘉明的等待地点与第一次尝试的时间。这里写入的是“借种安排已确认”，不是“已经怀孕”。

若夏乔决定等下个易孕窗口，本场在这里正常收束，101 后续于合法窗口出现`按计划赴约`，不重复丈夫请求和夏乔决定。

### B. 夏乔做最后选择

第一次尝试开始前，陆嘉明先按约定留在客厅或离开。无论哪种选择，他都不观看、不指挥，也不通过门缝或摄像头参与。

关门的人必须是夏乔。她按已经确定的决定靠近，也仍可在临场停下。这一拍承担从家庭安排到成人场景的转换，不让丈夫的一句“我同意”替代她的身体同意，也不再增加一轮答题。

### C. 第一次受孕尝试

成人演出可分两轮正文：

1. `靠近与再次确认`：保持夏乔主动性，并承接她与玩家已有关系；
2. `完成受孕尝试`：只有有效的无保护阴道内射结果，才可提交一次怀孕判定。

其他亲密行为可以出现在正文里，但不能冒充借种完成条件。玩家若临场改变决定、使用保护或选择体外结束，本场可以温和收束，状态回到“共识已立／待下次尝试”，不惩罚、不伪造受孕。

### D. 门重新打开

事后不使用羞辱、战果汇报或丈夫检查身体。陆嘉明只确认夏乔是否还好，并把准备好的水放下。三个人面对计划板，明确“今天只是一次尝试，结果还不知道”。

这拍用于把成人场景重新接回家庭关系，也是首次尝试成功提交的原子落点。

## 六、怀孕系统承接

### 不保证第一次成功

借种共识不是强制怀孕开关。每次真正完成的尝试继续走现有易孕日、60%／80%／100%连续失败补偿和一次判定纪律：

- 非易孕日不运行有效受孕判定；
- 生成失败、取消、重掷未提交、保护措施、体外结束或非阴道行为不占用当天判定；
- 有效尝试成功提交后，才由现有怀孕系统决定是否受孕；
- 未受孕时进入“待下次易孕窗口”，只复用简化的再次赴约，不重演五日前置和三人谈判。

### 不提前泄露结果

若判定成功，仍遵守现有`已受孕→待告知→已告知`生命周期。正文、手机、界面和计划板在正式告知前都不能提前宣告成功。

受孕场次只需带可识别的“101借种”来源，用于后续分支；不能为了显示结局而额外创建第二套怀孕真值。

### 告知后的结局落点

夏乔达到“已告知”后，触发一次短结局`计划成真`：她先告诉陆嘉明，再由夫妻共同邀请玩家到 101。计划板新增产检日期或完成标记，三人再次确认孩子的家庭身份。

此时才登记完整的“夏乔借种结局完成”。在此之前应区分：

- `借种共识已立`；
- `正在尝试`；
- `已受孕但尚未公开`（仅脚本内部可知）；
- `计划成真／结局完成`。

## 七、结局后的户级关系变化

### 夏乔

- 永久记住她亲自选择玩家帮助受孕，而不是被丈夫转交；
- 普通互动不再重复注入“孕欲”，只读取借种共识、真实孕态和既有关系记忆；
- 借种协议不自动授权所有后续亲密，玩家仍需面对她当下的选择。

### 陆嘉明

- 形成“知情并主动承担社会父亲责任”的丈夫事实；
- 对玩家的态度是复杂的共同守密者，不套用被蒙骗、撞破或观看取乐的丈夫轨道；
- 不能简单把信任值拉满。数值仍可按后续行为变化，但借种共识会改变怀孕曝光事件的解释方式。

### 101 户

- 最终计划板成为永久环境痕迹；正式告知后再升级为产检／孕期版本；
- 数据库记忆登记家庭安排确认、第一次尝试和正式告知三个独立事实，不把整段压成“玩家睡了人妻”；
- 高风闻导致孕情曝光时，101 不再触发通用丈夫质问或被背叛版本，而改为“夫妻保护家庭口径”的借种专属反应；
- 对外仍由夏乔夫妻决定如何说明，玩家的生物学角色默认保密。

## 八、失败、取消、重掷与回档

| 情况                     | 处理                                                       |
| ------------------------ | ---------------------------------------------------------- |
| 赴约谈话生成失败／取消   | 不取得共识，不清邀请票；下次从当前缺失共识继续             |
| 玩家暂时离场             | 保留已明确取得的共识，最早下一晚可继续；不写结局失败       |
| 玩家明确拒绝并二次确认   | 写入“已拒绝”，撤下赴约入口；只有回档可改变                 |
| 夏乔决定改天             | 正常收束到“待首次尝试”，不重复丈夫请求和决定               |
| 成人轮生成失败／取消     | 不记尝试、不扣当天判定、不运行怀孕、不清可继续入口         |
| 当轮没有达到有效受孕条件 | 回到“待下次尝试”，不伪装成功，也不惩罚                     |
| 同一成功正文被重复观察   | 共识、尝试和怀孕判定全部按票据幂等，只提交一次             |
| 重掷                     | 重放同一冻结事件；旧分支结果不得二次写入                   |
| 回档／删楼／切分支       | 路线状态、计划板背景、微信通知和怀孕真值一起随有效存档恢复 |

## 九、与其他大型场景的边界

- 赴约谈话和受孕尝试运行时，继续使用现有特殊场景／待发送事件互斥；不能与录像带、静音会议、荣耀洞、丈夫登门或普通持续亲密场景并发。
- 本结局只关闭 101 中语义冲突的“丈夫被蒙骗／孕情质问”分支，不把全楼其他特殊场景标成完成。
- 不复用录像带两户的监控互动、丈夫观看、绿帽愿者、失败补偿或 CG；前置第三天的监控只负责观察计划反应。
- 不把收租、胜任度或公寓经营数值设成借种成功门槛。公寓系统提供地点与生活背景，不成为结局核心玩法。
- 六项阶段性癖仍只是各自的一次阶段里程碑。本结局不能重新把性癖变成装备、常驻提示或通用特殊场景钥匙。

## 十、建议拍板项

本稿建议直接采用以下决定：

1. 借种第一幕固定为陆嘉明坦白男方检查结果、承认隐瞒，并在夏乔知情后亲口提出请求；
2. 夏乔按阶段、数值、关系记忆和性格决定继续后，家庭安排才确认；真实怀孕仍由现有系统判定，不保证首夜成功；
3. 丈夫留在客厅或暂时离开由夏乔决定，两者只改变演出，不分成绿帽／非绿帽两条结局；
4. 正式告知怀孕后才写“计划成真”，避免系统提前泄露受孕；
5. 借种完成后只替换 101 的语义冲突分支，不吞掉其他角色或全楼大型场景。
