# rq0.90.4 后本地 CG 淘汰与产品化审计

记录日期：2026-09-04。

## 一、审计边界

本审计只覆盖 `rq0.90.4` 正式发布之后在本地形成或接入的新功能 CG。判断顺序为：

1. 当前运行时生产者与消费者；
2. 当前状态机及旧档迁移入口；
3. 权威 manifest、任务状态、审核记录与 SHA；
4. `rq0.90.4` 标签和之后的 Git 历史；
5. 文件名、目录名与修改时间只作辅助，不单独决定淘汰。

未经本清单分类并取得对应用户确认的图片，禁止转换、删除、覆盖或改动接线。`rejected`、`superseded`、旧任务图和制作中间层继续按证据保留，不得因为不进入产品就删除原件。

## 二、状态定义

- **当前保留**：权威清单选中，且存在当前运行时消费者。
- **待产品化**：权威清单已选中，但尚未生成正式产品副本或发布闭包。
- **待用户确认**：代理审核已完成，但 manifest 仍明确要求用户终审。
- **公开旧档兼容**：新流程已取代，但 `rq0.90.4` 公开存档仍可能进入当前兼容路径。
- **已被取代但保留证据**：不再进入当前产品，仍须保留来源、审核、SHA或失败证据。
- **明确淘汰／拒绝**：manifest、审核或后继选择已明确排除；不参与转码和产品安装。
