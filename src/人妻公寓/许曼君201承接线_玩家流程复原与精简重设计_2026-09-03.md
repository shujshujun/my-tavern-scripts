# 许曼君 201 承接线：现有玩家流程复原与精简重设计

> 日期：2026-09-03
> 状态：**用户已确认，四幕优化方案已在当前工作区落地，尚未发布**
> 本文前半保留旧长流程复原与问题分析，后半记录已经落地的四幕方案。最终第四幕采用“一幕三段、两天完成”；完整实现与验证见[四幕优化落地与验收](./许曼君201承接线_四幕优化落地与验收_2026-09-03.md)。
> 当前外部发布仍是 `rq0.90.4`；未跟踪源码、测试与12张本地资源都不能视为已经进入远端版本。

## 一、先给结论

当前《分居》并不是“内容太少”，而是把真实性错误地等同成了办手续：

```text
准备封套
→ 接通知
→ 准备空袋
→ 投信
→ 确认取信
→ 取空袋
→ 大堂点名
→ 再进201
→ 开封套
→ 接钥匙
→ 去楼外确认离楼
→ 回管理员室第一次封存
→ 跨夜
→ 再验封
→ 收出车表
→ 完整亲密
→ 再取袋
→ 再验封
→ 再进201
→ 再装物
→ 再接钥匙
→ 再去楼外
→ 再回管理员室第二次封存
→ 再等冷静日
→ 再开最终会
→ 改钥匙用途
→ 第三次去楼外确认离楼
```

这些动作中有真实因果，但重复程度过高。玩家连续跑地图，实际能决定的事情却很少，主要只是反复回答“是否承担”。

当前已经落地为四幕：

```text
201初谈
→ 201三人摊牌
→ 管理员室一次封存，丈夫开始真实外住
→ 201独住夜；共同夜晚可当晚完成或以后再补
→ 丈夫唯一一次回201取完物品并提出修复
→ 完整经过一个世界日
→ 201私下决定婚姻与玩家关系
→ 管理员室离婚前交接
→ 同一枚封存钥匙改为“待离婚交接”
```

精简后的核心不是删剧情，而是：

1. 只保留会改变空间、权限、人物选择的地图动作；
2. 工资卡和钥匙仍然是硬事实，但不拆成十几次搬运点击；
3. 赵国强只预约回 201 一次；
4. 201 住户钥匙只封存一次，不再拆封、归还、重新封存；
5. 许曼君是否继续分居，不再被玩家是否承诺恋爱绑架；
6. 亲密场景保留，但不再用“满意度＋有效楼数”当离婚前置考试；
7. 201 留宿权限来自一次真实共同过夜和许曼君的明确允许，不来自性表现达标。

## 二、本次复原依据与当前接线边界

### 2.1 当前已经接入正式入口的主链

当前未跟踪的 `许曼君分居系统.ts` 已被以下正式文件直接导入：

- 客户端 `App.vue`：201 分居背景、事件 CG；
- `useRoomActions.ts`：地点动作与 201 过夜瓷砖；
- `档案卡.vue`：路线下一步；
- `游戏逻辑/index.ts`：动作事件、正文票提交、时间推进与睡醒地点；
- `snapshotSystem.ts`：长期事实注入；
- `商店系统.ts`：路线商品；
- `回合引擎.ts`：路线剧情约束；
- `时间推进系统.ts`：预约／跨日同步；
- `玩家资源系统.ts`：路线亲密收尾；
- `角色结局占位.ts`：后续《离婚》入口。

因此，当前 201 不是一组孤立草稿。它已经形成一条脏工作树中的主生产链，但这条链尚未封板、未发布，也不能因为接线很多就默认设计正确。

### 2.2 当前未形成正式消费者的拆分模块

以下模块目前主要是主状态的只读投影或另一套接口提案，没有形成完整生产消费者闭环：

- `许曼君分居丈夫认知.ts`
- `许曼君分居手机副作用.ts`
- `许曼君分居结局入口.ts`
- `许曼君分居背包.ts`
- `许曼君分居输入桥.ts`
- `许曼君分居钥匙柜.ts`
- `许曼君分居资源.ts`

`许曼君201留宿.ts` 只有 `归一化睡醒地点` 被当前正式入口引用，其他授权投影仍未形成唯一所有者。

这些文件不能为了测试变绿而全部强接。新设计确认后，应逐个决定：

```text
并入现有权威所有者
／保留为真正被消费的只读视图
／删除为重复草稿
```

### 2.3 当前存在的直接实现异常

`许曼君分居玩法.ts` 当前物理文件在 A3 剧情规格第三拍中途截断，属于真实语法残缺，不是简单的旧测试断言过时。

本稿只登记，不修复。原因是该文件本身代表另一套未封板接口；应先确认新设计，再决定修复、合并还是废弃。

## 三、当前玩家实际怎么玩

下面不是旧设计文档的宣称，而是按当前主状态机和正式消费者复原的正常正向路径。

### 3.1 解锁与购买

前置大致为：

- 许曼君达到 L5；
- 完成 201 阶段主题／“没有债也会来”；
- 完成《肉偿账本》；
- 《分居》未完成。

玩家在商店领取 0 元的《许曼君·分居》。领取只把路线改成待开始，随后必须等赵国强按普通作息外出，再去 201 找许曼君。

### 3.2 A1：201 初谈

地点：201。
人物：许曼君、玩家；赵国强必须不在场。

固定三回合：

1. 许曼君承认，自己虽然已经不是为了还债才找玩家，却仍按丈夫的出车空窗安排关系；
2. 她决定由自己提出三人当面谈，不让玩家代替她宣布离婚；
3. 玩家回答是否愿意出席、是否承担自己的位置。

若玩家拒绝或暂缓，路线停在第三回合前，可以以后重答。

同意后还要在 201 做两个独立硬动作：

1. 看许曼君把赵国强工资卡放进归还封套；
2. 接过她署名的会面通知。

### 3.3 A2：准备会面

玩家随后跨三个状态处理会面：

1. 去管理员室准备空的 201 钥匙封存袋；
2. 去信箱区把署名通知投进 201 信箱；
3. 等赵国强按真实作息回楼；
4. 再到信箱区点击确认通知被取走。

通知已取、空袋已准备后，系统向后搜索最多 42 天，找下一次夫妻都在 201 的安全晚上，登记第一次三人会面。

### 3.4 A3：第一次三人会面

到了预约时段，玩家依次：

1. 去管理员室取出空封存袋；
2. 去大堂确认三人到齐；
3. 再进入 201；
4. 启动五回合会面。

五个固定回合：

1. 三人坐下，赵国强问玩家为什么在场；
2. 许曼君归还工资卡；
3. 许曼君亲口说出她与玩家的关系；
4. 玩家当面承认或拒绝承担；
5. 赵国强拒绝当晚直接同意离婚，也拒绝三人婚姻，但决定先去车队外住，以后预约回来取物并谈一次修复。

第一回合后，玩家还必须单独点击“打开工资卡封套”，剧情才能进入第二回合。

若玩家在第四回合拒绝，工资卡已经归还、丈夫已经知情，但会面停住；玩家以后在 201 重答，不能重演前面事实。

五回合完成后，玩家继续：

1. 在 201 接住赵国强装好钥匙的封存袋；
2. 去公寓外部确认他第一次离楼；
3. 回管理员室完成第一次封存。

只有第一次封存成功后：

- 赵国强切换为路线外住；
- 普通丈夫作息暂停；
- 普通丈夫随机打断暂停；
- 只允许明确预约回楼。

### 3.5 A4：独住夜、亲密与留宿权限

第一次封存后，玩家回 201，进行两回合独住谈话：

1. 许曼君面对少掉的钥匙和刚结束的争执；
2. 她要求玩家也离开，让她真正独住一晚。

玩家随后：

1. 点击“把 201 留给她一晚”；
2. 离开并真实跨夜；
3. 次日去管理员室核对封条与取用记录；
4. 再回 201，陪她收起丈夫的出车表；
5. 等到安全晚上，再赴她的邀请。

邀请包含两个固定剧情回合。第二回合只建立一场普通 201 L5 亲密账本，随后玩家必须完整游玩现有亲密系统。

当前完整判据不是“正常收束”这么简单，而是同时要求：

- 201 是主焦点；
- 许曼君没有退出；
- 结束方式为主动收尾或体力耗尽；
- 满意度达到满意目标；
- 有效楼数达到满意目标；
- 时长评价不是“太短”。

未满足会回到再次邀请。

满足后还有两个事后回合：

1. 许曼君问，下次赵国强回来时玩家是否仍会站在这里；
2. 玩家再次回答是否承担。

当前实现会在第二回事后无条件先解锁 201 永久留宿。即使玩家随后拒绝面对丈夫，完整亲密和留宿允许仍保留，只是后续取物会面暂停。

### 3.6 A5：丈夫预约取物与修复提案

玩家同意继续承担后，系统寻找下一个安全白天安排取物。

到时玩家依次：

1. 去管理员室取出第一次封存的钥匙袋；
2. 去大堂让赵国强验封、取回钥匙；
3. 陪同进入 201；
4. 启动五回合会面。

五个固定回合：

1. 三人确认这次只处理约定用品；
2. 赵国强装好第二批生活用品；
3. 他提出减少非必要长途、参与家庭生活、重划娘家支出边界等修复方案；
4. 许曼君承认方案有分量，但拒绝恢复共同生活；
5. 玩家再次表态，赵国强准备归还钥匙。

第一回合后，玩家还必须单独点击让赵国强装好生活用品。

剧情完成后继续：

1. 在 201 接回第二次钥匙；
2. 去公寓外部确认赵国强第二次离楼；
3. 回管理员室用第二枚封条重新封存。

第二次封存后，系统再等待至少一个完整冷静日，并安排最终会面。

### 3.7 A6：最终会面

到安全白天预约时段，玩家去管理员室启动四回合会面：

1. 赵国强承认外住已成为真实生活；
2. 许曼君确认不恢复共同生活；
3. 玩家再次回答是否承担；
4. 赵国强同意进入正式离婚办理。

随后玩家还要：

1. 在管理员室把钥匙用途改成“待离婚交接”；
2. 去公寓外部第三次确认赵国强离楼。

到此《分居》完成，独立《离婚》结局才解锁。

### 3.8 当前正常路线的实际规模

不算失败重试、错过预约、地图移动点击与普通亲密内部回合：

- 固定剧情回合：`3 + 5 + 2 + 2 + 2 + 5 + 4 = 23`；
- 路线硬动作 ID：30 个，其中正常正向路径使用 28 个；
- 商店领取：1 次；
- 强制真实亲密：1 场；
- 真实跨夜：至少 1 次；
- 冷静等待：至少 1 个完整日；
- 预约：至少 2 次；
- 钥匙封存：2 次；
- 去公寓外部确认离楼：3 次。

因此，正常正向流程在普通亲密与走地图之前，已经约有：

```text
23 个正文回合
＋28 个硬动作
＋1 次商店领取
＝52 次明确输入／点击
```

这还没有计算移动、推进时段、等待预约和亲密内部回合。

## 四、现有方案的具体问题

### 4.1 流程过长，不是因为剧情丰富，而是同一事实被拆得太碎

“丈夫决定外住”被拆成：

```text
决定外住
→ 装袋
→ 楼外确认
→ 入柜
```

“丈夫回来取物”又被拆成：

```text
管理员室取袋
→ 大堂验封
→ 201取物
→ 再装袋
→ 再去楼外
→ 再入柜
```

最后还要第三次去楼外确认。

第一次完整演出确实能带来物件感，第二次大致重复，第三次只是在重复证明同一个人离开。

### 4.2 重复钥匙封存制造手续感，而不是生活变化

当前个人住户钥匙经历：

```text
丈夫持有
→ 第一次装袋
→ 玩家背包
→ 管理员室封存
→ 玩家再次取出
→ 丈夫验封并取回
→ 第二次装袋
→ 玩家背包
→ 管理员室第二次封存
→ 改用途
```

这条链技术上严谨，但玩家体验像保管员，不像参与一段婚姻真正分开的生活。

### 4.3 地图互动数量很多，价值却不等于数量

有价值的地图变化是：

- 201 从三人共同生活痕迹变为一人生活；
- 管理员室的 201 钥匙状态真实改变；
- 赵国强普通回家路径被关闭，只能预约；
- 玩家以后能在 201 过夜。

价值较低的重复动作是：

- 为同一场会面先去信箱投递，再回来确认被取；
- 大堂只用于“点名三人到齐”；
- 三次去公寓外部只用于确认离楼；
- 同一把钥匙两次装袋、两次入柜；
- 把 AI 会面内部自然能完成的开封套、装用品再拆成按钮。

地图动作应回答：“玩家不做，这个世界状态为什么不会成立？”
若答案只是“为了多点一次”，就不该保留。

### 4.4 玩家决定重复，且错误地绑架许曼君自己的婚姻决定

玩家当前至少在 A1、A3、A4 事后、A5、A6 多次被要求表态“承担”。

这并没有形成五种不同后果，只是在多个节点重复同一口令。

更严重的是：

- 玩家拒绝，许曼君的会面或取物路线就暂停；
- 她是否推进自己的分居，实质上被玩家是否承诺这段关系控制。

这与角色核心矛盾冲突。许曼君要完成的成长是：

> 她不再替任何人把决定算好，也不再靠丈夫或玩家给自己许可。

玩家的选择应改变“玩家与她以后怎样相处”，不应决定“她能不能离开已经决定结束的共同生活”。

### 4.5 跨日是对的，但当前等待被手续稀释

保留真实跨夜与冷静期是必要的，因为分居不能在同一晚口头完成。

问题是当前跨日之间塞满重复取袋、验封、离楼、再封存，玩家感受到的是排期，而不是：

- 201 真正少了一个人；
- 许曼君第一次独自生活；
- 丈夫有时间认真提出修复；
- 她在冷静后仍作出同样选择。

### 4.6 丈夫作息处理正确，但可以只保留一个真实切换点

当前正确点：

- 分居前必须尊重赵国强普通作息；
- 他本人决定外住并完成钥匙交接后，普通回楼与随机打断才暂停；
- 后续只能明确预约回楼。

不需要两次拆封才能证明这套机制。一次正式外住登记即可切换作息；之后一次预约由管理员陪同取物，丈夫的个人钥匙可以始终留在封存中。

### 4.7 亲密场景被做成了性能考试

保留一场“不再躲丈夫出车表”的 201 亲密是有价值的。它表达的是空间意义改变，而不是单纯奖励。

当前问题：

- 必须达到满意目标；
- 有效楼数还必须再次达到同一个目标；
- 时长不能太短；
- 不满足就整场重约；
- 这场结果又直接决定 201 睡眠入口。

这样玩家容易把剧情理解成：

> 性表现达标，才有资格在她家睡觉，婚姻流程才继续。

这既损害人物逻辑，也让弱模型、短场景、取消或正常但较短的互动更容易卡死。

### 4.8 201 留宿权限的语义混在三个概念里

当前同时混合：

1. 许曼君是否明确允许玩家过夜；
2. 201 此刻是否满足睡眠安全条件；
3. 一场亲密是否达到机械完整判据。

应拆开：

- **关系事实**：她是否允许；
- **现实条件**：她在场、丈夫外住、无医院／预约／强剧情冲突；
- **睡眠事务**：统一时间推进能否提交。

关系许可不应由满意度数值决定。

### 4.9 医院、孕产、打断的硬门方向正确，但要减少中间危险断点

当前路线已经考虑：

- 201 医院硬锁；
- 亲密进行中；
- 父亲电话；
- 特殊场景；
- 201 丈夫孕情登门；
- 其他待发送强剧情；
- 丈夫作息与预约。

但阶段越多，中断后越容易停在：

- 空袋已经取出；
- 钥匙在玩家背包；
- 丈夫持钥匙但还没进 201；
- 丈夫离楼但钥匙未入柜；
- 第二枚封条未完成。

精简阶段本身就是最有效的异常治理。

### 4.10 资源数量不应反向决定剧情步骤

当前 12 张本地资源尚未发布。不能因为已经有“第一次袋、第二次取物、最终钥匙柜”等画面，就让剧情必须保留所有手续。

正确顺序应是：

```text
先封板玩家流程
→ 再决定哪些现有图复用
→ 多余资源保留为本地候选或以后用途
```

不能用素材沉没成本绑架设计。

## 五、新方案的设计原则

### 原则 1：一次地图动作只能负责一个有长期后果的现实变化

保留：

- 201 当面谈；
- 管理员室登记外住并封存钥匙；
- 201 独住后的环境变化；
- 201 丈夫唯一一次预约取物；
- 管理员室把钥匙用途改为待离婚交接。

删除：

- 投信与确认取信的双跑；
- 大堂点名；
- 三次公寓外部确认；
- 两次拆封／两次封存；
- 单独点击打开封套、装好用品。

### 原则 2：丈夫与妻子各自作决定，玩家只决定自己的位置

- 许曼君决定是否分居；
- 赵国强决定是否外住、是否提出修复、是否进入办理；
- 玩家决定是否公开到场、是否继续这段关系、是否接受第一次共同过夜。

玩家拒绝不能让许曼君失去继续分居的能力。

### 原则 3：工资卡与钥匙仍是硬事实，但由场景提交原子化

- 三人摊牌成功后，工资卡归还与丈夫知情在同一剧情事务提交；
- 管理员室办理外住成功后，丈夫离楼、普通作息暂停、个人钥匙入柜在同一事务提交；
- 丈夫预约取物时由玩家用管理员权限陪同开门，他的个人钥匙不拆封；
- 最终只改变同一枚封存钥匙的用途标签，不再生成第二枚封条。

### 原则 4：跨日用来证明生活已经变化，不用来等待按钮

必须保留：

- 丈夫外住后的第一个完整夜晚；
- 取物与最终决定前至少两个完整世界日，或一个可调的真实冷静期。

玩家等待期间可以正常玩其他系统；只有真正正在提交的短事务才锁时间。

### 原则 5：亲密表达关系，不充当路线考试

正向体验保留一次完整的 201 共同夜晚，其中可以接入现有普通 L5 亲密。

路线只要求：

- 入口合法；
- 正常建立真实亲密账本；
- 没有被角色中止或安全取消；
- 正常收束到睡眠／离场。

不再要求“满意度目标”和“有效楼数目标”双重达标。

## 六、精简后的四幕完整流程

## 第一幕：201《不再看出车表》

### 进入条件

沿用合理前置：

- 许曼君 L5；
- 《肉偿账本》完成；
- “没有债也会来”已成立；
- 赵国强按普通作息不在 201；
- 许曼君在 201；
- 无医院、生产、电话、亲密或其他强事务。

商店仍可作为主动入口，但名称和说明应明确这是承接剧情，不是购买离婚结果。

### 玩家操作

进入 201，点击：

```text
和她谈那张一直挂着的出车表
```

### 固定三回合

1. 许曼君承认，她已经不再为欠债而来，却仍把关系藏在丈夫的作息空窗；
2. 她决定归还工资卡，并由自己约赵国强在 201 当面说清；
3. 玩家选择自己怎样参与。

### 第一个真实玩家决定

给出三个语义，而不是要求命中特定口令：

```text
A. 我会在场，亲口承担自己的位置
B. 你先亲口告诉他；需要我时我再进来
C. 现在还不能开始，暂缓
```

A 与 B 都能继续：

- A：下一幕从三人同桌开始；
- B：下一幕前两拍先由夫妻谈，第三拍许曼君再把玩家叫进来，仍让丈夫精确认知玩家关系；
- C：只停在待初谈确认，不生成任何物件或预约。

### 成功后的硬事实

- 许曼君决定分居谈话；
- 玩家参与方式已记录；
- 工资卡待归还；
- 系统按赵国强真实作息自动登记下一次安全晚上。

不生成玩家背包通知，不要求玩家代许曼君投信。

理由：由许曼君本人联系丈夫，更符合她“自己承担决定”的成长。

## 第二幕：201《把话说在这间屋里》

### 时间与地点

- 下一次赵国强按普通作息能够真实在 201 的安全晚上；
- 玩家到 201 主动启动；
- 错过后自动顺延，不扣除任何既成事实。

### 玩家操作

```text
参加约好的201谈话
```

### 固定四回合

1. 许曼君把工资卡亲手归还赵国强，说明未来收入不再由她代管；
2. 她由本人说出与玩家的关系，并承认自己的隐瞒；
3. 按第一幕选择，让玩家当场承担，或从门外被叫进来确认；
4. 赵国强拒绝当晚直接离婚，也不接受名义夫妻／三人婚姻；他选择先去车队外住，给彼此真实冷静时间。

### 会面成功后的唯一地图交接

三人随后到管理员室。玩家点击：

```text
登记201临时外住并封存住户钥匙
```

这个动作必须在同一事务中原子完成：

- 赵国强本人交出个人住户钥匙；
- 钥匙进入管理员室 201 钥匙格；
- 钥匙用途变为“临时外住”；
- 赵国强真实离楼；
- 丈夫居住模式变为路线外住；
- 普通丈夫回家作息与随机打断暂停；
- 只允许一次后续预约回楼。

不再要求：

- 先准备空袋；
- 去大堂确认到齐；
- 去公寓外部确认离楼；
- 再回管理员室封存。

管理员室这一次操作本身就是完整的现实交接。

## 第三幕：201《一夜真正分开》

### 第一阶段：许曼君独住

外住登记完成后：

- 201 进入“分居独住”环境状态；
- 玩家必须离开 201；
- 至少跨过一个完整夜晚；
- 赵国强个人钥匙全程封存且没有预约取用。

不要求次日再去管理员室点“核对封条”。系统已经拥有钥匙位置、预约和时间真值，可以自动判定独住夜是否成立。

### 第二阶段：回到变化后的 201

下一次许曼君在 201、无强事务时，玩家进入房间，点击：

```text
看看少了一个人以后，201变成了什么样
```

固定两回合：

1. 房间中丈夫的工装、第二套餐具和出车表被收起；许曼君承认这不是一晚赌气；
2. 她说明：玩家若留下，也不再是趁丈夫不在；随后由玩家决定是否接受她第一次正式的共同过夜邀请。

### 第二个真实玩家决定

```text
A. 今晚留下
B. 今晚仍让她一个人，之后再说
```

两种选择都不阻断许曼君的分居：

- A：进入一次路线绑定的 201 共同夜晚；
- B：婚姻线继续，`共同夜晚待完成` 保留，玩家以后可以在 201 接受邀请。

### 共同夜晚与亲密

选择 A 时：

1. 先有两拍关系开场，明确这不是秘密空窗；
2. 可接入现有 201 普通 L5 亲密；
3. 正常结束后直接进入现有睡眠事务，到次日早晨；
4. 使用 201 夜／晨背景；
5. 成功后永久登记“许曼君允许玩家在条件合适时留宿 201”。

提交判据只要求：

- 本场确实是 201、许曼君为有效参与者；
- 场次没有角色中止、取消或安全失败；
- 亲密／共同夜晚正常收束。

不要求满意度与有效楼数双重达到数值目标。

若玩家取消、角色中止或生成失败：

- 不登记首次共同夜晚；
- 不解锁长期留宿；
- 不影响许曼君已经成立的独住与分居；
- 可以以后重试。

### 201 长期留宿权限

关系许可：

```text
首次共同夜晚正常完成
＋许曼君明确允许
```

每次实际可用仍需检查：

- 当前地点 201；
- 晚上或深夜；
- 许曼君在 201；
- 赵国强处于路线外住／待离婚交接／正式退居；
- 赵国强不在 201；
- 无医院硬锁；
- 睡醒前无丈夫预约；
- 无亲密、特殊场景、电话、生产、丈夫登门或其他强事务；
- 时间推进事务能够双存储提交。

“哪一个函数成为所有睡眠地点唯一授权入口”仍属于实现所有权问题，本稿不越过确认门槛。确认后再决定是扩展现有睡眠授权，还是由统一聚合器消费路线许可。

## 第四幕：《带走的东西，留下的决定》

第四幕仍是一幕，但已经按用户确认拆成三个独立提交节点，避免赵国强刚提出修复，所有人就在同一场内立刻接受离婚。

### 4A《一次取完》

#### 时间门与钥匙

- 赵国强外住后至少经过两个完整世界日；
- 系统自动选取许曼君不在医院的安全白天，错过后自动顺延；
- 玩家以管理员权限陪同开门；
- 赵国强的个人住户钥匙始终封存在管理员室，不拆封、不交还。

玩家在201点击：

```text
带赵国强进入201取完约定物品
```

#### 固定三回合

1. 赵国强一次取完换洗衣物、工作用品、洗漱用品和其他约定个人物件，201的长期环境完成第二次变化；
2. 他提出具体修复方案，例如减少非必要长途、固定参与家庭生活、把娘家支出与夫妻共同账分开；这些只是提案，不是已经实现的结果；
3. 许曼君承认方案有分量，但拒绝在取物当天作最终答复，决定继续独住一个完整世界日后再给答案。

成功后只提交：用品已取完、修复已提出、丈夫继续外住。此时不得写成许曼君已经拒绝复合、赵国强已经同意离婚或钥匙已经改用途。

### 冷静期：完整一个世界日

4A结束后必须完整经过一个世界日。期间玩家可以正常处理楼务和其他角色；《分居》不锁时间。医院会冻结当前检查点，出院后继续，不重演取物或提案。

### 4B《她自己的答案》

地点固定在201，赵国强不在场。玩家点击：

```text
听她说出冷静后的决定
```

固定两回合：

1. 许曼君说明自己认真考虑过修复方案，但仍不愿恢复共同生活，决定进入正式离婚办理；这个决定不以玩家是否留下为条件；
2. 玩家只决定自己与许曼君的关系：继续、退出或暂不承诺。

三种选择的后果：

- **继续关系**：保留已经成立的共同夜晚和留宿许可；尚未完成共同夜晚时，以后仍可补完；
- **退出关系**：不阻断许曼君离婚，保留曾经共同夜晚的历史，但撤销未来201留宿许可；
- **暂不承诺**：不阻断离婚；保留既有留宿许可，但不会凭空生成尚未取得的许可。

### 4C《钥匙不再回来》

系统安排最近的安全白天。三人在管理员室201钥匙柜前完成两回合，赵国强不再进入201：

1. 许曼君亲口告诉赵国强，自己考虑后仍不恢复共同生活，并要求进入正式离婚办理；
2. 赵国强接受继续外住与进入办理，但不需要原谅玩家、接受三人关系、祝福两人或当场成为前夫。

最后由玩家点击：

```text
把201封存钥匙改为“待离婚交接”
```

同一事务完成：

- 同一枚钥匙始终留在原来的封存格；
- 封条修订保持一次，不拆封、不二次封存；
- 用途从“临时外住”改为“待离婚交接”；
- 赵国强继续车队外住，普通丈夫作息与旧随机打断继续暂停；
- 《分居》完成，独立《离婚》结局解锁。

法律离婚、正式退居、住户资格删除、原钥匙作废、换锁和财产处理仍留给后续《离婚》。不再要求去大堂验封或第三次到公寓外部确认离楼。

减少的是重复手续，保留并加重的是生活真正改变所需的时间。

这些要么属于场景内演出，要么可由一次原子事务完成。

## 九、地图、物件与画面如何重新分工

### 9.1 地图职责

#### 201

负责：

- 初谈；
- 三人摊牌；
- 独住后的环境核验；
- 第一次共同夜晚；
- 丈夫唯一一次取物与最终决定。

这是人物关系真正发生变化的地方，应承担大部分剧情价值。

#### 管理员室

只负责两次有长期权限后果的动作：

1. 临时外住登记＋个人钥匙首次封存；
2. 同一枚封存钥匙改为待离婚交接。

#### 信箱区、大堂、公寓外部

不再作为本线强制跑点。

这些地点仍可在自由演出、风闻或其他系统中出现，但不应作为同一事实的重复验收按钮。

### 9.2 物件职责

#### 工资卡

保留为人物和经济边界的核心象征。归还在三人摊牌的成功提交中成为硬事实，不进入玩家背包。

#### 201住户钥匙

保留为权限变化的唯一核心物件。生命周期：

```text
赵国强普通持有
→ 管理员室一次封存／临时外住
→ 原封不动改标为待离婚交接
→ 后续《离婚》再处理正式退居、作废或换锁
```

#### 会面通知与封存袋

可以继续出现在画面和叙事里，但不再作为玩家背包物件与多阶段主状态。

### 9.3 现有 12 张本地资源

资源继续保持本地未发布，确认前不删、不改名、不宣称已上传。

新方案优先复用：

- A1 工资卡／决定；
- A3 三人同桌；
- A3 工资卡归还；
- 钥匙首次封存；
- 201 分居独住背景；
- A5 取物与修复；
- A6 钥匙柜前最终会面；
- 201 留宿夜／晨。

“第二次钥匙装袋”“第二次离楼”等若与新流程冲突，可保留为未使用候选，不得为了消耗素材恢复重复步骤。

孕产／育儿长期背景继续高于分居背景。分居只能以轻量状态层补充，不能盖掉孩子、待产或产后现实。

## 十、丈夫作息、打断、医院与孕产

### 10.1 赵国强作息

#### 外住登记前

完全沿用普通丈夫作息：

- 早上／晚上在家；
- 中午／下午／傍晚外出；
- 深夜睡眠；
- 若被其他系统安排出差、夜班或登门，仍服从统一时钟真值。

三人摊牌只能安排在真实能到场的时段。

#### 外住登记后

统一切换：

- 普通回楼作息暂停；
- 普通首次丈夫对质与随机打断暂停；
- 只允许本线唯一一次取物预约；
- 预约结束后继续外住。

不能只在分居模块里写一个“他不回来”的文本字段，必须继续让统一丈夫位置推算消费居住模式。

### 10.2 丈夫认知

三人摊牌提交后，赵国强精确认知：

- 许曼君与玩家的关系；
- 玩家采取的参与方式；
- 工资卡已经归还；
- 分居不是普通催租或管理员纠纷。

后续孕情、电话、取物和《离婚》不得再演“第一次发现”。

### 10.3 怀孕与医院

#### 路线开始前或两幕之间进入医院

- 路线冻结；
- 预约不作废，只顺延到出院后的安全时段；
- 不生成钥匙、关系或用品的半事实；
- 医院／生产／育儿背景拥有视觉优先级。

#### 三人会面前已有丈夫孕情登门

先完成统一丈夫登门，再开始《分居》，避免两种“第一次发现”竞争。

#### 丈夫已经知情并外住后出现新孕情

- 不再触发普通首次对质；
- 使用“已知关系＋正在外住”的专属反应语义；
- 不允许他无预约突然出现在 201；
- 可通过手机、合法联系或下一次预约会面回应。

#### 共同夜晚发生受孕

继续走现有普通受孕、医院与生产系统，不由《分居》直接写怀孕结果。

### 10.4 打断与强事务

启动每一幕前继续检查：

- 医院硬锁；
- 正在进行的亲密；
- 当前特殊场景；
- 父亲电话；
- 场景剧情事务；
- 生产／丈夫登门；
- 时间推进或双存储事务；
- 当前消息分支与聊天身份。

场景已经生成但未提交时：

- 不预写工资卡、认知、钥匙或作息；
- 失败只保留同一稳定票重试；
- 切聊天、删楼、回档或分支变化时旧票失效；
- 迟到回调不得在新时间线提交。

## 十一、失败、取消、重复点击与回档

### 11.1 剧情生成失败

- 当前幕停在原阶段；
- 不提前提交长期事实；
- 使用相同场景票重试；
- 不重复排预约；
- 不重复创建 CG 或提示。

### 11.2 重复点击

每个硬动作必须带：

- 预期阶段；
- 预期绝对时段；
- 预期地点；
- 当前聊天／分支锚；
- 操作世代或事务票。

第一笔成功后，第二笔只返回幂等结果，不重复改钥匙、作息、时间或背包。

### 11.3 取消共同夜晚

- 不登记首次共同夜晚；
- 不解锁长期留宿；
- 不回滚丈夫外住与妻子独住；
- 下一个安全晚上可重新接受邀请。

### 11.4 错过预约

- 自动寻找下一次真实安全时段；
- 不要求玩家重新发通知；
- 不重复归还工资卡；
- 不拆封个人钥匙。

### 11.5 回档、撤回、删楼与切分支

权威状态只来自当前存档与当前消息分支：

- 回到摊牌前：丈夫认知、工资卡归还与外住都必须一起回到当时状态；
- 回到外住后：不能因聊天消息残留恢复普通丈夫作息；
- 删掉成功楼：后续票与迟到回调失效；
- 切分支：不同分支分别拥有预约与共同夜晚状态；
- 删除 201 住户：路线冻结／失效，不继续在空户写入钥匙事实。

## 十二、旧 33 阶段存档如何迁移到新检查点

这是设计映射，不是当前已经实施的迁移。

### 12.1 未开始与初谈前

旧阶段：

```text
未开始
待A1
待A1封套动作
待A1通知动作
待A2
```

迁移目标：

- 未开始保持未开始；
- 尚未让丈夫知情的一律落到“待初谈”或“待三人摊牌”；
- 已记录玩家承担方式则保留；
- 旧通知／空袋仅作为兼容残留清理，不生成新路线必需物件。

### 12.2 三人会面准备与进行中

旧阶段：

```text
待A3取袋
待A3大堂
待A3进入201
待A3工资卡动作
A3进行中
待第一次接钥匙
待第一次离楼
待第一次封存
```

迁移依据不是旧阶段名，而是正交事实：

- 工资卡是否已经归还；
- 丈夫是否已经知情；
- 丈夫是否已经选择外住；
- 钥匙是否已经进入管理员室。

若丈夫已知但钥匙未封存，迁到“待登记外住”；不能重演第一次发现。

旧背包里的通知／封存袋只在确认权威钥匙位置后去重，绝不能同时让钥匙存在丈夫、背包和钥匙柜三处。

### 12.3 第一次封存后至共同夜晚

旧阶段：

```text
待A4独住对话
待独住离场动作
待独住夜完成
待收起出车表
待亲密邀请
亲密进行中
A4事后进行中
待A4事后重答
```

迁移原则：

- 丈夫外住与第一次封存保留；
- 已完成独住夜则直接保留；
- 已完成真实共同夜晚则保留；
- 旧 `留宿201权限=true` 不得丢失；
- 亲密进行中的旧档必须按原场次标识续接或安全取消，不能伪造完成；
- 玩家曾拒绝承担不再阻断婚姻线，只转成关系待谈。

### 12.4 A5 取物阶段

旧阶段：

```text
待A5取袋
待A5大堂
待A5进入201
待A5取物动作
A5进行中
待第二次接钥匙
待第二次离楼
待第二次封存
```

迁移原则：

- 已提出修复与许曼君已拒绝的事实分别保留；
- 已取的用品不重新出现；
- 无论旧钥匙在预约手、背包还是第二次待入柜，都归一到唯一合法位置；
- 若取物会面未完成，迁到“待最终取物”；
- 若会面已完成，迁到“待钥匙转交接”。

### 12.5 A6 与已完成

旧阶段：

```text
待A6
A6进行中
待交接状态
待最终离楼
已完成
```

迁移原则：

- 双方已经同意进入办理时，不得重新检定丈夫是否愿意；
- 钥匙已经是待离婚交接时，不得退回临时外住；
- 已完成继续保持完成；
- 已解锁留宿继续保留；
- 法律离婚、正式退居、换锁仍不应被承接迁移提前完成。

## 十三、承接完成后的准确世界状态

《分居》完成时必须成立：

- 工资卡已由许曼君归还赵国强；
- 赵国强已知玩家关系；
- 赵国强经历了真实外住和一次真实取物；
- 他提出过具体修复；
- 许曼君听完后仍决定不恢复共同生活；
- 双方同意进入正式离婚办理；
- 201 住户钥匙封存在管理员室，状态为待离婚交接；
- 赵国强普通丈夫作息与随机打断暂停；
- 201 环境表现为分居后的长期状态；
- 玩家最终关系选择有记录；
- 首次共同夜晚若完成，201 条件式留宿许可保留；
- 独立《离婚》入口解锁。

仍不得成立：

- 法律婚姻已经解除；
- 赵国强已经是前夫；
- 赵国强住户资格已删除；
- 原钥匙已经作废；
- 201 已换锁；
- 所有共同财产已处理；
- 欠租与历史账目自动清零；
- 玩家自动取得 201 钥匙、常住权、再婚或独占关系。

这些继续属于独立《离婚》结局。

## 十四、确认后的实现所有权建议

这一节只说明推荐方向，用户确认前不接线。

### 14.1 路线状态

保留一个权威路线模块。所有主阶段、正交事实、剧情票和迁移都由同一所有者负责。

### 14.2 地点动作

直接进入现有 `useRoomActions` 与宿主动作事件，不再维护第二套截断的“分居玩法”状态机。

### 14.3 丈夫作息与认知

- 居住模式继续由统一楼层时钟消费；
- 丈夫首次对质和孕情反应直接读取权威分居事实；
- 不保留无人消费的独立投影文件，除非已有统一所有者明确导入。

### 14.4 睡眠授权

路线模块只提供：

```text
许曼君是否已经给予201留宿关系许可
```

统一睡眠所有者负责：

```text
当前地点／时段／人物／医院／预约／强事务／时间事务是否允许执行
```

最终由哪一现有函数承担这个统一所有权，等设计确认后再审，不在本稿提前定案。

### 14.5 背包、钥匙柜、手机与资源

- 背包不再出现会面通知和来回搬运的封存袋；
- 钥匙柜只显示唯一钥匙位置和用途；
- 手机可显示预约通知，但只读展示，不拥有路线状态；
- 资源解析并入既有资源所有者；
- 无消费者的输入桥、结局入口、手机副作用、背包与钥匙柜草稿逐一决定合并或废弃。

## 十六、已确认并落实的设计决定

### 决定1：一个钥匙生命周期

```text
普通持有
→ 一次封存为临时外住
→ 原封不动改为待离婚交接
```

第二次拆封、第二次归还、第二次封存和三次楼外确认已经从新玩家流程移除。

### 决定2：玩家不能绑架她的分居

玩家可以继续、退出或暂不承诺，但许曼君已经作出的分居决定仍能走到丈夫同意办理；玩家选择只改变两人的关系与未来201留宿后果。

### 决定3：亲密保留，但不再是数值考试

共同夜晚仍是一场真实201普通亲密；主动收尾或体力耗尽的正常收束即可。暂缓不阻断分居，角色中止或安全失败不伪造留宿许可。

### 决定4：第四幕一幕三段、两天完成

赵国强只回201一次取物并提出修复；完整经过一个世界日后，许曼君在201私下决定；再到最近安全白天，由三人在管理员室完成离婚前钥匙交接。

当前实现所有权已经收口：

- `许曼君分居系统.ts`是唯一状态机和写入者；
- 截断的`许曼君分居玩法.ts`收为只读适配层；
- Schema、schema.json、initvar和旧档迁移已经同步；
- 睡眠继续使用现有统一时间事务；
- 背包不再生成通知或封存袋；
- 12张本地图继续保留但尚未发布；
- 独立《离婚》仍待后续设计与实现。
