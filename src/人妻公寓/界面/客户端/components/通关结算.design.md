# 通关结算 Surface

## Overview

记录日期：2026-09-07。范围：客户端通关结算弹窗及其进度、首次纪念、晋级庆祝状态。
用户已确认成年角色庆典礼装 CG 与隆重通关风格；以群像、月桂评级和继续游玩构成庆典。
实现依据：同目录 `通关结算.vue`、`../composables/useSettlement.ts`、`../../../通关纪念存档.ts`；字体与背景交互依据 `../global.css`、`../App.vue`。

## Colors

- 深蓝底（`#111723`）承载主体，底栏（`#151b27`）与遮罩（`rgb(4 8 18 / 86%)`）区分层次。
- 金色（`--gold: #f3ce86`）用于评级、完成标记和主按钮；柔金（`--muted-gold: #d6c7ab`）用于辅助文字。
- 浅暖色标题（`#fff0cf`）突出庆典信息；保存错误使用浅红（`#ffc1b4`）。

## Typography

沿用现有字体变量：正文 `--font-body`、标题 `--font-prose`、评级 `--font-display`，具体字体栈以 `global.css` 为准。
桌面标题为 `clamp(24px, 3.2vw, 38px)`，评级为 `clamp(64px, 9vw, 96px)`；统计数字使用等宽数字排列。

## Layout

阅读顺序为标题 → 已通关庆典 CG → 评级与成绩切换 → 四项统计 → 角色结局 → 探索进度 → 固定继续按钮。
桌面容器宽度 `min(1180px, 100%)`，最大高度 `calc(100dvh - 28px)`；中段独立滚动，标题与底栏保持可见。
CG 宽度为 `100%`，比例 `1672 / 941`；桌面高度上限 `min(43dvh, 540px)`，居中偏上裁切（`center 20%`）。
手机断点为 `600px`：弹窗占满 `100dvh`，CG 取消高度上限、保持完整横幅；角色由双列转单列，继续按钮通栏，并留出安全区。

## Elevation & Depth

深色遮罩、细金边和评级下方渐变建立层次；评级以文字阴影从 CG 前景中分离。

## Shapes

桌面主体圆角 `14px`，主按钮圆角 `10px`；手机主体取消边框与圆角。角色与探索内容使用分隔线组织。

## Components

- 成绩在首次纪念与当前进度／本次成绩间切换；记录包含角色结局、特殊剧情、本局 CG、服饰与探索分，首次成绩随本局存档保留。
- 弹窗带有 `dialog`、`aria-modal` 和标题关联；打开时聚焦弹窗，Tab 在可用控件中循环，Escape 关闭，卸载后恢复原焦点；主界面在打开期间设为 `inert`。
- 按钮和折叠规则摘要使用可见金色焦点框；评级入场动画为 `900ms`，系统减少动画偏好与 `reducedMotion` 属性均关闭该动画。
- CG 加载失败保留成绩并提供重新载入；保存错误以 `role="alert"` 呈现。关闭立即返回游戏，纪念确认在后台重试。
- 已通关主按钮为“继续游玩”，未通关为“返回公寓”；保存中显示进度文字并禁用关闭控件。
