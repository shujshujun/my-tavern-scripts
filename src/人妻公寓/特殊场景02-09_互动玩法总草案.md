## 一、从「录像带」继承的设计纪律

本文件只设计剩余八种特殊场景。以下规则视为共同前提：

1. 特殊场景票购买后进入背包，不在商店立即触发。
2. 场景开始时冻结本次参与名单；动态角色不因后续排序、位置或阶段变化而替换。
3. 多人到场和头像点亮只属于特殊场景演出层，不改日常位置变量。
4. 正式剧情按多个 AI 回合推进，玩家在自由输入回合可以说话、提问或行动。
5. AI 必须先回应玩家，再回到本轮固定节拍；玩家不能用输入跳过、提前结束或改写场景骨架。
6. 交互幕出现时隐藏正文、输入框、原生瓷砖和离场入口；成功后显示结果图并自动触发下一回合。
7. 交互幕只使用单击/轻触、连续点击/连续轻触、长按三类输入，并提供三次失败后的补偿按钮。
8. 不是每个回合都安排互动；一场通常安排 1—3 个有叙事意义的交互幕。
9. 特殊场景正文作为真实发生过的普通聊天历史保存并进入长期记忆，但不自动上报主线阶段事件。
10. 每位数值参与妻只在最终成功收束后增加堕落值 `+2`；头像见证者、主持人和丈夫不因此获得数值。
11. 除非单独重新拍板，特殊场景不修改好感、婚姻、疑心、欠租、朋友圈、照片、服装、性癖槽或日常位置。
12. 人物的羞耻、主动、竞争、拒绝方式和事后态度不写成固定模板；每回合根据她当时的阶段、好感、堕落、当前情绪、婚姻状态、性癖和人物底色即时表现。

## 二、特殊场景 02：「大扫除日」

### 1. 定位与启动

- 参与妻：启动时从达到 L4 的妻子中固定四人。
- 建议启动地点：管理员室。
- 使用场景票后，四人带着清洁用品到管理员室集合，再按固定路线开始全楼大扫除。
- 本场允许地点随节拍从管理员室切换到楼道、公共区域和最终清洁房，但不修改任何人的日常位置。
- 场景票提供统一的单穿围裙，不要求玩家事先给四人各买一件「裸体围裙」，避免前置购买过重。
- 若以后希望强化收藏玩法，可将“至少给其中一人送过裸体围裙”设为货架提示条件，但不建议要求四件。

### 2. 正式节拍：8回合

1. **集合与分工**：四人到管理员室领围裙和工具；按当前人物状态表现接受方式，确定四种不同职责。
2. **第一站·擦窗**：两人处理玻璃和窗框，另外两人整理楼道；家务熟练度与暴露反差成为重点。
3. **第一站余波**：开放玩家输入；角色回应后完成擦窗，转向下一处。
4. **第二站·地面和床底**：跪地、俯身、交换工具；突出四人的动作和竞争方式不能同质化。
5. **第二站余波**：开放玩家输入；完成顽固污迹处理，确定谁最先失去表面上的“只是打扫”。
6. **第三站·清洁玩家**：四人把“最后需要清洁的对象”转向玩家，先完成分工和规则确认，不得一回合收束。
7. **共同服务**：开放玩家输入；四人按性格各自承担不同位置和职责，推进到接近完成。
8. **最终清理**：完成身体清洁主题的收束，四人重新整理围裙、工具和现场，回管理员室交还用品并离开。

### 3. 交互设计

#### 互动A：长按拧干抹布

- 插入点：回合1结束后。
- 操作：按住瓷砖 `拧干第一块抹布` 1.8秒。
- 操作图：管理员室桌面，四条不同颜色的围裙、四只水桶和湿抹布。
- 通过图：水从抹布落入桶中，四位妻子已经换好围裙站在门边，仅表现安全的背影和轮廓。
- 失败3次补偿：`让她们帮你一起拧干`。

#### 互动B：连续点击清除顽固污迹

- 插入点：回合3结束后。
- 操作：5秒内连续点击10次。
- 操作图：旧地板上的污迹、刷子和四双不同鞋型/赤足边缘，画面用速度线表现擦洗。
- 通过图：污迹消失，湿润地面映出模糊倒影。
- 失败3次补偿：`换一瓶强力清洁剂`。

#### 互动C：单击最终验收

- 插入点：回合5结束后。
- 两块瓷砖同时出现：
  - `验收房间清洁`：冻结，提示“还有最后一项”；
  - `验收她们的清洁服务`：可单击。
- 通过图：四人围拢玩家，清洁工具被放到一边，画面只负责进入最终段，不直接画完成结果。

### 4. 图片预算

建议6张：

1. 管理员室用品待领；
2. 换装集合通过图；
3. 地面擦洗操作图；
4. 地面清洁通过图；
5. 四人围拢的最终服务开场；
6. 收束后重新整理工具和围裙。

## 三、特殊场景 03：「部位评比」

### 1. 定位与启动

- 主持/裁判：母亲，仅演出和点亮头像，不参与 `+2`。
- 参赛妻：启动时固定最多四名 L4 妻子。
- 建议启动地点：302客厅；玩家在302对母亲使用场景票。
- 母亲负责宣布规则、逐项点评和最终裁决；玩家可以评价，但不能靠一句输入直接指定冠军。
- 冠军由本次固定参赛名单、人物当前状态与演出自然决定；不新建评分数值。

### 2. 正式节拍：8回合

1. **裁判开场**：母亲摆好号码牌、软尺和评分板，参赛者入场并确认规则。
2. **第一项·胸与肩颈**：逐人展示，母亲点评体态和反应；不急着判胜负。
3. **第二项·腰腹**：玩家可以输入评价；母亲回应后继续量取和比较。
4. **第三项·臀腿**：换站位和观察角度，突出参赛者之间的雌竞、合作或回避。
5. **自由陈述**：每位参赛者用符合人设的方式争取、否认或让出优势；玩家可以逐人回应。
6. **裁判合议**：母亲总结差异，公布唯一冠军；其余人保留观摩位置。
7. **冠军奖励上半段**：玩家和冠军进入奖励演出，母亲继续主持，其余参赛者观看；不得当轮结束。
8. **奖励完成与散场**：按原场景骨架完成奖励，母亲宣布评比结束，所有人整理现场离开。

### 3. 交互设计

#### 互动A：单击揭开评分板

- 插入点：启动后、回合1之前。
- 操作图：302客厅临时评比区，评分板盖着布，母亲坐在裁判席，参赛者背影排开。
- 操作：单击 `开始内部评比`。
- 通过图：布被揭开，四个空白号码位出现，不显示具体分数。

#### 互动B：长按拉直软尺

- 插入点：回合2结束后。
- 操作：长按1.8秒。
- 操作图：母亲手中的卷曲软尺和记录夹，参赛者在背景等待。
- 通过图：软尺拉直，镜头转入腰腹、臀腿评比段。
- 失败3次补偿：`请裁判亲自整理软尺`。

#### 互动C：连续点击鼓掌确认结果

- 插入点：回合6结束后。
- 操作：5秒内点击8次。
- 作用：不是玩家投票，只是确认接受裁判结果并进入冠军奖励。
- 失败3次补偿：`由裁判直接宣布进入奖励环节`。

### 4. 图片预算

建议6张：会场全景、评分板揭开、软尺操作、软尺通过、冠军公布、奖励开场。

## 四、特殊场景 04：「静音会议」

> **本节 7 回合内容已经作废。** 静音会议的权威实现契约已迁移到
> [《特殊场景04_静音会议_正式设计》](./特殊场景04_静音会议_正式设计.md)：
> 固定会议 12 拍、会后至少 3 拍，第 15 拍后由玩家选择无限继续或主动结束，最终收尾成功后才结算。

### 1. 定位与启动

- 参与妻：至少两名、最多三名，必须达到 L4 且已装载遥控跳蛋。
- 演出丈夫：与参与妻对应的丈夫，作为正常与会者临时到场。
- 建议启动地点：管理员室；桌椅临时排成楼务会议形式。
- 玩家拥有全部遥控器。
- 丈夫不知道遥控器控制的具体情况；妻子彼此知道其他参与者也处于同样状态。
- 本场的核心不是公开暴露，而是正经会议表面下的控制和忍耐。

### 2. 正式节拍：7回合

1. **与会者入席**：宣布楼务议题、座次和“会议期间保持安静”的规则。
2. **第一档会议**：讨论维修、卫生或租务；玩家第一次调整遥控，妻子必须继续正常发言或记录。
3. **交叉发言**：玩家自由输入；丈夫回应楼务内容，妻子在互相观察中维持表面。
4. **第二档会议**：强度上升，某位妻子险些露馅，但不得立即判败。
5. **点名表决**：玩家可以点名提问；每位参与妻必须用符合当前状态的方式完成一句正式回答。
6. **失守判定**：根据实际正文表现确定最先明显失态者，不建立永久输赢变量；宣布她会后留下。
7. **会后打扫**：丈夫们离开，留下者与玩家完成短收束；其他妻子是否短暂旁观由本轮固定节拍决定，最后全员离场。

### 3. 交互设计

#### 互动A：单击第一档遥控

- 插入点：回合1结束后。
- 操作图：玩家视角的会议桌下方，口袋边缘露出多个无文字遥控器；桌面上是正经会议资料。
- 操作：单击 `开启第一档`。
- 通过图：其中一个指示灯亮起，桌上所有人仍保持会议姿态。

#### 互动B：长按维持第二档

- 插入点：回合3结束后。
- 操作：按住2秒，松开过早即失败。
- 操作图：玩家拇指压住遥控器，妻子们的手在桌沿、笔记本或裙摆上出现不同紧张动作。
- 通过图：遥控灯稳定，某支笔在纸上留下轻微歪线。
- 失败3次补偿：`锁定当前挡位`。

#### 互动C：连续点击完成点名表决

- 插入点：回合5之前。
- 操作：6秒内点击参与妻人数×3次；人数2时6次，人数3时9次。
- 每组三次代表点名一人，前端依次点亮头像边框。
- 失败3次补偿：`改为逐一点名`。

### 4. 图片预算

建议6张：会议全景、第一档操作/通过、第二档操作/通过、丈夫离场后的会议室。

## 五、特殊场景 05：「肉偿账本」

### 1. 定位与启动

- 固定角色：许曼君。
- 启动地点：201室；玩家在许曼君实际在场时向她使用场景票。
- 前置：许曼君 L4，当前确实存在欠租。
- 这是唯一一次特殊正戏，不是每月循环的催租服务。
- 按已经拍板的特殊场景数值铁律，本场正文可以写“她在账本上划清这一期”，但代码不直接清空欠租变量；源码现有专属欠租清零结算需要另行修正。

### 2. 正式节拍：5回合

1. **带账上门**：许曼君拿出真实账本，先按她的精明方式核对金额、日期和责任。
2. **亲口开价**：玩家自由输入；她回应后必须由她主动提出“换一种结法”，不能让玩家替她说出口。
3. **逐笔报数**：每推进一次，她报出一笔数字或项目，声音和计算方式逐渐失去原本的从容。
4. **最后一笔**：玩家自由输入；完成身体交易主题的主要演出，但保留最终记账动作。
5. **只有两人懂的记号**：她在账本新栏留下记号，口头确认这一场已经结清，同时明确这不是下月固定服务。

### 3. 交互设计

#### 互动A：长按压平账页

- 插入点：回合1结束后。
- 操作：长按1.6秒。
- 操作图：旧账本、钢笔、算盘和许曼君按住翘起纸页的手。
- 通过图：账页平整，空白新栏被露出。
- 失败3次补偿：`让她用镇纸压住`。

#### 互动B：连续点击拨完最后一笔算盘

- 插入点：回合3结束后。
- 操作：5秒内点击9次。
- 操作图：算盘珠和她逐渐失去稳定的手。
- 通过图：最后一列算盘珠归位，钢笔停在新栏上。
- 失败3次补偿：`改用计算器核清最后一笔`。

### 4. 图片预算

建议5张：带账谈判、账页操作/通过、算盘操作/通过。最终正文沿用通过图等待生成。

## 六、特殊场景 06：「合拍」

### 1. 定位与启动

- 固定主角：安若妍。
- 搭档：启动时从其他 L4 妻子中固定一人。
- 启动地点：301室；玩家在安若妍实际在场时使用场景票。
- 拍摄主题表面是“人妻日常”，公开成片干净正常；被剪掉的中段才是特殊场景主体。
- 场景正文可以确认成片已经发布，但不新增朋友圈条目、照片收藏或录像变量。

### 2. 正式节拍：7回合

1. **定脚本和机位**：安若妍安排玩家掌镜，向搭档解释正常的拍摄主题。
2. **公开素材第一段**：两人完成做饭、整理或聊天等可公开镜头，建立镜头前的人设。
3. **镜头越摆越低**：玩家自由输入；安若妍回应并调整构图，搭档开始意识到拍摄方向改变。
4. **“休息”开始**：摄像机是否继续工作形成暧昧；两人从公开表演转入被删掉的中段。
5. **缺失的二十分钟**：玩家自由输入；按两人的当前人物状态推进合作、竞争或互相观察，不得一回合完成。
6. **重新面对镜头**：两人整理外观，补拍一段完全正常的结尾。
7. **剪辑与发布**：安若妍删去中段、播放成片并按下发布；三人都知道公开版本缺了什么。

### 3. 交互设计

#### 互动A：单击开始录制

- 插入点：回合1之前。
- 操作图：301拍摄区，三脚架、补光灯、相机取景框，两位妻子站在布景前。
- 操作：单击 `开始拍摄人妻日常`。
- 通过图：相机红灯亮起，取景框构图稳定。

#### 互动B：长按保持低机位

- 插入点：回合3结束后。
- 操作：长按2秒模拟稳定相机。
- 操作图：玩家手扶云台，构图逐渐降低，两位妻子的表情和站姿发生分化。
- 通过图：低机位锁定，但不在图片中呈现露骨行为。
- 失败3次补偿：`锁紧三脚架云台`。

#### 互动C：连续点击剪掉中段

- 插入点：回合6结束后。
- 操作：6秒内点击12次。
- 操作图：无文字的视频时间轴，中间一段以红色区块表示。
- 通过图：红色区块从公开时间轴消失，首尾正常镜头被拼接。
- 失败3次补偿：`让安若妍使用自动剪辑`。

### 4. 图片预算

建议6张：拍摄待机/录制、低机位操作/通过、剪辑时间轴/公开成片。

## 七、特殊场景 07：「家宴」

### 1. 定位与启动

- 主持者：母亲。
- 来客：启动时固定2—3名 L4 妻子。
- 启动地点：302餐厅；玩家在302对母亲使用场景票。
- 丈夫们只作为“今晚恰好不在”的背景条件，不点亮头像、不演出。
- 核心张力是家常动作中的主权宣示，不应开场就变成公开争抢。

### 2. 正式节拍：7回合

1. **入席**：母亲安排座次，逐人招呼、添饭，建立表面正常的家宴。
2. **第一轮夹菜**：每位妻子用符合人设的方式照顾或靠近玩家；母亲不动声色地回应。
3. **敬酒与暗流**：玩家自由输入；所有人可以回应，但饭桌礼节继续推进。
4. **桌下与桌上**：公开谈话维持家常，私下动作和视线逐步升级；不同角色不能使用同一种争宠方式。
5. **甜品与最后一次添菜**：母亲完成最明确但仍体面的主权宣示，并决定饭后谁帮忙洗碗。
6. **厨房收尾**：玩家与被选中的帮厨者进入厨房，其余人是否留在餐厅听见动静由固定节拍决定。
7. **送客**：完成厨房段的收束，母亲逐一送客、整理餐桌，最后只留下玩家与她的简短余韵。

### 3. 交互设计

#### 互动A：长按斟满第一杯酒

- 插入点：回合1结束后。
- 操作：长按1.8秒。
- 操作图：家宴圆桌，母亲的手扶杯，几位妻子的手和餐具体现不同身份。
- 通过图：酒杯斟满，众人视线在桌面交汇。
- 失败3次补偿：`让母亲接过酒壶`。

#### 互动B：单击揭晓洗碗人选

- 插入点：回合5结束后。
- 瓷砖：
  - 每位候选妻显示一块冻结姓名牌；
  - 唯一可点击瓷砖为 `听母亲安排`。
- 通过图：母亲把围裙或洗碗手套递给本次剧情选中的角色。
- 玩家不能用 UI 强行选择某人，避免动态名单和正文判定分裂。

### 4. 图片预算

建议4张：家宴全景、斟酒通过、洗碗人选揭晓、厨房收尾。

## 八、特殊场景 08：「制服夜巡」

### 1. 定位与启动

- 参与妻：启动时固定三名 L4 妻子。
- 启动时间：仅夜间或深夜。
- 启动地点：管理员室。
- 本场是明确的移动路线特例：管理员室领巡查表后，依次到三名妻子对应楼层，最后到顶层或管理员室提交总结。
- 不改真实位置变量；特殊场景状态保存当前检查站和完整路线。
- 制服优先采用角色当前已穿戴或拥有的 L4/L5 制服；没有可用制服时由场景临时提供与人物反差合适的一套，场景结束不写入穿戴槽。
- “JK”只作为成年人妻的角色扮演制服，不改变角色年龄。

### 2. 正式节拍：8回合

1. **领取巡查表**：玩家在管理员室确认三层路线，三块岗位瓷砖全部可见，仅第一站可用。
2. **第一站检查**：第一位妻子按制服和人物性格完成独有岗位职责。
3. **第一站验收与转场**：玩家自由输入；收束第一站并开放第二站。
4. **第二站检查**：第二位妻子必须使用不同的服务方式和空间构图。
5. **第二站验收与转场**：玩家自由输入；收束第二站并开放第三站。
6. **第三站检查**：第三位妻子承担强度最高但仍符合她当前状态的岗位内容。
7. **三人工作总结**：三位妻子在顶层或管理员室并排汇报，玩家可以逐人评价。
8. **最终验收**：完成统一的总结奖励，盖章结束巡楼，三人返回各自原位置。

### 3. 交互设计

三个站点分别使用三种操作，让夜巡具有通关感。

#### 第一站：单击门牌

- 操作：单击 `检查第一岗位`。
- 画面：夜间楼道，第一扇门虚掩，门牌和门内制服轮廓清晰。
- 通过图：门打开，第一位妻子以岗位姿态迎接检查。

#### 第二站：连续点击呼叫值班人员

- 操作：5秒内敲门9次。
- 画面：第二层门外，门内灯光随点击逐渐亮起。
- 通过图：第二位妻子开门，第一站瓷砖冻结标记“已验收”。
- 失败3次补偿：`使用管理员备用钥匙正常开门`。

#### 第三站：长按完成终层扫描

- 操作：按住扫描瓷砖2.2秒。
- 画面：第三层门口，巡查表、手电筒光束和最后一扇门。
- 通过图：三枚岗位印章全部亮起，进入第三站正文。
- 失败3次补偿：`切换固定照明完成检查`。

### 4. 图片预算

建议8张：管理员室路线图、三个站点各一张操作图和一张通过图、最终三人总结图。

## 九、特殊场景 09：「衣柜」

### 1. 定位与启动

- 数值参与妻：沈静仪。
- 演出丈夫：顾国栋。
- 启动地点：102室。
- 前置：沈静仪 L5，顾国栋的丈夫路线已经进入“观众席”。
- 玩家在沈静仪实际在场的102室使用场景票；顾国栋按剧情已经藏入衣柜。
- 顾国栋在场和头像点亮只属于本场演出，不改变作息、疑心或丈夫路线。
- 核心不是顾国栋突然闯入，而是三人都知道他在衣柜里，却共同维持“他出差了”的表面。

### 2. 正式节拍：6回合

1. **布置谎言**：沈静仪整理102客厅或卧室，平静说出“他出差了”；衣柜门保持关闭。
2. **留下门缝**：顾国栋进入观察位置，门只开一道缝；沈静仪第一次朝没有落点的方向看去。
3. **两人戏开始**：玩家自由输入；沈静仪必须回应，但她对被两双眼睛观看的认知成为本轮核心。
4. **门缝里的第三人**：玩家与沈静仪继续推进，顾国栋只能通过呼吸、衣料或门缝光影存在，不抢成丈夫主视角。
5. **观众席成人礼**：玩家自由输入；沈静仪的视奸欲达到本场顶点，三人默契不得被打破。
6. **衣柜开门与收束**：主要演出结束后才允许打开衣柜；三人正面承认刚才的共同事实，顾国栋离场或留下最后一句，场景完整收束。

### 3. 交互设计

#### 互动A：长按控制衣柜门缝

- 插入点：回合1结束后。
- 操作：按住2秒，将门缝停在规定宽度。
- 操作图：玩家手扶旧衣柜门，里面只有顾国栋的眼睛轮廓或肩部暗影，沈静仪在镜中可见。
- 通过图：门缝固定，一线暖光落进衣柜；沈静仪从镜中确认位置。
- 失败3次补偿：`用门挡固定缝隙`。

#### 互动B：连续点击压住衣柜震动

- 插入点：回合4结束后。
- 操作：5秒内点击10次。
- 叙事含义：玩家及时扶住因内部动作或呼吸碰撞而轻响的柜门，避免打破表面谎言。
- 操作图：柜门边缘出现轻微震动残影，沈静仪仍维持动作和视线。
- 通过图：柜门恢复稳定，门缝中的目光仍在。
- 失败3次补偿：`让顾国栋自己扶稳柜门`。

### 4. 图片预算

建议5张：102布置全景、门缝操作/通过、柜门震动操作/通过。最终开门由正文完成，不必额外画露骨结果图。

## 十、共同技术配置建议

每个场景最终应从硬编码分支迁移为统一配置，至少包含：

```ts
interface 特殊场景玩法配置 {
  id: string;
  启动地点: string | ((data: SchemaType) => string);
  总回合: number;
  参与名单: (data: SchemaType) => 门牌[];
  演出妻?: (data: SchemaType) => 门牌[];
  演出夫?: (data: SchemaType) => 门牌[];
  允许移动路线?: string[];
  节拍: {
    id: string;
    类型: 'AI' | '自由输入' | '交互';
    提示词?: string;
    交互id?: string;
  }[];
  交互: Record<
    string,
    {
      类型: '单击' | '连续点击' | '长按';
      目标次数?: number;
      时间窗毫秒?: number;
      长按毫秒?: number;
      失败补偿阈值: number;
      补偿文案: string;
      操作图: string;
      通过图: string;
    }
  >;
}
```

### 正文记忆口径

- 所有正式回合和玩家输入照常写入酒馆正文历史。
- 数据库或智脑照常记忆这些正文，保证角色以后知道完整经历。
- 代码只阻止特殊场景被当成主线晋阶事件，不过滤其剧情记忆。
- 后续人物如何提起往事仍服从她当时的最新人物快照，不能把场景中的临时情绪写成永久阶段结论。

### 动态名单纪律

- `L4们(d).slice(...)`只能在启动时执行一次。
- 固定名单写入通用 `_特殊场景` 状态后，后续回合、刷新和重掷只读取已保存名单。
- 如果启动时人数不足，场景票不消耗。
- 场景中有人因普通系统变化暂时不在原位置，也不替换演员。

## 十一、下一轮建议讨论顺序

建议不要一次实装八场，按下列顺序逐场确认：

1. 「静音会议」：最适合验证多角色、丈夫在场和多次交互。
2. 「制服夜巡」：验证特殊场景内部移动路线。
3. 「肉偿账本」：验证单角色短场景和旧专属结算移除。
4. 「合拍」：验证公开版本/删减版本的正文记忆。
5. 「家宴」：验证动态多人同桌和主持者不参与数值结算。
6. 「衣柜」：验证丈夫路线前置和三人固定在场。
7. 「大扫除日」：验证四人长场景。
8. 「部位评比」：最后处理最多五位女性同场与动态冠军。

每场确认后再单独建立正式玩法文件、生图清单和代码状态机，避免总草案中的建议值未经讨论就直接成为实现。
