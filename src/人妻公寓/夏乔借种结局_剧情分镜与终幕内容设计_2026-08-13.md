## 一、前置与借种正戏的边界

`家庭计划套件`及其五日流程就是借种结局的完整前置：

1. 安装家庭计划板；
2. 投放匿名辅助生育资料；
3. 通过现有监控确认陆嘉明开始考虑；
4. 放入玩家姓名磁贴；
5. 夏乔发来微信，101 出现`赴约`。

前置已经完成“让丈夫接受借种概念，并把玩家视为可信候选”的全部任务。进入 101 赴约以后，不再重新追查匿名资料是谁投的、不审判玩家如何使用监控，也不要求额外拆除摄像头。

借种正戏从陆嘉明的坦白正式开始。

## 二、借种第一幕：《他说出真相》

### 场景

地点固定在 101 客厅。桌上同时摆着：

- 陆嘉明藏了三个月的男方检查报告；
- 家庭计划中的匿名资料；
- 写有玩家姓名的磁贴。

夏乔一开始只知道丈夫要谈“孩子的事”，不知道检查结果，也不知道丈夫已经准备提出借种。

### 第一拍：丈夫坦白检查结果

陆嘉明必须亲口承认：

- 三个月前他已经做过男方检查；
- 报告提示问题很可能在自己，需要复查；
- 他因为羞耻和害怕失去丈夫的体面，把报告藏了起来；
- 他明知道夏乔还在吃叶酸、测排卵、怪自己，却一直没有说。

玩家不能替他揭发。陆嘉明也不能用“怕你难过”轻轻带过；他要承认自己的沉默让夏乔替两个人承担了失败。

### 第二拍：夏乔的反应

夏乔按现有人格经历四个动作：

1. 下意识提高声音，试图把谈话岔成普通家事；
2. 伸手整理桌面，却反复挪动同一张纸；
3. 追问报告日期，算清自己在不知情时又努力了多久；
4. 停止替丈夫找理由，让他继续说完。

她可以愤怒、委屈，也可以暂时不决定是否原谅，但不能立即被写成“听说有替代方案就高兴”。这场坦白先处理夫妻之间的真相，再进入借种请求。

玩家本拍只选择在场方式：

- `让夏乔把问题问完`；
- `把水推到她手边`；
- `提出先出去等`。

替丈夫辩解会被夏乔打断，但不会直接写死路线，玩家可重新选择。

### 第三拍：陆嘉明提出借种请求

坦白完成后，陆嘉明把匿名资料与玩家姓名磁贴推到桌子中央，说明家庭计划让他认真考虑了另一条路。

他亲口向玩家提出请求：如果夏乔仍然想要孩子，玩家是否愿意作为他们共同信任的人提供帮助。

请求必须同时包含三层意思：

- 陆嘉明仍愿意承担丈夫和父亲的位置；
- 他选择玩家作为候选，但不能替夏乔同意；
- 玩家可以拒绝，不承担关系或经营惩罚。

这一拍的戏眼是一个平时一天说不了十句话的人，第一次把最伤自尊的话完整说完。

这里是本场唯一一轮玩家文本瓷砖，不是地图上的房间行动：

- `我愿意，但先听夏乔怎么说`；
- `先把三个人的边界说清楚`；
- `我现在不能答应`。

前两项进入第二幕，第三项正常暂停。

## 三、借种第二幕：《夏乔的决定》

### 第一拍：她问的不是“能不能怀”

夏乔不会立刻讨论受孕概率。她先问玩家：帮助他们要孩子，和想得到她，是不是被玩家混成了同一件事。

这里不再出现第二轮玩家选项。脚本根据夏乔当前阶段、好感／堕落／婚姻等真实数值、已经完成的`孕欲`线路、近期关系记忆和既有人格，先确定她本次是`接受`、`延期`还是`拒绝`，正文只负责演出。玩家不能靠选中一句正确答案改变她的结论。

她仍按夏乔的人格表现：行动先于自省，紧张时更忙、更响；可以承认自己也渴望玩家，也可以因为丈夫隐瞒而暂时不愿继续，但不能等待丈夫或玩家替她决定。明显不成立的阶段和数值应在路线入口阻止；旧档或异常状态不满足时，由她延期或拒绝。

### 第二拍：把安排说清一次

不做逐条谈判或规则选择。若夏乔决定继续，陆嘉明只用一小段话说明固定安排：不观看、不记录；孩子由夫妻共同抚养；以后是否继续亲密仍由夏乔决定。

陆嘉明留在客厅或暂时离开101，由夏乔结合当前状态亲口决定；他始终不观看、不指挥、不检查结果。

### 第三拍：是否今晚开始

夏乔亲手决定是否把玩家姓名磁贴从`可信任的人`移到`孩子计划`。

今晚开始、等到下一个易孕窗口或今天只谈到这里，都由前一拍已经算出的夏乔决定自然落地，不显示成玩家按钮。她选择延期时不重演丈夫坦白和家庭安排；下一次由夏乔本人通过微信邀请。她明确拒绝时结束路线。

## 四、借种第三幕：《第一次尝试》

### 第一拍：夏乔自己关门

陆嘉明按她的决定留在客厅或离开。关卧室门、决定灯光和让玩家靠近的人必须是夏乔。

她仍会本能地张罗毛巾、饮料和窗帘，用忙碌掩饰紧张。玩家可以：

- 等她自己走回来；
- 告诉她今晚不是来催交备孕作业；
- 再问一次是否要延期。

催促她抓紧易孕时间会让本拍停下。

### 第二拍：她不是一项备孕任务

夏乔会问：如果这一次没怀上，下一次见面是不是又只剩日历。

玩家必须承认结果无法保证，并把夏乔本人放回场景中心。可以表达渴望，但不能只称赞她适合怀孕、适合做母亲或把身体写成计划工具。

人物表现继续遵守夏乔既有差分：主动、直接、行动先于自省；越紧张越忙，越强烈越容易失去说话节奏，但不坍缩成统一淫语或等待命令的人。

### 第三拍：有效受孕尝试

真正可能触发怀孕判定以前，再提供一次明确选择：

- `等夏乔亲口确认后完成尝试`；
- `改用保护措施`；
- `在体外结束`；
- `现在停下`。

只有第一项在有效正文中真实完成无保护阴道内射，才提交一次`101借种有效尝试`。其他选项都是合法收束，不降低好感、不清除已经确认的家庭安排，也不占用当天怀孕判定。

### 第四拍：门重新打开

门由夏乔打开，陆嘉明只有在她叫他时才回来。

他只确认夏乔是否需要水或空间，不询问过程、不检查身体，也不向玩家作战果式道谢。三个人面对计划板，承认今天只是一次尝试，结果还不知道。

这时才原子提交尝试票和现有怀孕判定。

## 五、未受孕后的再次尝试

若未受孕，不重演家庭计划、丈夫坦白和三人谈判。下一合法窗口由夏乔发来简短邀请，101 出现`按计划再见`。

每次仍需要：

1. 夏乔当次主动邀请；
2. 卧室门前再次确认；
3. 玩家可保护、体外或停止；
4. 有效完成后才运行一次现有怀孕判定。

尝试次数只影响回忆和终幕语气，不改写现有 60%／80%／100%连续失败补偿。

## 六、借种终幕：《计划成真》

### 触发

只有现有怀孕真值进入`已告知`，且夏乔已经先告诉陆嘉明，夫妻才共同邀请玩家到 101。受孕当晚、待告知期间或玩家提前知道脚本结果时都不能触发。

### 第一拍：夏乔亲口告诉玩家

门由陆嘉明打开，结果由夏乔宣布。她可以高兴、慌乱、话快得自我打断，但不能让丈夫替她宣布，也不能把这一刻写成玩家验收血脉。

计划板新增真实产检日期，不提前出现孩子性别、姓名或出生结果。

### 第二拍：姓名磁贴收起来

夏乔把玩家姓名磁贴从`孩子计划`取下，放回最初的无署名信封，收进计划板旁的抽屉。

含义是：玩家的帮助不会被抹掉，但他的名字不作为父权、所有权或公开秘密钉在墙上。最终 101 背景只保留夫妻的产检与生活安排。

### 第三拍：丈夫的承诺落到生活

陆嘉明在计划板上写下：

- 由他请假陪同产检；
- 明确承担家务与孕期照料；
- 对外口径由夫妻共同决定；
- 怀孕不等于夏乔必须原谅他此前隐瞒检查结果。

### 第四拍：“夏乔自己的事”

夏乔在`孩子计划`旁新增一栏：`夏乔自己的事`。

里面可以有：

- 稳定期以后去一次 livehouse；
- 联系以前奶茶店的同事；
- 尝试周末小摊或外卖窗口，重新做喜欢的饮料。

这才是人物终点：她终于得到想要的孩子，却没有再次把自己活成生育工具。她能成为母亲，也仍然是那个会开店、追现场、大声笑的夏乔。

结局标题建议：`计划成真`。副标题：`不是任务完成`。

## 七、内容状态与失败边界

| 状态 | 含义 |
| --- | --- |
| `丈夫已坦白` | 检查结果和隐瞒已由陆嘉明亲口说出 |
| `借种请求已提出` | 丈夫正式邀请玩家成为候选 |
| `借种安排已确认` | 夏乔已经决定继续，家庭安排已经说明 |
| `待首次尝试` | 选择改日，不重复谈判 |
| `待下次窗口` | 已尝试但未受孕，可由夏乔再次邀请 |
| `已受孕待告知` | 只供脚本内部承接，正文不得泄露 |
| `计划成真` | 正式告知完成，结局成立 |

- 丈夫坦白或借种请求生成失败：不推进本幕，赴约票保留；
- 玩家暂不接受：正常暂停，不惩罚；
- 夏乔拒绝借种：二次确认后关闭路线，只有回档改变；
- 成人轮失败、取消、保护、体外或停止：不运行怀孕判定；
- 重掷和重复观察：同一票据只提交一次；
- 回档、删楼或切分支：路线、计划板、邀请和怀孕真值共同恢复。

## 八、当前内容结论

1. 家庭计划是完整前置，不在借种正戏里重新审判前置手段；
2. 借种第一幕固定为陆嘉明坦白男方检查结果并亲口提出请求；
3. 第二幕才轮到夏乔决定和三人定边界；
4. 第一次尝试可以当晚，也可以由夏乔选择改到合法窗口；
5. 最新暂存口径把完成分成两层：夏乔决定继续并完成第一次有效尝试后，101的关系性质已经改变；正式怀孕告知后再进入`计划成真`终幕。此项仍待继续修改。

## 九、结局系统定位（暂存方向，尚未拍板）

### 1. 三层结构

当前建议把整条路线拆为同一结局项目的三个连续阶段：

1. 商店`结局`分页中的`家庭计划`项目卡；
2. 购买后启动的五日地图互动前置；
3. 微信赴约后固定发生在101的借种结局特殊场景。

地图前置负责让玩家参与筹划，101固定场景负责完成关系转折。它们不是两个商品，也不重复收费。

### 2. 与普通特殊场景的边界

- 玩家界面新增独立页签`结局`，内部配置类型可命名为`结局场景`；
- 普通特殊场景仍然服务一次性表演、奖励和小范围状态变化；
- 结局场景代表住户关系模式的永久改变，因此不写入普通`已完成特殊场景`账；
- 运行时可复用现有特殊场景的固定地点、多拍生成、移动／时间锁和互斥能力，但普通特殊场景与结局场景必须共用同一个活动互斥槽，不能并发运行；
- 结局项目卡购买后不消失，暂定显示`尚未开始`、`筹备中`、`待赴约`、`关系已改变`、`计划成真`等进度。

### 3. 固定地点与场景分区

借种结局固定在101，不另建旅馆或管理员室场景：

1. 101客厅：陆嘉明坦白检查结果并提出请求；
2. 计划板前：夏乔完成质问，由她决定是否接受，三人确认边界；
3. 101卧室：在她当次仍然同意的前提下完成第一次有效尝试；
4. 回到客厅：三人承认结果尚未知，并提交新的家庭关系事实。

若夏乔选择改日，当前谈话场景应正常结束并写入`共识已立／待首次尝试`，以后由101重新出现赴约入口；不能让活动中的特殊场景跨日占住全局运行状态。

### 4. 完成后改变的是关系性质

该结局不应通过简单拉满堕落、清空婚姻或只写丈夫`结局轨道`来表达。暂定为101增加结构化的户级关系状态，例如`知情借种家庭`，至少保存以下事实：

- 陆嘉明已经坦白男方生育问题；
- 夏乔本人明确同意这项家庭安排；
- 玩家是夫妻共同认可的帮助者；
- 陆嘉明承担社会父亲和家庭照料责任；
- 每次尝试仍需夏乔当次主动确认；
- 丈夫不观看、不验收过程，也不取得对夏乔身体的支配权；
- 对外口径仍由夫妻共同决定。

这项关系状态应优先影响101的正文人格、快照、丈夫反应、孕情微信、丈夫登门、手机邀约、地图行动、档案徽记和冲突场景判断。它只改变家庭结构的解释，不能被写成夏乔从此默认同意所有亲密行为。

### 5. 两层完成点

- `借种关系成立`：借种安排已确认，并完成第一次有效尝试。即使当次未受孕，101也已经进入新的家庭安排，后续由夏乔主动邀请再次尝试；
- `计划成真`：怀孕真值经过既有隐藏期并正式告知后，触发当前设计中的最终终幕。

每次有效尝试需要保存独立的`家庭计划借种`来源，让怀孕微信、丈夫登门和相关提示不再退回普通偷情／对质语义。现有60%／80%／100%连续失败补偿暂时保留。

### 6. 既有孕情与冲突路线

暂定只有夏乔处于`未孕`时才能进入该结局的可执行状态。已经由普通亲密场景形成的孕情不能被后来的丈夫同意追认成借种结果；是否为既有孕情另写分支，留待以后单独决定。

结局页的具体显现时机、商品价格、冲突结局清单、拒绝后的永久关闭规则以及`借种关系成立`的准确提交拍，均保留为待修改项。
