## 一、已经确认的结构

1. `家庭计划`是玩家持续暗示陆嘉明的地图任务；
2. 家庭计划成功的确定结果是：陆嘉明已经决定借种，并选定玩家；
3. `赴约`只负责让陆嘉明把这个既定决定正式告诉玩家，正文有效完成后家庭计划任务结束；
4. 家庭计划完成以前，商店不显示`借种`；
5. 家庭计划完成以后，商店`特殊场景`分页才出现独立商品`借种`；
6. `借种`特殊场景不再讨论、检定或说服陆嘉明是否同意；
7. 该特殊场景本身就是夏乔的结局剧情，场景有效完成时直接登记夏乔结局完成；之后没有`待再次尝试`、`计划成真`或第二层终幕任务。
8. `借种`商品解锁后可以在任意日期购买，但特殊场景只能在夏乔固定易孕日`星期一`启动；星期限制只拦截新开场，不中断已经开始的结局。
9. 本场固定要求夏乔处于阶段5；不得为阶段1—4制作降级版，也不得在场内重演第一次接吻、第一次触碰、身体适应或是否准备好的试探。

## 二、商品与开演方式

### 商品

- 名称：`「借种」`；
- 分类：现有商店`特殊场景`分页；
- 出现条件：持久事实`家庭计划完成`；条件未满足时完全隐藏，不显示灰锁商品；
- 唯一性：每局只能购买并完成一次；
- 与家庭计划的关系：两个独立商品、两套独立状态，不共用项目卡，也不重复收取家庭计划套件费用。

货架文案建议只透露已经准备就绪，不重复解释前置：

> 101的计划板上，最后一个位置已经留好了。

### 启动

采用现有`背包使用＋指定地点`方式：

1. 玩家购买后得到一次性场景票`借种`；
2. 商品在家庭计划完成后立刻出现，任意星期都可购买，不要求玩家为了购买等到星期一；
3. 玩家只能在`星期一`的晚上或深夜前往101使用；
4. 非星期一、地点错误或时段错误时，只显示尚未到启动窗口的反馈，不消费场景票、不写入运行态，也不推进时间；
5. 条件满足时只出现一次简单确认：`进入借种结局`／`暂时不开始`；
6. 确认后才原子消费场景票、写入`场景进行中`并冻结本场状态。

这一步只是防止误触，不是剧情选择。商品购买不会自动把玩家从其他地点拖入101。

星期一只检查一次`未开始 → 进行中`的启动事务。场景开始后玩家被限制在101，不能执行推进世界时间的地图行动，正文回合也不推进世界时间，因此整场自然停留在启动时的星期一时段。刷新或重开界面只按持久的`场景进行中`状态恢复，不重复检查星期。启动失败、取消确认和非星期一误用均不得留下半消费票或半运行状态。

## 三、玩法核心

这场结局不再把“是否借种”做成问题。真正的玩法是：同一个已经确定会发生的结局，按照这一局夏乔真实走到的状态，演成属于她的版本。

场景开始时一次性冻结以下表现输入：

| 输入 | 影响什么 | 不影响什么 |
| --- | --- | --- |
| 当前阶段 | 启动时固定为阶段5，只负责开放她已经具备的完整亲密经验与玩法范围 | 不再生成低阶段适应、试探或第一次经历 |
| 好感值 | 她是否把玩家视为自己真正想靠近的人 | 不把低值变成答题失败 |
| 堕落值 | 她面对身体欲望时的直接程度 | 不把高值写成统一服从 |
| 婚姻值 | 她如何看待丈夫与这个家庭安排 | 不恢复丈夫的决定检定 |
| `孕欲`完成事实 | 借种主题与她既有欲望如何衔接 | 不当作永久授权台词 |
| 当前心理／情绪 | 当晚的紧张、期待、愤怒或释然 | 不由正文模型擅自改写结果 |
| 近期关系记忆 | 她与玩家已经共同经历过什么 | 不重复演第一次亲密 |

脚本负责把这些输入整理成当晚的表现标签，正文模型只演出已冻结的夏乔，不自行选择一套通用“借种人妻”人格。

### 夏乔固定人格

无论数值组合如何，都必须保留：

- 行动先于自省；
- 越紧张越忙、声音越响；
- 会用张罗水、毛巾、窗帘和时间掩饰真正情绪；
- 不会安静站着等丈夫把她交给玩家；
- 仍可能生丈夫隐瞒检查结果的气；
- 她对玩家的感情、身体欲望和想要孩子，可以同时存在，不必伪装成无欲的家庭义务。

## 四、正式场景：六拍

六拍都属于同一场特殊场景，不生成新任务、微信邀请或跨日状态。

### 第一拍：已经准备好的101

玩家使用场景票后进入101。

计划板、匿名资料和姓名磁贴仍在。陆嘉明不再复述五日前置，也不问玩家是否愿意。他只用很短的话确认：自己已经作出决定，今晚的安排不会再改变。

这一拍的作用是把家庭计划结果带入特殊场景，不承担新的选择。

### 第二拍：夏乔知道以后

陆嘉明把决定正式说给夏乔听，或确认夫妻已经谈过；具体采用哪种开场，由特殊场景开始时冻结的近期关系事实决定，不能让同一件事被重复告知两次。

夏乔的反应完全由状态演出，不显示玩家答题按钮：

- 好感较高时，她更容易把这件事与自己对玩家的真实渴望连在一起；
- 婚姻值较高时，她会更在意丈夫亲口承担决定，而不是把她推出来；
- 堕落值和`孕欲`越成熟，她越可能主动把计划从纸面推进到身体行动；
- 当前仍对隐瞒生气时，她可以先冲陆嘉明发火，但不会把场景退回“丈夫是否同意”的讨论；
- 近期已经与玩家多次亲密时，不重演第一次触碰或第一次接吻。

本拍结束时，夏乔亲手处理姓名磁贴或计划板，表示从这里开始由她接过这件事。不是玩家替她移动，也不是丈夫把她交接出去。

### 第三拍：由夏乔带玩家离开计划板

夏乔决定陆嘉明留在客厅还是暂时离开101，然后亲自带玩家进入卧室。

这个决定由她的婚姻值、当前情绪和近期关系事实生成，不给玩家二选一。陆嘉明不观看、不指挥、不使用摄像头，也不参与后续成人演出。

这里保留玩家唯一一次中途退出权：

- `跟夏乔进去`：继续结局；
- `现在停下`：场景安全结束，不登记结局完成，场景票恢复为可再次启动状态。

这不是说服夏乔的选项，只决定玩家是否继续自己已经购买的结局场景。

### 第四拍：她要的不是一项任务

进入成人正戏前，夏乔必须把她这一局真正的动机演出来。表现按冻结状态组合，不另设问答：

- 好感主导：重点是她想要玩家本人，不愿这晚只剩生育用途；
- 孕欲／堕落主导：重点是她主动把长期压抑的孕育欲望变成自己的选择；
- 婚姻主导：重点是丈夫终于承担决定，而她仍保留自己的身体主动权；
- 愤怒或矛盾主导：她可以一边执行已经决定的安排，一边明确这不代表原谅丈夫此前的隐瞒。

玩家本拍使用普通自由输入回应，不弹“正确台词”。正文按玩家实际态度和夏乔状态继续，但不能把场景重新写成同意检定。

### 第五拍：借种正戏

进入本拍后不启动普通`_性爱场景`前台，而是打开`接种`专属亲密循环：

1. **起始回合由夏乔主动**：她根据冻结状态决定第一步怎样靠近、怎样把玩家带进节奏，不能把开场责任推回玩家；
2. **之后开放玩家互动循环**：每一轮玩家先选择`顺着夏乔`或`接过节奏`，再使用自由输入写实际动作；正文必须先承接玩家当轮行为，再由夏乔按当前主动权与人物状态回应；
3. **至少两轮有效互动后**，只有当夏乔在成功正文中给出明确的临场信号，专属面板才进入`可以接种`状态；
4. 此时同时提供`继续亲密`和`完成接种`。玩家可以继续循环，不设强制回合上限；选择完成时使用无倒计时、无失败惩罚的长按确认，取代普通亲密框架的射精部位选择；
5. 长按确认后排队唯一的接种收尾回合：目标固定为夏乔、未使用保护、阴道插入并在体内完成。本回合成功落地后才进入第六拍。

`顺着夏乔／接过节奏`不是台词问答，也不决定成功或失败，只决定下一轮由谁主导动作。玩家可以逐轮切换，最终形成`夏乔主导`、`相互承接`或`玩家接手`的本场过程摘要，供第五拍后续正文与第六拍结局口吻读取。

中间不插入拖拽、限时连点、三轮规则确认或受孕概率小游戏。玩家在接种收尾正文成功前始终可以停止；停止时不登记完成并恢复场景票。

本拍的状态差分重点：

- 高好感不能只写成甜言蜜语，要表现她认得眼前这个具体的人；
- 高堕落不能写成无人格服从，要保留她主动、吵闹和会临场张罗的方式；
- 高婚姻不能把丈夫写成观看者，而是让她清楚这项家庭决定的重量；
- 任何状态都不能让陆嘉明通过门缝、监控或检查身体参与验收。

### 第六拍：夏乔结局

有效收尾后直接进入同一特殊场景的结局拍，不再等待一周、发送怀孕通知或生成第二个终幕。

结局拍只收束三件事：

1. 夏乔亲手在计划板上完成最后的状态变化；
2. 陆嘉明的决定已经执行，但不检查过程，也不向玩家作战果式道谢；
3. 夏乔以符合本局状态的方式确认，这不是丈夫替她完成的任务，而是她已经接过并完成的选择。

本拍有效落地后原子登记：

- `特殊场景：借种`已完成；
- `夏乔结局：借种`已完成；
- 商品、场景票和101入口永久关闭。

这里就是夏乔结局的完成点。之后普通游戏可以读取结局事实改变口吻，但不得继续弹出借种任务、再次尝试或另一段“计划成真”终幕。

## 五、接种专属亲密框架

### 5.1 与普通亲密框架的边界

可以复用的底层能力：

- 正文回合生成、失败重试和楼层提交；
- 既往亲密经历与当前动作连续性；
- 成人CG舞台、加载降级与画面连续性；
- 玩家随时停止的安全语义；
- 最终有效行为事实向受孕／结局结算层提交。

不得复用到前台的普通框架内容：

- 普通亲密底栏与`PRIVATE SCENE`抽屉；
- 体力消耗、体力耗尽与失控收尾；
- 满意度钻石、满意目标、偏好命中和主焦点切换；
- 保护状态选择、行为／部位管理和射精位置菜单；
- 普通亲密场景的自由结束与通用结果卡。

`借种`由`_特殊场景`状态机独立拥有拍次、互动轮数、当前主导权、可以接种状态和最终提交。普通亲密账本不得与它并行启动，也不得在特殊场景结束后残留一个半开的`_性爱场景`。

### 5.2 专属面板

第四拍结束后，输入区上方出现轻量的`接种场景`专属面板，替代普通亲密底栏。面板只显示：

- 固定时机：`星期一`；
- 当前阶段：`夏乔主动`／`互动中`／`可以接种`／`收尾中`；
- 当前主导：`夏乔`或`玩家`；
- 操作：`顺着夏乔`、`接过节奏`、`停止`；
- 达到条件后追加：`继续亲密`、`长按完成接种`。

面板不显示数值进度条。系统内部可以记录有效互动轮数，但玩家看到的是夏乔是否已经给出信号，而不是`0/2`式任务计数。

选择主导方式后不会自动替玩家编造具体动作；它只设置下一轮的演出方向，玩家仍通过自由输入完成真正的参与。如果玩家直接在原生输入中清楚表达跟随、接手或停止，脚本可以识别并同步同一状态，但不得让自由文本跳过最少互动、直接伪造接种完成。

### 5.3 明确不提供的选择

本场不再提供：

- 丈夫是否同意；
- 说服夏乔；
- 三枚共识；
- 逐条规则确认；
- 丈夫等待地点选择；
- 今晚／改日选择；
- 怀孕概率或重复尝试。

## 六、完成、失败与回档

| 情况 | 处理 |
| --- | --- |
| 商品购买后尚未开演 | 场景票留在背包，可稍后到101使用 |
| 非星期一、地点或时段不合法 | 不消费场景票，不启动场景 |
| 启动确认取消 | 不消费场景票 |
| 正文生成失败／取消 | 不推进当前拍；恢复到本拍开始前，可重试 |
| 玩家在第三拍退出 | 不登记结局完成，恢复场景票 |
| 玩家在专属亲密循环中停止 | 不登记结局完成，清除互动摘要并恢复场景票 |
| 已选择主导方式但当轮正文失败 | 不增加有效互动轮数，不改变主导摘要，保留在原轮重试 |
| 长按未完成或被取消 | 不排队接种收尾，不改变`可以接种`状态，可继续互动 |
| 接种收尾正文生成失败 | 保持`可以接种`与最终提交令牌，允许重试，不重复消费场景票或重复结算 |
| 重复点击或迟到旧正文 | 同一场景票和拍次只提交一次 |
| 回档／删楼／切分支 | 商品、场景票、当前拍和结局完成事实随有效存档恢复 |
| 第六拍有效完成 | 原子写入特殊场景完成与夏乔结局完成，不再恢复场景票 |

场景运行期间继续占用现有特殊场景互斥槽，冻结普通地图行动、时间推进、后台特殊事件和其他大型场景。数据库长期记忆是可选副作用，写入失败不能阻止结局核心提交。

## 七、第一版暂不决定的参数

- 商品价格；
- 专属面板的最终视觉、按钮文案与长按时长；
- 具体CG数量和每拍对应画面；
- 好感／堕落／婚姻的具体分档阈值；
- 结局完成事实在档案卡、商店和101门牌上的最终显示文案。

这些参数不改变已经确认的结构：家庭计划结束后解锁独立借种商品，借种特殊场景本身完成夏乔结局。
