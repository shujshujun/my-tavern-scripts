## 一、v2 改了什么

| 项目 | v1 | v2 |
|---|---|---|
| 丈夫的现场行为 | 只观看、只对话 | **对着自己妻子的记录自行手淫至完成**，这是本场高潮 |
| 何俊生的处境 | 自愿、专注、有礼貌 | **被迫**：他无权拒绝，也无权要求单向忠贞 |
| 陪看人的功能 | 端设备、转达托付 | **她本人即现场刺激层**：低胸短裙、贴耳距离、全程不可接触 |
| 贞操锁 | 写成前提，全程不动 | 锁着 → 宣读授权 → 解开 → 本人重戴 → 陪看人核验锁定 |
| 授权 | 六幕里反复征求同意 | 收成单一节点：宣读妻子预留的条件，接受才继续 |
| 两户关系 | 对称的两次友好交付 | **不对称**：顾国栋获得观众席，何俊生只有这一次 |
| 母带 | 信息三段 | 两盘独立十拍 **× 与丈夫身体状态、陪看人距离逐拍耦合** |

**v1 是交接，v2 是演出：丈夫是表演者，陪看人是唯一在场的观众，玩家是观众的观众。**

## 二、v1 中确认保留的部分

1. **固定观看视角链**：302监控界面 → 102／202现场 → 现场播放器 → 播放器里的既有记录。玩家不直切母带原始画面。这是本项目相对漫画的实质改进。
2. **两位妻子各自决定自己那盘交付什么**；送片人不能替录像里的妻子改口或加承诺。
3. **两路同一晚并行**，可以先后进入相近节拍，不要求机械同步。
4. **母带片段必须对应真实发生过的前置剧情**，不能挑图后反称玩家经历过。
5. **两路母带都只允许对应妻子与成年玩家，不得出现第三人、陌生客人、群交、性玩具、束缚、药物、组织、编号、面具、口塞、鼻钩、项圈或牵绳**。

## 三、动力结构：三层同时成立

丈夫在场内同时承受三层压力。**缺任何一层，这一场就退回 v1 的无后果版本。**

| 层 | 内容 | 作用 |
|---|---|---|
| 屏幕层 | 自己妻子选择留下的记录，尺度逐步升高 | 欲望对象＋"她是自己决定的"认知冲击 |
| 现场层 | 另一户的妻子坐在一臂之外，为被看而穿着，**不可接触** | 把私事变成有人在看的演出；羞耻与兴奋同源 |
| 身体层 | 贞操锁：锁着 → 授权解开 → 本人重戴 → 被核验 | 把"看"变成必须完成的事，并框定只有这一次 |

耦合规则：**屏幕层推进一格，身体层才允许推进一格，现场层随之收紧距离。** 陪看人不领先于屏幕，丈夫不领先于授权。

### 现场层的硬规则

陪看人从进门到离开**不与对方丈夫发生任何身体接触**：不替他解锁、不触碰他的身体或性器官、不脱衣、不露乳头或外阴。她穿奶白低胸针织上衣、黑色超短裙、黑色大腿袜、银手链；允许乳沟、大腿与贴耳说话。

这不是安全声明，是机制本身：**她穿成这样却明确不可及，丈夫的欲望只能转回屏幕上自己的妻子。** 她一旦可及，这一场立刻塌掉。丈夫若把注意力转向她，她的处理是提醒他看回屏幕。

## 四、两户不对称：同一套动作，两种含义

现场机械动作完全一致，得到的东西不同。**这是两条线的全部区别所在，不能写成两次友好交付。**

| | 顾国栋（102） | 何俊生（202） |
|---|---|---|
| 他为什么获准 | 他此前主动预约，接受沈静仪定的观看纪律 | 他必须面对周小满已经做出的选择，**无权继续要求单向忠贞** |
| 他的姿态 | 主动、羞耻、兴奋、对妻子的新认知并存 | 先想质问 → 无法自居受害者 → 只能吞下 |
| 陪看人如何进门 | 周小满：轻声，但把托付的话说完整 | 沈静仪：端庄、近乎公事公办 |
| 他事后交出什么 | 空白录像带或书面回执，意为"下一次仍由沈静仪决定" | **202住户钥匙／门禁凭据** |
| 长期含义 | 进入沈静仪安排的**观众席**；每次是否观看仍由她重新授权 | 只有这一次；不获下一盘、不获观众席、不进开放关系 |
| 允许的事后情绪 | 感激、忐忑、期待下一次 | 愤怒、痛苦、失眠、无话可说；**但不能恢复成道德胜利者** |

何俊生这一侧是"被迫"，但被迫的来源必须是**已经存在的事实**（他自己的外遇证据、周小满已收回备用钥匙），不是本场新造的把柄。沈静仪只引用，不添加。

## 五、八幕剧情

两路并行。每幕先写 102，再写 202；同幕内两路允许错开几分钟。
逐镜分镜、机位与可直接使用的完整提示词见 [v2 逐镜分镜与提示词](./录像带_v2_逐镜分镜与提示词_2026-08-31.md)（36 镜）。

### 第一幕 · 302：两份交付物

桌上两份已整理好的记录与对应播放器。两位妻子确认收件人与内容，没有临时换片。玩家不替她们决定送什么。

- 沈静仪：「到了以后，先让他看清楚，这是我给他的。」
- 周小满：「你那边也是。开头那段，让他听完。」

玩家检查两路监控覆盖交付区域，本次送片开始。
**幕末状态**：两份内容与去向明确；两位妻子出发；玩家留在302。

### 第二幕 · 门口：两种进门

**102**——顾国栋听见敲门走到门边，看见周小满手里的交付物，让开位置。他不演怀疑。
- 顾国栋：「是静仪托你来的？」／ 周小满：「嗯。她让我亲手带给你。」

**202**——何俊生开门先说客套，看到播放器把话收回去。他**试图质问**，沈静仪只引用已存在的证据和钥匙事实。
- 何俊生：「她还真让你亲自送来了。」／ 沈静仪：「是她自己托我的。方便进去吗？」
- 何俊生想争两句，沈静仪：「这些你都知道。是要在门口说，还是进去看？」

**幕末状态**：两位丈夫都让送片人入内；102是接受，202是无法拒绝。

### 第三幕 · 设备摆好，尚未播放

陪看人把播放器放到丈夫面前、调好支架，位置同时满足丈夫可看与监控可见。**不靠镜头穿墙穿屏。**

- 顾国栋：「她说现在就可以看？」／ 周小满：「嗯。你还想看吗？」／ 顾国栋：「想。放吧。」
- 沈静仪：「现在开始？」／ 何俊生把椅子拉近：「……放。」

**此时贞操锁仍锁着，钥匙／控制权在陪看人手里。**
**幕末状态**：两台设备就位，画面未亮。

### 第四幕 · 授权节点（本场的机制枢纽）

**这一幕是 v1 缺失最关键的一幕。** 播放开始后不久，陪看人宣读录像中的妻子**预先留下的授权**，条件明确：

> 只限本次、只限这一盘、结束后立即重新戴好、由陪看人核验。

丈夫必须**明确表示接受**，陪看人才交出钥匙／解除控制，允许他自己解下贞操带。

- 周小满宣读沈静仪的授权后：「她说完了。你接受吗？」／ 顾国栋：「我接受。」
- 沈静仪宣读周小满的授权：「只有今天，只有这一盘。完了你自己戴回去，我看着你戴。」／ 何俊生沉默较久，才：「……知道了。」

**硬门：解锁动作由丈夫本人完成，陪看人不上手。** 她只在旁确认他没有把观看对象转向自己。
**幕末状态**：两人都已接受条件、已解锁；欲望对象被明确框定为屏幕里自己的妻子。

### 第五幕 · 屏幕推进，身体跟随

母带信息十拍，与身体层逐拍耦合。102 和 202 各有自己的十张屏幕资产，不能共用妻子画面，也不能用五张高光代替完整过程。第一拍播放时贞操锁仍锁着；片头后完成授权与本人解锁，第二拍才进入成人段：

| 母带阶段 | 屏幕内容 | 丈夫的身体层 | 陪看人 |
|---|---|---|---|
| 01 片头 | 对应妻子与成年玩家同框；妻子亲手开录并讲清这是她选择留下的记录 | 仍锁着，还没开始 | 坐在一臂外，安静；片头后宣读授权 |
| 02 进入 | 片头后进入明确前戏，仍只有妻子＋玩家两名成年人 | 本人解锁后开始，动作克制 | 保持距离，只在被问时回答来源 |
| 03 主动参与 | 妻子主动回应玩家 | 连续动作，不把这一段跳成摘要 | 不替妻子解释感受 |
| 04 首次性交 | 第一张无法误读的性交证据 | 明显加快 | 安静见证，不接触 |
| 05 连续换位 | 保持连接与场景连续完成换位 | 调整呼吸但不退出播放 | 可在片段间隙说明另一户也在进行 |
| 06 妻子掌控 | 妻子主动控制并经历第一轮高点，录制继续 | 随屏幕升档 | 可贴耳提醒，双手留在自己身上／设备上 |
| 07 第二轮升档 | 后半轮继续推进 | 保持连续，不提前收口 | 退回原距离 |
| 08 峰值准备 | 妻子明确选择继续，以一对一无玩具准备承接下一镜 | 短暂停顿，仍看屏幕 | 不催促、不做身体动作 |
| 09 硬核峰值 | 本盘最高尺度与明确完成 | 接近完成但暂不结算 | 提醒他看完 |
| 10 片尾 | 保留上一镜结果；妻子亲自留话并停止录制 | 对着自己妻子的画面完成 | 仍不接触，只见证结果 |

丈夫的提问在这一幕发生：
- 顾国栋：「这一段也是她自己留下的？」／ 周小满：「是，她自己选的。」他点头，让她继续。
- 何俊生起先想用玩笑填满安静，听到周小满在片子里继续说话后自己停下。沈静仪不训诫，只等他把注意力放回屏幕。何俊生：「这一段先别跳。」

**幕末状态**：两条线都出现可见、可听的主动回应；两人都已接近完成。

### 第六幕 · 另一户也在进行

在一个片段间隔里揭示同步安排。**重点是两位妻子的合作，不是突然扩大谁能接触录像。**

- 顾国栋：「你那边呢？」／ 周小满：「静仪这会儿也去了202。带的是我的那份。」／ 顾国栋：「所以是你们一起商量好的。」／ 周小满：「嗯。各自那份，都是自己选的。」
- 沈静仪：「小满正在102，把我的那份送过去。」／ 何俊生：「你们倒是配合得挺好。」／ 沈静仪：「她交代的，我会说清楚。」

送片人只能说自己知道的安排，**不能隔空报告另一户丈夫此刻的表情或台词**。玩家拥有双路观察，能看到她们看不到的另一半。

**幕末状态**：两路在剧情上连起来；玩家理解这是互相完成的托付。

### 第七幕 · 完成、重戴、核验、离开

**这是本场的收口，四个动作缺一不算完成。**

1. 丈夫**只对着自己妻子的记录**完成；精液落在自己身上／手上，陪看人不接触。
2. 他**本人**重新戴好贞操带。
3. 陪看人**核验锁定状态**，收回钥匙／控制权。
4. 丈夫交出回执：102是空白带或书面回执；202是**住户钥匙**。

- 顾国栋：「告诉静仪，我看完了。」收设备时又补：「后面的事，我想听她亲口说。」
- 何俊生：「这些话，你会都带回去？」／ 沈静仪：「你要我转达什么？」／ 何俊生：「算了，我自己跟小满说。」

**不写成永久授权。** 陪看人分别收好设备告别离开；不新增她们与对方丈夫的亲密关系。
**幕末状态**：两次观看均已完成并核验；两位丈夫留在各自家中。

### 第八幕 · 302 收口

玩家先在监控里看见她们离开，行程合理后见她们返回302。**同一人不能同时出现在两处。**

- 周小满把沈静仪的那份放回桌上：「他看完了，说后面的事想听你自己说。」
- 沈静仪没有立刻当成永久承诺，把另一份还给周小满：「他也有话要跟你说，不过这次他说想自己来。」
- 周小满看一眼手机，没有急着念出来。两人相视片刻，绷着的神情才松下来。

玩家可询问她们的亲身感受。两份记录重新放好，302退出观看界面。

**事件结果**：两次交付完成；两位丈夫已在授权范围内完成观看并重新锁定；顾国栋进入观众席，何俊生只有这一次；两位妻子完成彼此的托付。

## 六、玩家在这一场做什么

- 开始前确认记录、送片对象与两路可见范围；不替角色同意。
- 观看时切换关注左路／右路／双路；不进入两户代替角色说话。
- 返回302后与两位妻子交流，结束场景。

以观看与人物回应为主，不加搬运、解谜或分数小游戏。**切换监控不暂停现实现场。**

## 七、必须保留的漫画高潮点清单

以下八项来自漫画 109–126，是这一段之所以成立的原因。**任何后续修订不得再次删除。**

1. 丈夫看到的是自己妻子的成人录像，且知道是她自己选择留下的。
2. 送片人留在现场陪看，不是放下东西就走。
3. 送片人以低胸、超短裙、大腿袜、乳沟、大腿与贴耳距离构成现场刺激。
4. 送片人全程不与丈夫发生身体接触；丈夫的欲望只能转回屏幕。
5. 丈夫**当着送片人的面，用自己的手，对着自己妻子的录像完成**。
6. 母带尺度逐级升高，丈夫的身体反应与之同步。
7. 送片人告知另一户正在进行对称的事。
8. 完成后丈夫本人重戴贞操带、被核验、交出回执／钥匙。

## 八、明确不采用的漫画元素

社长、组织、母猪编号、酒店招待、陌生客人、多人轮流、面具、口塞、鼻钩、第三人在场；送片人裸露乳头或外阴；送片人替丈夫手淫／口交／任何身体服务；丈夫对着送片人完成；两位丈夫进入302。

## 九、反推何俊生线时只取这些终点条件

| 本场需要的事实 | 本轮不决定 |
|---|---|
| 他有绿帽偏好，本场自愿到场 | 何时发现、如何承认 |
| 开场前已戴锁 | 谁提出、怎样达成、钥匙长期归谁 |
| 他自己的外遇证据已经存在 | 外遇的具体经过与时间 |
| 周小满已收回备用钥匙 | 收回的具体场次 |
| 沈静仪能作为受托送片人进入202 | 两位妻子怎样建立信任 |
| 他本场交出住户钥匙，且不获下一次 | 他之后住哪、关系如何长期变化 |

**不以"他必须搬走""他罪有应得"倒过来假造历史。** 需要角色线自然走到这些事实。
