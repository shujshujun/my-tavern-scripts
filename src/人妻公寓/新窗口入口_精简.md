## 四、不可回退的运行规则

- 唯一世界钟是 `系统._绝对时段`；普通聊天和微信不自动推进时间。
- AI 不直接结算时间、精力、体力、满意度、现金、胜任度或风闻。
- 变量写权只开放给本轮精确演员；旁观者和后台住户保持只读或不进入提示。
- MVU 外置模型解析开启时，正文二次结算必须关闭；未开启时只向玩家建议按需开启二次结算。
- 亲密“过久”保持原名称，含义为已经达标并超过角色理想楼数上限后的正面“超满意”。
- 初始精力／体力为 `8／5`；体力五级上限为 `5／7／10／12／15`。
- 阶段剧情、特殊场景和任务只能在有效正文成功落地后提交；失败、取消、错场、重掷和重复点击不得推进。
- 日常文本中的“床单、音乐高潮、亲密关系、讨论体位”等普通词语不得误开成人写权。
- 不恢复智脑路线，不增加旧存档兼容分支。

## 五、新窗口工作方法

1. 先运行 `git status --short`，确认用户脏工作树。
2. 从待办清单选中一个具体编号，只读取对应源码、设计小节和测试。
3. 先核对现状与可复现缺口，再修改；不要从历史聊天猜实现状态。
4. 新功能必须同时具备：运行状态、UI入口或事件入口、成功提交、失败／取消／回档边界和专项测试。
5. 先跑相关专项测试；只有功能完成准备交付时才跑一次全量回归。
6. 只有用户明确要求发布时才构建、组卡、commit、tag 和 push。
7. 手机或宿主 UI 任务需使用真实浏览器／手机画幅复核，并保存截图证据。
