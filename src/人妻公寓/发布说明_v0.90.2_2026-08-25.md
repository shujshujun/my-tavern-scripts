# 《人妻公寓》v0.90.2 发布说明

- 发布分支：`release/rq0902`
- 发布标签：`rq0.90.2`
- 角色卡版本：`0.90.2`
- 存档数据版本：`9`
- 兼容范围：v0.80(v7)、v0.81/v0.82(v8) 自动迁移；v0.83～v0.90.1(v9) 直接继续

## 本次热修

### 微信刷新恢复

- `_微信` 的正式真值仍保存在当前酒馆聊天变量；每次手机事务额外写入同聊天、单调修订的父窗口／`sessionStorage` 刷新恢复镜像，兜住宿主保存吞错后立即刷新造成的服务器旧值回退。
- 启动时先等待真实聊天楼轴和 metadata 就绪，再按聊天身份、楼层、绝对时段、分支指纹与修订号恢复，随后才启动手机节拍、红点和初始通知。
- swipe、删楼、回档、切聊天与重开均推进时间线世代；重开使用高修订清空墓碑，旧局微信不能因刷新复活。迟到的低修订事务也不能覆盖较新镜像。
- 玩家发送、角色回复、邀约、撤回、父亲通话、自动节拍、楼务通知、已读水位、摘要压缩与时间事务补偿均进入统一持久化边界。

### 数据库逐楼所有权

- `RQ_剧情事件` 的摘要由本楼最终正文同轮产生，脚本以 `floor_no + event_code` 双键精确写入；后一楼正文不能再填进前一楼记录。
- `RQ_剧情事件` 与 `RQ_社交轨迹` 关闭通用自动填表。安全模板不再调用无目标表的整批 `triggerUpdate`，其余人物记忆、承诺伏笔和纪要仍由数据库自动调度。
- 当前数据库版本的默认全选、显式选择、旧／新手动填表面板、追平按钮以及公开 `set/clear/manualUpdate` API 均排除两张脚本表；离开本卡或切到其他角色卡时恢复进入前的数据库全局手动选择。
- 只锁定表头完全匹配的本游戏表，同名但不同结构的作者自定义表不受影响。

### 重要朋友圈长期记忆

- “仅你可见”、荣耀路线公开暗示、换装余波晒装与家庭计划公开动态由脚本附带稳定 `RQP-朋友圈-*` 事件键后写入 `RQ_社交轨迹`。
- 数据库只保存结构化事件与后续影响，不保存朋友圈原文；普通晒饭、天气和同质化日常动态不进入长期表。
- 内存去重按聊天 ID、手机时间线世代和事件键隔离；切聊天、回档或 swipe 后，当前分支可重新建立已经被旧时间线撤销的记录。

## 旧档边界

- 空摘要、旧“待整理”摘要与明确失败占位会按各自楼层的持久元数据安全补写。
- 已经非空且写错的历史摘要不会被程序猜测性批量覆盖；玩家可手动删除对应错误行，后续补写会按该楼自身行动生成安全摘要。
- 刷新恢复镜像从 v0.90.2 开始建立；升级前已经从服务器和聊天变量中丢失的微信原文无法凭空还原。
