# 《人妻公寓》v0.91.5

- 发布标签：`rq0.91.5`
- 角色卡版本：`0.91.5`
- 上一正式版本：`0.91.4`
- 素材仓库：`shujun8520-design/qgy-assets`，继续复用不可变素材标签 `cg5`、`cg6`
- 存档数据版本：`9`；v0.80(v7)、v0.81／0.82(v8) 继续按既有规则迁移，v0.83～v0.91.4(v9) 可直接继续。

## 本次修复

### 1. RQ 剧情事件与社交轨迹重新稳定写入

- 修复 v0.91.4 回归后 `RQ_剧情事件`、`RQ_社交轨迹` 可能停止更新的问题。
- 游戏重开会清空上一局的五张数据库记忆表，并等待空表稳定后才开放新局写入；旧局迟到任务不能重新灌回新局。
- 删除消息按目标楼层之后裁剪，切换消息分支按被替换楼层及之后裁剪；`rq_events` 与 `rq_social_history` 都使用同一时间线世代、聊天身份和提交校验，旧分支迟到结果不能污染当前分支。
- 本次只修复社交轨迹的时间线恢复与写入生命周期，不改变群级摘要、实际接收者以及各接收者个人见闻之间的知情隔离设计。

### 2. 变量结算和主回合完成后的假忙态

- 主回合与手动变量重生成现在都会先结束事务、清理生成身份并释放共享前台租约，再向客户端广播完成。
- 已提交回合的数据库骨架、漏楼补齐和可选数据库 AI 填表会先可靠登记，再于下一任务拍异步执行；数据库等待不再占住玩家操作的“内容正在生成”门。
- 正文与最终变量已经提交后，后处理失败只会给出非阻塞提示，不会把已经发生的回合伪报成“本次操作没有发生”，也不会诱导重复执行。

### 3. 时间推进恢复门与数据库重开恢复

- 时间推进、睡眠、小憩、晨跑、健身和时间撤销继续与正文、变量、MVU、手机后台生成双向互斥。
- 数据库时间线恢复会持续核对待结算写入、实际表内容和稳定窗口；真正未恢复时仍严格阻止写入，恢复完成后不会残留长期假门。
- 删除、重掷、回档、原生 swipe、切换聊天和重开都推进统一时间线世代，旧异步即使经历聊天 A→B→A 的 ABA 切换也不能误认新现场。
- v0.91.4 已发布的自定义变量 API 自动恢复、宿主 Promise 保存回滚和游戏内置解析／MVU 单路线防双发完整保留。

### 4. 彻底删除“省流模式”和“减少动效”

- 设置页、共享状态、组件参数、CSS 根类及所有 `rq-lite`／`rq-still` 运行分支均已移除，不再允许这两个危险选项关闭背景、地图或关键动效。
- 地图只在立面图真实加载失败时使用玻璃楼体兜底；系统级 `prefers-reduced-motion` 仍按浏览器无障碍偏好正常生效。
- 启动、读取、保存及变量解析设置写回时都会再次剔除废弃字段，旧值不能被其他设置合并写重新带回。

### 5. 父页面／iframe 旧偏好迁移与启动链恢复

- 客户端在等待 DOM、MVU、`stat_data` 或 Vue 挂载之前，同步清理当前 iframe 与父页面根元素上的旧 class，并从可访问的父页／iframe 共享存储中只删除 `省流`、`减动效` 两个字段。
- 同一存储对象中的主题、字号、立绘、变量解析通道、自定义变量 API 配置及其他未知字段均被保留；跨域、隐私模式或存储异常只记录诊断，不会阻断游戏启动。
- 入口不再依赖 jQuery ready 这一条无超时前置门，改用浏览器原生 `DOMContentLoaded`／已就绪微任务；MVU 与变量依赖等待保持有界降级，修复旧偏好环境长期停在“游戏界面加载中”。
