# 人妻公寓：阶段攻略线路 V0.2（102—302）

> 本稿记录2026-07-30讨论确认的沈静仪、许曼君、周小满、安若妍与母亲路线。  
> 夏乔修订稿及全局机制见[阶段攻略线路设计](./阶段攻略线路设计.md)。

## 共通执行标准

1. 阶段0裂缝、确认信和开门礼物保持现状，后续路线不得要求重送或重演。
2. 晋阶路线默认玩家已体验到当前阶段允许行为的最大上沿；铺垫最多试探下一阶段半档，质变留给晋阶。
3. 阶段2默认可能已有拥抱、舌吻、长时间亲吻和隔衣抚摸；2→3不得退回初恋式接吻。
4. 阶段3默认可能已经多次发生基础性关系；3→4不得把主动亲吻当作重大突破。
5. 已发生的事实只产生新后效，不再次成为任务。
6. 所有硬节点均由脚本控制，满足前置后100%出现；错过时段会在下一相同时段重现。
7. 玩家只看到叙事暗示，不看到内部倒计时。“经过一个完整时段”是设计表达，最终参数进静态配置。
8. 道具启动故事，不以购买、赠送或装载成功直接结算。
9. 招牌性癖必须完成开幕正戏和后效，不能只装备。
10. 每条1→2、2→3、3→4、4→5线路前均有一个不计`1/4`进度的“节点0：上下文承接层”。它按`脚本完成记录 > 特殊场景记录 > 数据库明确经历 > 近期正文事实 > 本阶段最高实际尺度 > 阶段上沿默认值`选择接法，只改变节点1的动机、开场和第一条关系侧写，不代替任何固定关卡。
11. 自由RP若已超过路线最低描写，节点0必须把奖励改写为人物主题上的新选择；不得让角色失忆、关系倒退或重新演身体层面的“第一次”。
12. 文中“第一夜”统一指角色主题的首次质变，不强制是身体第一次。若可信历史已确认发生性关系，固定功能链照常完成，但末场改演“第一次不复原／不标价／明确选择她本人／完全关闭记录／清醒面对身份”等主题突破。

关系线索页在正式四条线索上方显示一条无勾选的动态侧写，例如`· 有些账，似乎早就不是第一次算了。`。这条侧写不属于任务进度，刷新也不能推进路线。

## 102 沈静仪：从被收藏到主动安排目光

### 0→1 陌生邻里→贞淑：被当作女人看见

保持现状：摄像头四段观察→确认无性婚姻→送正红色口红。口红和初始录像从此属于历史事实。

### 1→2 贞淑→动摇：把变化留给某个人看

阶段基线：玩家已能经常入户、独处、闲聊和送小礼物；她仍避开明确接触，但已习惯玩家停留。

1. **擦掉的红色**：开门事件经过一个完整时段，原摄像头记录她独处时涂上口红，听见丈夫回来的动静后又擦掉。
2. **明确的空窗**：玩家使用物业巡检表，脚本给出顾国栋下一个确定外出时段，不等待随机出差。
3. **弹完自己的曲子**：丈夫外出的下午，102出现钢琴事件。她弹完自己的曲子，没有中途合上琴盖，也没有擦掉口红。
4. **今天的颜色**：下一个傍晚在信箱区赴约。她允许一次接近接吻的停留，但仍停在正式接吻前，只问玩家“今天的颜色，好看吗”。完成后解冻19。

暗示方向：`她似乎在练习一种并不准备给丈夫看的颜色。`

### 2→3 动摇→越界：允许这个家无法恢复原样

阶段基线：拥抱、舌吻、长吻和隔衣抚摸都可能发生过；真正未跨越的是入衣、上床和发生性关系。

1. **收藏家的规矩**：与顾国栋对饮，专属事件必定谈到“好东西应保持品相和原样”。
2. **没有扶正的相框**：经过一个完整时段查看摄像头，发现沈静仪故意没有扶正玩家碰歪的相框。
3. **制造长空窗**：玩家使用外地项目介绍，让顾国栋确定离家一段时间。
4. **今晚不用恢复**：第二天晚上102出现事件。开场承接阶段2上沿；她主动解开发髻、推乱梳妆台，并阻止玩家恢复房间，随后进入第一夜。完成后解冻39。

暗示方向：`有些东西一旦被挪动，便不必再放回原处。`

### 3→4 越界→沉沦：她知道镜头存在，并决定不拆

阶段基线：两人可能已多次发生性关系；她仍关灯、整理痕迹，不主动安排。

1. **角度变了**：第一夜经过一个完整时段，摄像头角度被人为调整。
2. **没有拆掉**：玩家以检修为由进入102，触发固定对峙。她知道镜头存在，却只问玩家看过多少。
3. **主动走进画面**：经过一个下午，摄像头记录她主动站到画面中央并停留。
4. **灯与镜头都开着**：下一个晚上她主动微信邀请玩家；灯不关，镜头也不遮。她第一次主动选择目光、位置和时机。完成后解冻64。

暗示方向：`镜头的位置变过。知道它在哪里的人，不止你。`

### 4→5 沉沦→归属：从展品变成观看的导演

阶段基线：她已经可能主动邀约、尝试花样和大胆地点；终盘不再把开灯或面对镜头当作第一次。

1. **装载视奸欲**：购买并装载招牌性癖，完整完成专属开幕正戏。
2. **她选择机位**：经过一个完整时段，摄像头出现由她主动布置的新机位和位置提示。
3. **观众席前兆**：再次与顾国栋对饮，固定推进“有人欣赏才有价值”的丈夫逻辑；尚未开线时由本节点100%启动观众席前兆。
4. **观众由她安排**：她主动安排一次同时存在镜头、门缝或第二道目光的事件，决定谁看、从哪里看、何时停止。完成后解冻89。

`衣柜`仍是观众席结局奖励，不反过来卡个人晋阶。

## 201 许曼君：从替所有人算账到允许自己不讲等价

### 0→1 陌生邻里→贞淑：有人替她接住这个月

保持现状：街坊四段打听→确认娘家窟窿→送房租宽限批条。宽限批条从此是历史事实。

### 1→2 贞淑→动摇：一笔暂时无法偿还的人情

阶段基线：她接受过一次承担，却仍将其视为未来必须偿还的债。

1. **承诺真正落账**：下一次收租时玩家选择宽限或代垫，不再送第二张批条。
2. **夜里的缝纫机**：当天深夜201出现检修角标；玩家用工具箱入户，确认她仍接缝补活偿还这份人情。
3. **布头背面的细账**：经过一个完整时段翻垃圾，先发现布头；再经过一个时段复查，才看见背面写满偿还计划。
4. **划掉私人欠账**：下一个晚上管理员室出现事件。玩家将这笔私人债从正式账本划掉；她阻止时与玩家的手停留片刻，但仍不正式接吻。完成后解冻19。

暗示方向：`她接受了宽限，却没有真正放下那笔账。`

### 2→3 动摇→越界：第一次亲密没有价格

阶段基线：拥抱、舌吻和隔衣抚摸都可能发生；她会在事后补一句“我会还”。

1. **丈夫不知道的账**：与赵国强对饮，必定确认他完全相信妻子掌账，不知道欠租与娘家支出。
2. **主动制造空账期**：使用钓鱼团购券，让赵国强确定离开一个白天到晚上。
3. **她提出结算**：丈夫离开后，许曼君到管理员室试图把帮助、亲吻和今晚可能发生的事换算成价格。
4. **不记账的第一夜**：从阶段2上沿继续；玩家拒绝写价格，她也没有在事后要求记账，随后进入第一夜。完成后解冻39。

暗示方向：`她能接受交易，却不知道怎样接受一件无法偿还的事。`

### 3→4 越界→沉沦：第一次把资源花在自己身上

阶段基线：关系可能已多次越界；她仍习惯把亲密解释成还债、交换或临时失控。

1. **铁盒少了一笔**：新的收租周期后调查垃圾房，发现娘家汇款照常，私人铁盒却少了一笔钱。
2. **不是汇款单**：下一个下午，信箱区出现她领取私人包裹的事件；包裹是给自己的。
3. **她自己的衣服**：玩家送当前阶段服饰；她不再先算价格或考虑退换，并在经过一个时段后的大堂事件穿出门。
4. **今天不算值不值**：当晚她主动微信邀请玩家，理由与房租、补偿和人情无关。完成后解冻64。

暗示方向：`她最近的一笔支出，账本上没有写去处。`

### 4→5 沉沦→归属：给自己标价，再亲手划掉

阶段基线：她已能主动约玩家并体验多种私密玩法；终盘不是重复一次普通肉偿。

1. **一笔真实欠租**：新的收租周期保留一笔201欠租，系统提前预告。
2. **装载交易快感**：购买、装载并完整完成专属开幕。
3. **肉偿账本**：尚未完成时，解锁并完成唯一一次特殊场景；由她主动报价、报数，并从交易本身获得快感。若它已在自由流程中完成，本节点直接认已有脚本记录，并把节点0侧写与后续剧情承接到“账清以后为何仍会来”，禁止再次上架或复演。
4. **没有债也会来**：经过一个完整时段，她在管理员室撕掉两人的价格栏，承认账清以后仍会来。完成后解冻89。

## 202 周小满：从被忽略到主动占住自己的位置

### 0→1 陌生邻里→贞淑：有人记得她的名字

保持现状：与何俊生对饮四节点→确认外遇→送刻名手链。手链从此是历史事实。

2. **被拆掉的第二只鸟**：经过一个时段翻垃圾发现绣线；再经过一个时段复查，确认十字绣上的第二只鸟被主动拆掉。
3. **大堂里等她说完**：下一个白天的大堂事件中，她被别人打断，玩家留下并让她继续。
4. **猫记得她**：下一个傍晚触发喂猫事件。她主动讲完一件自己的小事，允许玩家握手片刻，但仍停在拥抱和接吻前。完成后解冻19。

暗示方向：`那幅绣了一半的图，不像没有完成，更像被人拆掉了。`

### 2→3 动摇→越界：不是丈夫缺席时的替代品

阶段基线：拥抱、舌吻、长吻和隔衣抚摸都可能发生；她仍不敢相信玩家明确选择了她。

3. **倒掉豆浆**：丈夫离开后经过一个时段，摄像头或入户事件记录她把等待丈夫的豆浆倒掉，没有再热一杯。
4. **一直叫她的名字**：下一晚进入第一夜；直接承接阶段2上沿，突破点是她主动关门，并要求玩家一直叫“周小满”。完成后解冻39。

暗示方向：`今晚的那杯豆浆，没有再被热第二次。`

### 3→4 越界→沉沦：第一次没有给别人让位置

阶段基线：两人可能已多次发生性关系；她私下可以主动，公开场合仍会缩回去。

1. **没有摘下的手链**：送当前阶段服饰；经过一个时段，她穿着新衣服和刻名手链出现在丈夫面前，引发固定家庭余波。
2. **姐妹群的半句话**：余波后的姐妹群必定议论她的变化；她第一次不只回复“不是的”。
3. **大堂撞场**：下一个傍晚安排可控撞场；另一位角色靠近玩家时，小满没有让开原本的位置。
4. **她给出时间地点**：经过一个时段，她第一次主动微信邀请玩家，并给出明确时间与地点。完成后解冻64。

暗示方向：`她说话仍然很轻，却不像以前那样总往后退。`

### 4→5 沉沦→归属：主动要求属于自己的印记

阶段基线：她已能主动邀约并体验多种私密玩法；终盘不只是玩家再次留下吻痕。

## 301 安若妍：从经营滤镜到掌握真实影像

阶段基线：玩家可能已和她拍照、讨论账号并独处；她仍会将一切整理成可发布的形象。

2. **保存的位置**：安装摄像头并经过两个游戏时段，记录她将照片放到加密相册旁。
3. **大堂临时掌镜**：下一个白天出现设备故障事件；玩家临时掌镜，拍到一次真正的笑。
4. **没有要求重拍**：经过一个时段，她通过微信只发给玩家未经修饰的照片；两人靠近查看，她没有立即躲开，但正式接吻留给阶段2。完成后解冻19。

暗示方向：`她扔掉了很多不够完美的照片，却少了一张。`

### 2→3 动摇→越界：第一次让镜头完全关掉

阶段基线：拥抱、舌吻和隔衣抚摸都可能发生；镜头外看她一眼不再是足够的突破。

1. **后台不是动态广场**：继续考古一条旧动态，发现同一幸福场景被重拍多次。

4. **没有镜头的第一夜**：直接承接阶段2上沿；真正突破是她不摆姿势、不找机位，并在没有记录的情况下进入第一夜。完成后解冻39。

暗示方向：`她什么都愿意留下影像，唯独有些真实不敢保存。`

### 3→4 越界→沉沦：真实第一次渗入公开人设

阶段基线：两人可能已经多次发生性关系；私下真实不再稀奇，难点是公开形象是否出现裂口。

1. **你选的衣服**：送当前阶段服饰并等待换装余波成熟。
2. **少了一句“他送的”**：她在朋友圈发布穿搭，第一次没有把礼物归功于丈夫。

暗示方向：`她最近的一条动态，少了一句过去从不会漏掉的话。`

### 4→5 沉沦→归属：镜头替她保存真实选择

## 302 母亲：从母亲身份回到她自己

### 1→2 贞淑→动摇：第一次没有把目光解释成孝顺

阶段基线：母子本就长期熟悉；新变化不是照顾和亲近，而是她意识到玩家以成年男人的目光看她。

1. **围裙下面的衣服**：破墙经过一个时段，回家事件记录她独自试穿新衣；听见玩家回来仍套上围裙，却没有换掉衣服。
2. **父亲只问了楼**：下一通固定电话只谈公寓和账目；她问父亲近况，却没有得到任何关于自己的回应。
3. **空出来的下午**：玩家使用全楼聚餐，替她卸掉一个下午的做饭职责；道具只创造时间，不立即结算。
4. **以自己的名义出门**：下一个下午，她穿新衣与玩家完成一次不为买菜、办事或照顾人的外出；允许一次带有异性意味的靠近停留，但不正式越过阶段2边界。完成后解冻19。

暗示方向：`她好像很久没有度过一个不属于家里任何人的下午。`

### 2→3 动摇→越界：药物首夜成为因果终点

阶段基线：拥抱、接吻和隔衣抚摸都可能发生；不能重新演第一次牵手或第一次亲吻。

1. **长期不归被确认**：下一通父亲电话固定确认长期不归。
2. **不会被打断的晚上**：玩家完成父亲事务安排，脚本锁定当晚没有电话、求助或外部打断。
3. **药物窗口**：只有前两项完成后，安神助眠剂才上架；购买只是取得剧情钥匙。
4. **首夜与早饭桌**：从阶段2上沿继续；真正无法清醒跨过的是母子身份与第一次性关系。完成药物首夜，并在下一游戏时段强制完成早饭桌第二幕，两幕结束后解冻39。

暗示方向：`那道界线并不在拥抱和亲吻之间，而在她清醒时绝不会承认的身份里。`

### 3→4 越界→沉沦：不再用照顾解释主动靠近

阶段基线：第一夜已经发生，之后也可能再次发生性关系；主动触碰不再足以构成突破。

1. **过度正常的家常**：早饭桌后再经过一个时段，触发她试图将一切塞回母子习惯的家庭日常。
2. **楼里女人的目光**：玩家使用节日礼盒全员装，引出全楼互动；姐妹群或楼务闲谈必定注意她的衣着与状态。
3. **无法解释的照顾**：下一个晚上厨房事件仍从添汤、喂饭开始，却由她主动做出无法再用母亲职责解释的亲密选择。
4. **没有家务借口的夜访**：经过一个时段，深夜管理员室出现她的头像；她不送饭、不提醒睡觉，主动创造相处理由。完成后解冻64。

暗示方向：`这一次，她似乎不是为了照顾你才来。`

### 4→5 沉沦→归属：照顾成为她主动选择的欲望

阶段基线：她已经能够主动夜访、安排私密相处并接受多种玩法；终盘不再是普通喂饭。

1. **一碗汤的变化**：阶段4后的晚间厨房必定出现事件，照顾与情欲明显合流。
2. **剧情解锁哺育癖**：事件结束后自动获得可装载项，不进入普通商店。
3. **装载并完成开幕**：玩家主动装载，完整演出专属开幕；装备成功本身不计完成。
4. **不再绕回“妈”**：经过一个完整时段，完成她主动延续关系的家庭后效；事后不再用母亲职责撤回选择。完成后解冻89。

`家宴`保留为多角色后期奖励，不作为母亲个人晋阶硬门。
