## 三、当前已拍板的产品设计

### 3.1 《第二机位》的定位

《第二机位》是沈静仪进入共享结局《录像带》之前的独立承接事件。

它只完成：

```text
顾国栋通过“门缝那一眼”知道沈静仪与玩家的关系
→ 冷静后主动给出下一次准确外出时间
→ 沈静仪利用这段空窗亲自安排第二机位
→ 一次真实亲密场景被记录
→ 沈静仪亲自封存母带
→ 玩家把母带带回302资料柜归档
→ 《第二机位》完成
```

《第二机位》不完成顾国栋的“观众席”结局。正式观众席只在沈静仪、周小满两条承接都完成后的共享《录像带》中结算。

### 3.2 “门缝那一眼”改为第一幕

旧随机全局开线方案作废。

新的第一幕必须由玩家真实进入102触发：

- 顾国栋原本外出；
- 沈静仪真实在102；
- 玩家进入102并进行有效关系剧情；
- 顾国栋临时回来取工作文件；
- 他从102里间半掩的门看见足以确认关系的一瞬；
- 他没有推门、没有质问，主动退出；
- 玩家离开102后必须亲自回302查看CAM-102异常记录；
- 监控复核证明他进入、停留、退出、等待玩家离开后再重新回家取文件。

不新增永久“琴房”或室内地图瓷砖。里间门只属于剧情构图、事件CG与正文表达。

### 3.3 顾国栋的主动回应

至少跨到另一游戏日，玩家通过现有“与顾国栋对饮”入口触发专属剧情。

顾国栋不直接谈门缝，也不说破关系，只主动给出未来某个准确外出窗口：

- 明确日期；
- 明确离开和返回时段；
- 那段时间102只有沈静仪；
- 表面仍以“照应家里／照应静仪”的体面口径表达。

这段行程必须真实覆盖丈夫作息，不能只是一句正文。

### 3.4 第二机位套件何时出现

不能在第一幕前就提前准备录像设备。

正确顺序：

```text
门缝第一幕完成
→ 302监控复核完成
→ 隔日顾国栋主动留下空窗
→ 玩家去102把空窗告诉沈静仪
→ 沈静仪决定由自己安排下一次记录
→ 商店才上架“第二机位套件”
```

套件可以包含：

- 小型离线摄像设备；
- 固定支架；
- 录制遥控器；
- 原始记录卡；
- 黑色硬壳封存盒。

### 3.5 正式录制日

在顾国栋给出的准确窗口内：

```text
玩家亲自到102
→ 点击“安装第二机位”
→ 沈静仪决定机位，玩家负责安装
→ 点击“把遥控器交给沈静仪”
→ 沈静仪亲自检查画面并按下REC
→ 进入现有完整阶段5亲密系统
→ 不设最低回合、指定动作、长按、进度条或缩水循环
→ 正常有效收尾后，才允许进入母带封存
```

### 3.6 “沈静仪母带”的表现

母带不能只表现成一句“获得母带”。

它是有完整物件生命周期的实物：

1. 沈静仪亲自停止录制；
2. 检查开头与结尾；
3. 决定保留；
4. 从设备中取出原始记录卡；
5. 放入黑色硬壳封存盒；
6. 盒面只标 `CAM-2`、日期与封条；
7. 交给玩家；
8. 玩家背包临时持有“沈静仪母带（已封存）”；
9. 玩家亲自返回302；
10. 点击“存入资料柜”；
11. 302环境长期出现黑色母带盒；
12. 此时才登记《第二机位》完成。

不要在《第二机位》中提前解释母带未来由谁送给顾国栋，也不要在承接事件中提前讨论最终观看规则。

## 四、建议的跨日期玩家流程

### 第一日：门缝与监控复核

```text
商店购买《第二机位》任务入口
→ 等顾国栋外出、沈静仪在102
→ 点击102一次性动作“赴沈静仪的约”
→ 第一幕“门缝那一眼”
→ 离开102
→ 回302打开监控
→ 点击CAM-102异常记录
→ 确认顾国栋看见并主动退出
```

### 第二日或以后：丈夫留下空窗

```text
至少经过一个完整游戏日
→ 使用现有“与顾国栋对饮”
→ 顾国栋主动给出未来准确外出时间
→ 未来丈夫作息真实写入该窗口
```

### 第三日：沈静仪作出决定

```text
在预约窗口到来前进入102
→ 点击“告诉她顾国栋留下的时间”
→ 沈静仪决定采用第二机位
→ 商店上架“第二机位套件”
→ 玩家购买套件
```

### 第四日：安装、录制、封存、归档

```text
到顾国栋给出的窗口
→ 玩家亲自进入102
→ 点击“安装第二机位”
→ 点击“把遥控器交给沈静仪”
→ 沈静仪按下REC
→ 完整阶段5亲密玩法
→ 正常收尾
→ 点击“让她取出记录卡并封存”
→ 玩家获得封存母带
→ 亲自回302
→ 点击“把沈静仪母带存入资料柜”
→ 《第二机位》完成
```

日期可因玩家错过窗口、医院硬锁或其他大型事件顺延，但不能在同一天把全部步骤连续做完。

## 五、三层体验标准

### 5.1 地图与功能层

玩家要真实点击：

- 102赴约；
- 302查看CAM-102异常记录；
- 顾国栋对饮；
- 102告知空窗；
- 商店购买第二机位套件；
- 102安装第二机位；
- 102交出遥控器／开始录制；
- 102封存母带；
- 302归档母带。

### 5.2 背景图与CG层

建议至少准备：

1. 门缝那一眼；
2. CAM-102异常记录；
3. 顾国栋给出准确行程；
4. 安装第二机位；
5. 沈静仪按下REC；
6. 取出记录卡并封存母带；
7. 302资料柜归档。

另可有：

- 102第二机位已安装的临时背景差分；
- 302资料柜已有母带盒的持久环境差分；
- 录制期间的 `CAM-2 / REC` 视觉叠层。

图片加载失败只能降级显示，不能决定状态是否推进。

### 5.3 正文层

AI只负责：

- 顾国栋看见后为何没有推门；
- 沈静仪是否听出丈夫的钥匙与脚步；
- 顾国栋如何体面地交出空窗；
- 沈静仪为何决定掌握机位；
- 她为何最终保留母带。

AI不能绕过地图动作、日期、作息、真实亲密场次和物件生命周期。

## 十、新窗口最终交付格式

新窗口完成后应向用户说明：

1. 关联审查发现了哪些真实问题；
2. 哪些问题已经修复，哪些只是设计待定；
3. 玩家从购买、门缝、监控、对饮、告知、安装、录制、封存到归档的实际流程；
4. 微信与怀孕为什么不会被错误接管；
5. 旧门缝随机事件和旧录像带存档如何兼容；
6. 跑了哪些测试，结果是多少；
7. 是否生成图片；
8. 明确没有构建、组卡、提交或发布，除非用户另行授权。
