# 母亲结局线：《回国》口头时段、《双重继承》商店启动、终幕后收束与长期影响权威设计

## 一、事件结构

母亲线只有两个正式事件：

```text
承接事件《回国》
结局事件《双重继承》
```

《回国》负责完成母亲的关系立场、群聊摊牌、玩家经营资格确认，以及父亲愿意近期回国完成交接的口头事实。

《双重继承》负责由玩家主动启动父亲真实回楼、现场验收、完全交权、总钥匙、三日早餐、机场视频与302最终收束。

不存在第三个《托付》事件。

## 二、《回国》的日期只存在于人物对话

《回国》结尾只允许父亲表达：

- 海外工作正在收尾；
- 自己近期会回国；
- 正式交接前由玩家准备好管理员室材料后再通知；
- 回来时以交接者而非重新审核者身份看公寓。

这只是软叙事事实。产品代码不得：

```text
写入父亲回国绝对时段
建立父亲抵达倒计时
到期自动启动《双重继承》
因玩家错过旧日期而失败
```

兼容字段即使继续留在旧档结构中，也固定视为废弃值，不再作为任何生产判断的消费者。

《回国》完成只提交：

```text
_回国.阶段 = 已完成
_已完成特殊场景 += 回国
父亲已经口头确认近期回国并等待玩家通知
```

## 三、《双重继承》改为商店场景票

### 3.1 商品

```text
ID：双重继承
名称：「双重继承」
类别：特殊场景
建议价格：1500
使用地点：管理员室
```

商品代表正式交接文件夹、签字页与总钥匙牌，不代表玩家花钱购买父亲认可。

建议描述：

> 父亲已经答应近期回国。一套用于正式交接公寓管理权的文件夹、签字页和钥匙牌。带到管理员室整理妥当，再通知他可以回楼。

### 3.2 上架与购买

仅在以下事实成立时上架：

```text
《回国》已经完成
《双重继承》尚未购买、启动或完成
没有坏结局
```

购买只执行：

```text
现金扣款
背包 += 双重继承
双重继承阶段 = 待使用双重继承
```

购买本身不让父亲出现，不推进世界时间。

### 3.3 在管理员室使用

使用时再次验证：

```text
玩家位于管理员室
场景票仍在背包
《回国》已经完成
没有亲密、医院、父亲活动电话、特殊场景或其他强剧情
```

成功后：

```text
背包移除双重继承
双重继承阶段 = 待父亲回楼
最早父亲到楼时段 = 当前时段或下一个安全下午
```

这才是父亲实际到公寓的唯一硬调度起点。它与《回国》里的口头“近期回国”没有日期绑定。

## 四、《双重继承》主体

```text

→ 一回合专属最终收束

→ 《双重继承》原子完成
```

## 五、视频结束后的上下文隔离

母亲视频现场正文继续使用现有独立短线程和持久现场记录，不写入普通正文历史。

第7张结束后不得直接把控制权交给普通自由正文。脚本先冻结以下硬事实：

```text
父亲已经挂断并不在302
手机已经回到母亲手中
视频不会再次接通
刚才的亲密动作已经彻底结束
302当前只有玩家和母亲
公寓楼总钥匙仍在玩家背包
```

随后只开放一次性硬动作：

```text
把公寓楼总钥匙放到她的钥匙旁
```

最终收束正文只读取上述短快照，不读取54张视频历史。AI只能演出玩家放下钥匙、母亲的反应、母亲关门与最后确认；不得继续视频、继续成人动作、让父亲开口、让其他角色进入或自行宣布系统结局完成。

若弱模型首稿越界，允许一次定向重写；仍不合格时使用固定安全收束，不能让玩家永远卡在结局最后一步。

## 六、结局完成后的经济规则

公寓经济与楼务玩法继续存在，但父亲审核永久结束。

继续保留：

- 收租、欠租、现金、维修支出；
- 公共楼务、住户反馈、经营质量；
- 胜任度作为公寓内部经营表现。

永久停止：

- 父亲按期查账或逐项询问楼务；
- 依据胜任度生成最后通牒；
- 父亲收回钥匙或让玩家去打工的坏结局；
- 未接父亲电话形成失联责任；
- 风闻通过父亲重新审判管理资格；
- 母亲替玩家向父亲圆场。

结局完成时清理尚未成立的旧通牒与母亲圆场水位。经营失败只产生现金、维修、住户与公共秩序后果，不再推翻正式交权。

## 七、结局后的父亲联络

父亲继续在海外，但切换为低频家常联络：

```text
约14～21个游戏日一次
两通至少相隔12天
只在安全下午或晚上送达
未接不扣分、不升级、不形成责任
```

话题池：

- 父亲自己的海外近况；
- 身体、饮食、睡眠；
- 玩家个人生活与未来；
- 家里、亲戚、节日和旧事；
- 母亲近期生活；
- 普通转达、快递或家庭琐事。

父亲主动联系不得携带公寓账本、维修、欠租、上交、胜任度或审核话题。玩家主动谈到公寓时，他可以以曾经管理过这里的人身份回应经验，但不得恢复批准权或问责权。

父亲始终不知道母亲与玩家的真实关系，不得出现看穿、默许、成全或双关托付。

## 八、母亲的长期转变

相关AI只需长期知道：

```text
玩家是公寓唯一管理员
父亲已经退出公寓日常管理
母亲主动选择留在302
母亲与玩家的特殊关系已经稳定成立
父亲始终不知情
```

不长期注入钥匙、挂钩、饭桌、柜子或门锁细节，避免分散正文注意力。

母亲不再说“等你爸回来决定”，不再替玩家向父亲圆场，也不会因父亲偶尔来电退回结局前关系；但仍保留自己的判断与人格，不成为无条件顺从者。

## 九、姐妹群、私聊与朋友圈进入结局期

### 9.1 认知从真实事实派生

不能因为《双重继承》完成就让全员全知。每名角色只读取：

- 自己的真实阶段与已完成结局；
- 已在姐妹群真实发出的摊牌内容；
- 已真实发布的朋友圈内容；
- 自己的私聊记忆；
- 当前群成员对其可知的结局事实。

已摊牌、已完成结局的角色不再装作第一次发现；尚未摊牌者继续保留边界。

### 9.2 群聊口径变化

结局期不再统一写成“彼此隐约有数却谁都不说破”。

群聊张力从：

```text
关系到底存不存在
```

转为：

```text
时间、陪伴、优先级、邀约、生活安排和各自结局后的现实
```

已公开关系可以直接调侃；未公开关系不能被其他人凭后台变量说破。母亲继续作为不参与雌竞的成员发言，不成为群规训者或每轮必出场者。

### 9.3 一次性结局余波

《双重继承》完成后的下一个安全手机节拍，姐妹群可产生一次5～8气泡的非阻塞余波：

- 母亲说明父亲已经离开，玩家正式接管公寓；
- 她确认自己仍留在302；
- 其他成员按自己的真实阶段、结局与已知事实回应；
- 不复述机场隐秘现场；
- 不重新举行《回国》茶话会；
- 失败不回滚结局，可在后续节拍重试，成功后只发生一次。

### 9.4 三层表达边界

```text
公开朋友圈：社会上可解释的称呼和内容
姐妹群：按群内已经公开的关系事实说话
私聊／仅你可见：按本人真实阶段与结局使用更直接的口吻
```

不能让群内摊牌自动泄漏到公开朋友圈。称呼按场景、本人历史与真实结局派生，禁止所有角色统一使用同一个亲密称呼。

## 十、本轮暂不扩展

孕产、医院、生产和产后差分仍沿用现有通用系统；除夏乔已经完成的借种专属差分外，其他角色以后统一完善，本轮不扩展第二套孕产逻辑。
