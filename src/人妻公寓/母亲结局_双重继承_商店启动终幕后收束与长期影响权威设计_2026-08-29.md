## 一、最终拍板

母亲线仍只有两个玩家可见事件：

```text
承接事件《回国》
结局事件《双重继承》
```

《回国》只完成以下叙事与关系事实：

- 父亲看过经营归档，确认公寓长期稳定；
- 父亲口头表示近期回国，并愿意以交接者身份回来；
- 母亲确认玩家已经是合格继承人；
- 母亲不再替玩家向父亲圆场；
- 母亲加入姐妹茶话会并维持已经成立的关系；
- 《回国》完成。

《回国》不再把父亲抵达日期写入世界时钟，也不自动启动《双重继承》。父亲在微信中谈到的日期、机票和“近期回来”只是软叙事，不承担代码触发职责。

## 二、《双重继承》商店启动

### 2.1 商品

```text
ID：双重继承
名称：双重继承
类别：特殊场景
建议价格：1500
启动方式：背包使用
使用地点：管理员室
```

商品代表正式交接材料、签字页与总钥匙牌，不代表玩家花钱购买父亲认可。

### 2.2 上架条件

```text
《回国》已经完成
《双重继承》尚未购买、启动或完成
当前没有坏结局
```

购买只扣款并把`双重继承`放入背包，不让父亲立即出现。

### 2.3 使用

玩家到管理员室，从背包使用`双重继承`。使用时重新验证道具、地点、上游完成事实与强剧情互斥；验证失败不消费道具。

使用成功后：

```text
背包移除：双重继承
双重继承阶段：待父亲抵达
父亲最早抵达时段：使用后的下一个安全下午
```

父亲真正到达公寓的时间只从《双重继承》启动后计算，与《回国》对话中提到的口头日期无代码绑定。玩家因此拥有正式开始结局的决定权，也不会因错过旧日期永久失败。

```text
父亲在安全下午到达公寓
→ 八个公共区域现场验收
→ 管理员室两回合完全交权
→ 玩家亲自接过公寓楼总钥匙

→ 三人家庭早餐
→ 父亲离楼前往机场
→ 微信视频通话终幕
```

主体沿用现有公共验收、完全交权、三日早餐及54张视频CG实现，不重新审核胜任度，也不存在父亲反悔或失败分支。

## 四、视频结束后的硬转场

视频现场正文属于隔离事件短线程。长视频记录不进入普通正文历史；普通正文也不得在视频第七张后自行猜测场景已经如何结束。

### 4.1 第七张结束时

只提交：

```text
父亲已经挂断
视频状态已完成
手机已回到母亲手中
双重继承阶段 = 待总钥匙收束
```

此时不能写入《双重继承》完成ID。

### 4.2 确定性转场

系统向玩家明确说明：

> 手机里的画面已经彻底暗下去。父亲不在302，手机也已经回到母亲手中。刚才的现场已经结束，房间里只剩下你和她。

不把54张视频记录、逐帧动作或完整微信内容塞给下一次普通正文模型。

### 4.3 最后现实动作

302只出现一个动作：

```text
把公寓楼总钥匙放到她的钥匙旁
```

点击后启动一次性最终收束正文。提示只提供以下硬事实：

```text
父亲已经在机场挂断并离开；
父亲不在302，也始终不知情；
手机已经由母亲接回，视频不会再次接通；
刚才的亲密现场已经完全结束，不得继续；
302只有玩家与母亲；
玩家正在放下父亲交给自己的公寓楼总钥匙；
本拍只演母亲对此的反应、她亲自关门和最终确认。
```

禁止父亲重新说话、重新来电或回到302，禁止继续视频现场动作，禁止其他角色突然进入，也禁止复述完整视频。

最终正文成功后才原子提交：

```text
背包移除：公寓楼总钥匙
双重继承阶段 = 已完成
_已完成特殊场景 += 双重继承
恢复普通地图、房间动作与输入
```

母亲最后确认的主体性保持：

> 楼是他交给你的。这个家，是我自己留下来的。

钥匙与关门只承担一次性结局演出，不作为以后每轮都注入AI的长期环境细节。

## 五、普通正文重新接管

结局完成后的前两轮只提供短暂过渡摘要：

```text
父亲的机场视频已经结束；
父亲已经返回海外并始终不知情；
玩家已经正式接管公寓；
母亲主动选择留在302；
刚才的隐秘现场已经结束，不复述、不继续。
```

长期只保留四项必要事实：

```text
玩家是公寓唯一管理员
父亲已经退出公寓日常管理
母亲主动留在302，既有特殊关系稳定成立
父亲始终不知情
```

不长期注入钥匙、挂钩、饭桌、柜子和门锁等微观环境信息。

## 六、结局后的经济系统

经济玩法继续，父亲审核永久结束。

继续保留：

- 收租、欠租与现金；
- 公共楼务、维修费用与设施状态；
- 住户反馈、关系与风闻；
- 胜任度作为公寓内部经营质量指标。

永久停止：

- 父亲周期查账和楼务问责；
- 因胜任度触发最后通牒；
- 父亲收回公寓或管理员钥匙；
- “滚去打工”的管理失败坏结局；
- 未接父亲电话形成失联责任；
- 母亲替玩家向父亲圆场；
- 风闻转化为父亲楼务质问。

业主款或分成可以继续作为财务流水存在，但不再成为父亲是否认可玩家的考试，也不生成楼务电话。

## 七、父亲长期联络

结局后普通经营系统不再生产父亲电话。父亲改为独立的低频家常联络：

```text
两通之间至少间隔较长世界时间
只在安全下午或晚上出现
未接不扣分、不形成责任、不升级通牒
```

话题只来自：

- 父亲海外生活与普通生意近况；
- 身体、饮食与睡眠；
- 玩家个人生活；
- 母亲普通身体与生活近况；
- 家庭旧事、节日、亲戚、快递和带东西；
- 偶尔的人生经验。

不得生成账目、租金、维修、楼务、胜任度、审批或重新交楼。玩家主动提公寓时，父亲可以作为前任管理员简单回应，但不能反向索取报表或恢复上级身份。

父亲始终寡言、务实，把关心藏在简短训话里；始终不知道母亲与玩家的真实关系。

## 八、母亲长期变化

结局后母亲不再向父亲圆场，也不再说“等你爸回来再决定”。相关AI只需知道：

```text
玩家是唯一管理员
父亲不再管理公寓
母亲主动选择留下
母亲与玩家关系已经稳定
父亲始终不知情
```

她仍保留自身判断，可以直接提醒玩家经营或生活问题，但不会替玩家向父亲求情，也不会在父亲偶尔来电时退回结局前的旧秩序。

## 九、手机、朋友圈与姐妹群

### 9.1 认知按真实事实派生

不能因《双重继承》完成就让全员获得后台全知。每名成员的关系公开级从以下事实临时派生：

- 当前阶段；
- 已完成承接与结局；
- 已真实落库的姐妹群消息；
- 已真实发布的朋友圈；
- 本人私聊记忆；
- 已公开的丈夫认知和家庭结构。

可区分：`心知肚明`、`群内摊牌`、`结局稳定`、`家庭结构已公开`。未公开内容仍不能说破。

### 9.2 一次性结局余波

《双重继承》完成后的下一个安全晚上，姐妹群生成一次5～8气泡的非阻塞余波：

- 母亲说明父亲已经离开，玩家正式接管公寓，自己仍留在302；
- 其他成员按自己真实阶段与结局回应；
- 已经公开或完成的关系不得失忆后重新震惊；
- 尚未公开的角色保持当前边界；
- 不透露机场视频的隐秘现场。

失败只顺延，不回滚结局，不同时轰炸所有私聊。

### 9.3 结局期普通群聊

群聊重心从“彼此到底有没有关系”转为：

- 时间与陪伴；
- 邀约、聚餐、礼物与共同活动；
- 已公开的结局后生活；
- 玩家正式接管公寓后的身份变化；
- 真实发生过的共同回忆；
- 各自丈夫与家庭安排中已经公开的部分；
- 互相支招、拆台、调侃和现实分寸。

雌竞和火气仍可存在，但不再把已经摊牌的关系反复写成第一次发现。母亲不参与普通雌竞，也不成为每轮必发言的纪律委员。

### 9.4 称呼按场景分层

- 公开朋友圈：只用玩家名字、管理员及社会上可解释的称呼；
- 姐妹群：允许真实在群内使用过、符合人物的昵称；
- 私聊／仅你可见：可按本人结局和关系使用更直接的称呼；
- 禁止所有角色统一套用“主人”“老公”等同质称呼。

### 9.5 朋友圈分层

- 公开朋友圈可以说公寓已经正式交接，但不能公开母亲与玩家的真实关系；
- 姐妹群知情不等于公开朋友圈可泄密；
- 仅你可见和私聊可以按真实结局更直接；
- 其他角色的首次结局回应采用懒触发，不在母亲结局结束后同时轰炸手机。
